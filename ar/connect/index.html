استوديوك.

Kleo خادم MCP بعيد. يتحدث بروتوكول Model Context Protocol عبر Streamable HTTP مع OAuth 2.1، لذا يعمل العنوان نفسه في كل عميل، والربط زر واحد على صفحة Kleo نفسها — بلا نموذج تسجيل، بلا كلمة مرور، بلا بطاقة. البداية مجانية: 7 نقاط في حسابك لحظة الربط، أنيماتيك واحد. أضفه إلى مساعدك وصِف الفيلم الذي تريد صنعه.

01الربط

اختر مساعدك.

كل عميل أدناه يستخدم العنوان نفسه والبداية نفسها بزر واحد: الصق العنوان، تنفتح صفحة Kleo، تنقر Start free، وتعود إلى العميل و7 نقاط في الحساب. هذه هي الخطوات التي اختبرناها.

Claude التطبيق · الويب

عنوان الخادم https://mcp.kleooai.com/mcp
  1. افتح Settings → Connectors واختر Add custom connector.
  2. سمِّه Kleo، والصق العنوان أعلاه، وأكّد. تنفتح صفحة Kleo: انقر Start free وتعود إلى Claude.
  3. في محادثة جديدة، فعّل Kleo من قائمة الأدوات واطلب: اصنع لي Short مدته 45 ثانية عن…

تسمح خطة Claude المجانية بموصّل مخصص واحد.

ChatGPT وضع المطوّر

عنوان الخادم https://mcp.kleooai.com/mcp
  1. افتح Settings → Apps & Connectors (يُسمى Connectors في الإصدارات الأقدم)، ثم Advanced settings، وفعّل Developer mode.
  2. عُد إلى Connectors واختر Create: سمِّه Kleo، والصق العنوان، واضبط المصادقة على OAuth، واحفظ. تنفتح صفحة Kleo: انقر Start free وتعود إلى ChatGPT.
  3. في المحادثة، فعّل Kleo من قائمة + واطلب الفيديو. يطلب منك ChatGPT التأكيد قبل بدء أي تصيير.

يتطلب ChatGPT Plus أو Pro أو Business أو Enterprise.

Grok الموصّلات

عنوان الخادم https://mcp.kleooai.com/mcp
  1. على grok.com أو في التطبيق، افتح Settings → Connectors واختر Add connector → Custom.
  2. سمِّه Kleo، والصق العنوان، وأكّد. تنفتح صفحة Kleo: انقر Start free وتعود إلى Grok.
  3. في المحادثة، فعّل Kleo في قائمة الموصّلات واطلب الفيديو.

Claude Code سطر الأوامر

# أضف Kleo مرة واحدة (أضف --scope user ليكون في كل مشروع) claude mcp add --transport http kleo https://mcp.kleooai.com/mcp # ثم، داخل جلسة: /mcp → Kleo → Authenticate
  1. نفّذ الأمر أعلاه، ثم اكتب /mcp في جلسة، واختر Kleo ثم Authenticate: تنفتح صفحة Kleo في متصفحك، انقر Start free وتعود إلى Claude Code.
  2. اطلب: Use kleo for a 5-minute video on the history of coffee, 16:9. يتابع Claude Code التقدم نيابةً عنك ويسلّمك الروابط.

Cursor mcp.json

أنشئ أو حرّر ~/.cursor/mcp.json (لكل المشاريع) أو .cursor/mcp.json داخل مشروع واحد.

{ "mcpServers": { "kleo": { "url": "https://mcp.kleooai.com/mcp" } } }
  1. احفظ الملف: يعرض Cursor خادم Kleo تحت Settings → MCP. انقر Connect (أو استخدم أداة مرة واحدة): تنفتح صفحة Kleo، انقر Start free وتعود إلى Cursor.

VS Code mcp.json

أنشئ .vscode/mcp.json في مساحة عملك (أو نفّذ MCP: Add Server من لوحة الأوامر والصق العنوان).

{ "servers": { "kleo": { "type": "http", "url": "https://mcp.kleooai.com/mcp" } } }
  1. احفظ الملف، ثم انقر Start فوق مدخل الخادم. يفتح VS Code صفحة Kleo: انقر Start free وتعود إلى VS Code.
  2. في Copilot Chat، انتقل إلى وضع Agent: تظهر أدوات kleo في قائمة اختيار الأدوات.

OpenCode opencode.jsonc

أضف هذا إلى ~/.config/opencode/opencode.jsonc (عام) أو إلى opencode.jsonc في المشروع، ثم اربط من الطرفية.

{ "mcp": { "kleo": { "type": "remote", "url": "https://mcp.kleooai.com/mcp", "enabled": true } } }
# اربط مرة واحدة (يفتح المتصفح) opencode mcp auth kleo
  1. احفظ الإعدادات ونفّذ الأمر أعلاه: تنفتح صفحة Kleo في المتصفح، انقر Start free وتعود إلى OpenCode.
  2. شغّل opencode واطلب الفيديو: أدوات kleo متاحة في كل جلسة.

Gemini CLI سطر الأوامر

# أضف Kleo (أضف --scope user ليكون في كل مشروع) gemini mcp add --transport http kleo https://mcp.kleooai.com/mcp
  1. نفّذ الأمر أعلاه، ثم شغّل gemini واكتب /mcp auth kleo: تنفتح صفحة Kleo في متصفحك، انقر Start free وتعود إلى Gemini CLI.
  2. اطلب الفيديو في الجلسة. يعرض /mcp list كل أدوات kleo.

Windsurf وتطبيق Gemini ووكلاؤك الخاصون http

Kleo خادم MCP قياسي عبر نقل Streamable HTTP مع OAuth 2.1. أي عميل متوافق يتصل بالعنوان نفسه والبداية نفسها بزر واحد.

عنوان الخادم https://mcp.kleooai.com/mcp
  1. Windsurf: Settings → MCP → Add server، الصق العنوان (يستخدم ملفه mcp_config.json المفتاح "serverUrl").
  2. تطبيق Gemini: Settings → Connected apps → Custom apps، الصق العنوان (يتطلب حاليًا Google AI Pro أو Ultra).
  3. لوكيلك الخاص: استخدم MCP SDK (بلغة Python أو TypeScript) مع نقل HTTP وأكمل تدفق OAuth مرة واحدة.

02الطلب الأول

ابدأ بطلب واضح.

يقرأ المساعد طلبك وفق قائمة استقبال Kleo — الموضوع والمدة والصيغة والمظهر — ويسأل عن كل ما ينقص قبل أن يكتب المعالجة. اذكر الأربعة وينتقل مباشرةً إلى العمل. الصق هذا في محادثتك الأولى:

«استخدم Kleo للتخطيط لفيلم مدته 30 ثانية عن حارس منارة يكتشف رسالة في زجاجة. مظهر واقعي، سرد بالإنجليزية، 9:16. أرني المخطط وتكلفة النقاط قبل التصيير.»

يتوفر مظهران على الخادم: واقعي، لقطات حية مولَّدة، ورسوم متحركة، فيلم رسوم متحركة ثنائي الأبعاد. بدّل الكلمة في الطلب لتحصل على الآخر.

03النقاط

تحقق من رصيدك قبل الإنتاج.

يشمل الربط 7 نقاط: أنيماتيك من الستوري بورد الخاص بك يكلّف 5 وكل حساب يمكنه طلب واحد. يُصنع الفيلم فقط للحسابات التي اشترت باقة، أي باقة، ويكلّف فيلم مدته 30 ثانية 15 نقطة، لذلك يبدأ الفيلم الأول بباقة الـ€5: 7 + 10 = 17 نقطة، ما يكفي لـShort مدته 30 ثانية.

اطلب من المساعد صفحة حسابك لشراء النقاط، ثم أكّد عندما تريد بدء التصيير. لا يُخصم شيء حتى يقبل Kleo المهمة: يذكر المساعد النقاط الدقيقة أولًا، والطلب المرفوض لا يكلّف شيئًا.
