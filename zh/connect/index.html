Kleo 是一个远程 MCP 服务器。它通过 Streamable HTTP 和 OAuth 2.1 使用 Model Context Protocol，所以同一个地址在每个客户端都能用，而连接只是 Kleo 自己页面上的一个按钮——没有注册表单，没有密码，没有银行卡。免费开始：连接的那一刻账户里就有 7 积分，可做一部动态分镜。把它添加到你的助手里，然后描述你想做的影片。

01连接

选择你的助手。

下面每个客户端都使用同一个地址、同样的一键开始：粘贴地址，Kleo 的页面打开，点击免费开始，你就回到了客户端，账户里有 7 积分。以下是我们测试过的步骤。

  2. 命名为 Kleo，粘贴上面的地址，确认。Kleo 的页面打开：点击免费开始，你就回到了 Claude。
  3. 在新对话中，从工具菜单开启 Kleo，然后说：帮我做一个 45 秒的 Short，讲……

ChatGPT 开发者模式

Grok 连接器

  1. 在 grok.com 或应用中，打开设置 → 连接器，选择添加连接器 → 自定义。

Claude Code 命令行

# 添加一次 Kleo（加上 --scope user 可在所有项目中使用） claude mcp add --transport http kleo https://mcp.kleooai.com/mcp # 然后，在会话中： /mcp → Kleo → Authenticate
  1. 运行上面的命令，然后在会话中输入 /mcp，选择 Kleo 和 Authenticate：Kleo 的页面在浏览器中打开，点击免费开始，你就回到了 Claude Code。
  2. 提出需求：用 kleo 做一个 5 分钟的视频，讲咖啡的历史，16:9。Claude Code 会替你查看进度，并把链接交给你。

Cursor mcp.json

创建或编辑 ~/.cursor/mcp.json（所有项目）或某个项目内的 .cursor/mcp.json。

{ "mcpServers": { "kleo": { "url": "https://mcp.kleooai.com/mcp" } } }
  1. 保存文件：Cursor 会在设置 → MCP 下列出 Kleo。点击连接（或使用一次工具）：Kleo 的页面打开，点击免费开始，你就回到了 Cursor。

VS Code mcp.json

在你的工作区创建 .vscode/mcp.json（或从命令面板运行 MCP: Add Server 并粘贴地址）。

{ "servers": { "kleo": { "type": "http", "url": "https://mcp.kleooai.com/mcp" } } }
  1. 保存文件，然后点击服务器条目上方的启动。VS Code 打开 Kleo 的页面：点击免费开始，你就回到了 VS Code。
  2. 在 Copilot Chat 中切换到智能体模式：kleo 工具会出现在工具选择器中。

OpenCode opencode.jsonc

把下面的内容加到 ~/.config/opencode/opencode.jsonc（全局）或项目内的 opencode.jsonc，然后从终端连接。

{ "mcp": { "kleo": { "type": "remote", "url": "https://mcp.kleooai.com/mcp", "enabled": true } } }
# 连接一次（会打开浏览器） opencode mcp auth kleo
  1. 保存配置并运行上面的命令：Kleo 的页面在浏览器中打开，点击免费开始，你就回到了 OpenCode。
  2. 启动 opencode 并提出视频需求：kleo 工具在每个会话中都可用。

Gemini CLI 命令行

# 添加 Kleo（加上 --scope user 可在所有项目中使用） gemini mcp add --transport http kleo https://mcp.kleooai.com/mcp
  1. 运行上面的命令，然后启动 gemini 并输入 /mcp auth kleo：Kleo 的页面在浏览器中打开，点击免费开始，你就回到了 Gemini CLI。
  2. 在会话中提出视频需求。/mcp list 会列出所有 kleo 工具。

Windsurf、Gemini 应用和你自己的智能体 http

Kleo 是一个标准的 MCP 服务器，使用 Streamable HTTP 传输和 OAuth 2.1。任何兼容的客户端都用同一个地址、同样的一键开始来连接。

服务器地址 https://mcp.kleooai.com/mcp
  1. Windsurf：设置 → MCP → 添加服务器，粘贴地址（它的 mcp_config.json 使用键 "serverUrl"）。
  2. Gemini 应用：设置 → 已连接的应用 → 自定义应用，粘贴地址（目前需要 Google AI Pro 或 Ultra）。
  3. 你自己的智能体：使用 MCP SDK（Python 或 TypeScript）的 HTTP 传输，并完成一次 OAuth 流程。

02第一个请求

从一个清晰的请求开始。

助手会对照 Kleo 的需求清单——主题、时长、格式、风格——读取你的请求，在写剧本大纲之前把缺的问清楚。四项都说全，它就直接开工。把这段粘贴到你的第一次对话里：

“用 Kleo 规划一部 30 秒的影片，讲一位灯塔看守人发现漂流瓶里的信。写实风格，英语旁白，9:16。渲染前先给我看大纲和积分费用。”

服务器上有两种风格：写实，生成的真人实拍感画面；动画，一部 2D 动画影片。把提示词里的那个词换掉，就得到另一种。

03积分

制作前先查看余额。

连接即包含 7 积分：你的分镜的动态分镜需要 5 积分，每个账户都可以订购。影片只为购买过积分包的账户制作——任何积分包都行——而一部 30 秒的影片需要 15 积分，所以第一部影片从 €5 积分包开始：7 + 10 = 17 积分，足够做一个 30 秒的 Short。

向助手索要你的账户页面来购买积分，然后在你希望开始渲染时确认。Kleo 接受任务之前不会扣任何费用：助手会先说明准确的积分数，被拒绝的请求不收费。
