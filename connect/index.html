Kleo is a remote MCP server. It speaks the Model Context Protocol over Streamable HTTP with OAuth 2.1, so the same address connects from compatible clients, and connecting is a single button on Kleo’s own page — no sign-up form, no password, no card. It is free to start: 7 credits on your account the moment you connect, one animatic. Add it to your assistant and describe the film you want to make.

ChatGPT

Set up in ChatGPT ↗

Connect Kleo once, then create from your conversation. Manual setup is currently available for accounts with Developer mode.

Server address https://mcp.kleooai.com/mcp
  1. Open Settings → Security and login and enable Developer mode, if available for your account and workspace.
  2. Open Plugins, choose + to add a plugin, and enter https://mcp.kleooai.com/mcp as the public MCP server URL.
  3. Review the plugin information and complete Kleo’s sign-in when prompted.
  4. Start a new conversation and add Kleo to its tools. Choose the animatic or film prompt below and approve the treatment and cost before rendering.

Instructions checked against OpenAI’s setup guide on 24 September 2026. Access and menus can vary by account and workspace.

Claude Code cli

# add Kleo once (add --scope user to have it in every project) claude mcp add --transport http kleo https://mcp.kleooai.com/mcp # then, inside a session: /mcp → Kleo → Authenticate
  1. Run the command above, then type /mcp in a session, pick Kleo and Authenticate: Kleo’s page opens in your browser, click Start free and you’re back in Claude Code.
  2. Ask: Use kleo for a 5-minute video on the history of coffee, 16:9. Claude Code checks the progress for you and hands you the links.

Cursor mcp.json

Create or edit ~/.cursor/mcp.json (all projects) or .cursor/mcp.json inside one project.

{ "mcpServers": { "kleo": { "url": "https://mcp.kleooai.com/mcp" } } }
  1. Save the file: Cursor lists Kleo under Settings → MCP. Click Connect (or use a tool once): Kleo’s page opens, click Start free and you’re back in Cursor.

VS Code mcp.json

Create .vscode/mcp.json in your workspace (or run MCP: Add Server from the Command Palette and paste the address).

{ "servers": { "kleo": { "type": "http", "url": "https://mcp.kleooai.com/mcp" } } }
  1. Save the file, then click Start above the server entry. VS Code opens Kleo’s page: click Start free and you’re back in VS Code.
  2. In Copilot Chat, switch to Agent mode: the kleo tools appear in the tools picker.

OpenCode opencode.jsonc

Add this to ~/.config/opencode/opencode.jsonc (global) or to opencode.jsonc in the project, then connect from the terminal.

{ "mcp": { "kleo": { "type": "remote", "url": "https://mcp.kleooai.com/mcp", "enabled": true } } }
# connect once (opens the browser) opencode mcp auth kleo
  1. Save the config and run the command above: Kleo’s page opens in the browser, click Start free and you’re back in OpenCode.
  2. Start opencode and ask for the video: the kleo tools are available in every session.

Windsurf, the Gemini app and your own agents http

Server address https://mcp.kleooai.com/mcp

02First request

Start with a clear request.

The assistant reads your request against Kleo’s intake — subject, length, format, look — and asks for whatever is missing before it writes the treatment. Say all four and it goes straight to work. Paste this in your first chat:

Choose the product before rendering. Try a free animatic: drawn frames, camera movement and narration, 15–60 seconds, 5 credits. Create a film: generated moving footage, 15 seconds to 5 minutes, with a purchased pack and a quote you approve.

Try a free animatic

“Use Kleo to plan a 30-second animatic about a paper boat returning to its maker. Animation look, English narration, 9:16. Show me the treatment, confirm that the product is an animatic, and check the exact credit cost against my available balance. Wait for my approval before rendering. Do not start a paid film or buy credits.”

Create a film

“Use Kleo to plan a 20-second narrated film about two fictional cars leaving an amber-lit tunnel for a coastal road at golden hour. Realistic look, English narration, 16:9. Show me the treatment, the exact film credit cost, my available balance and whether my account is eligible. Wait for my approval before rendering. Do not buy credits. After rendering, give me the finished MP4 download link.”

Two looks are available on the server: realistic, generated live-action footage, and animation, a 2D animated film. Swap the word in the prompt to get the other one.

03Credits

Check your balance before production.

A €5 pack adds 10 purchased credits and unlocks film rendering. A 20-second film costs 10 credits; a 30-second film costs 15. After one 5-credit animatic, your 7 starter credits become 2; adding that pack gives a total balance of 12, not enough for a 30-second film. Ask your assistant to confirm the credits eligible for your chosen product and the exact quote before you buy or render.

Ask the assistant for your account page to buy credits, then confirm when you want the render to start. Nothing is charged until Kleo accepts the job: the assistant states the exact credits first, and a refused request costs nothing.
