映像制作のための
MCPサーバー。

Kleoはひとつのフィルム制作ワークフローをあらゆるMCPクライアントに提供します。インテーク、トリートメント、絵コンテ、ジョブのためにレンタルしたGPU上でのレンダリング、そして4K 60 fpsで完成したナレーション付きフィルムへのリンク。ひとりのナレーター、2つのルック、2つの製品（フィルム、または同じ絵コンテのアニマティック）、15秒から5分まで。アプリもダッシュボードもなく、アシスタントが以下のツールを通じて作業します。

https://mcp.kleooai.com/mcp

01エンドポイント

HTTPSで接続する。

KleoはリモートMCPサーバーです。ひとつのアドレス、Streamable HTTPトランスポート、OAuth 2.1。MCPクライアントにアドレスを設定し、ブラウザで認証を完了します。登録フォームもパスワードもありません。

  • エンドポイントhttps://mcp.kleooai.com/mcp
  • トランスポートStreamable HTTP。どのクライアントでも同じアドレス。
  • 認証OAuth 2.1。認証中にクライアントがKleo自身のページを開きます。Start freeをクリックすると、アカウントに7クレジットが入った状態でクライアントに戻ります。フォームもカードもなし。
  • トークンなしの場合エンドポイントへのGETは401を返し、OAuthリソースメタデータを含みます。これはプロトコルのエンドポイントであってウェブページではありません。ブラウザで開くことは接続手順ではありません。
  • クライアントClaude、ChatGPT、Grok、Claude Code、Cursor、VS Code、OpenCode、Gemini CLI、Windsurf、Geminiアプリ、そしてHTTPトランスポート対応のあらゆるMCP SDK。

各クライアントの接続手順 →

ターミナルやエディタから。

テスト済みクライアントのうち2つを例として挙げます。ClaudeとChatGPTからVS CodeとGemini CLIまで、その他の手順は接続ページにあります。

Claude Code cli

# Kleoを一度だけ追加 claude mcp add --transport http kleo https://mcp.kleooai.com/mcp # その後、セッション内で: /mcp → Kleo → Authenticate

ブラウザでKleoのページが開くので、Start freeをクリックするとClaude Codeに戻ります。

Cursor ~/.cursor/mcp.json

{ "mcpServers": { "kleo": { "url": "https://mcp.kleooai.com/mcp" } } }

ファイルを保存します。Cursorが接続するとKleoのページが開くので、Start freeをクリックするとCursorに戻ります。

02ワークフロー

制作の流れ。

ツールは決まった順序で実行されます。アシスタントがあなたの依頼を読み、kleo_adapt_promptからトリートメントを受け取り、kleo_storyboard_guideに従って絵コンテを書き、そのうえで初めてKleoにレンダリングを頼みます。

kleoのツール、アシスタントが実行する順に

ツール 役割
kleo_adapt_prompt 依頼をインテーク（題材、長さ、フォーマット、ルック。任意で視聴者、トーン、必ず入れたいもの）に照らして読み、足りないものを尋ね、トリートメントを返します。ログライン、切り口、オープニング、幕構成、結末、ルック、テンポ、ナレーター。
kleo_storyboard_guide 絵コンテの書き方を説明します。演出ブロック、シーン、ショット、制限。
kleo_create_video すべてを確認し、正確なクレジット数を提示してから、そのジョブのためにレンタルしたGPUでレンダリングを開始します。product: "film"または"animatic"を受け取ります。
kleo_get_job ジョブの進行を1回の呼び出しで報告します。
kleo_wait_for_video レンダリングを待ち、フィルムが完成するまで進行を報告します。
kleo_get_result 完成したフィルムへのリンクを返します。
kleo_cancel_job レンダリングを止め、未使用分のクレジットを返金します。
kleo_list_templates 唯一のワークフローであるフィルムを、そのフォーマット、長さ、声、そしてアカウントの残りクレジットとともに一覧します。アニマティックは同じワークフローの製品です。
kleo_account クレジット、アカウントが支払い済みかどうか（has_paid、フィルムを注文できるかを決めます）、アカウントページへのリンク、非公開のKleoキーを表示します。
kleo_generate_thumbnail ベータ版ではまだ利用できません。

正確な引数はライブサーバーのツールスキーマを参照してください。クライアントがツール呼び出しの実行時間を制限している場合、アシスタントはkleo_get_jobをポーリングでき、kleo_wait_for_videoを開いたままにする必要はありません。

03パラメータ

レンダリングに必要なもの。

kleo_create_videoは、あなたの言葉による依頼と、インテークで尋ねられた選択を受け取ります。トリートメントと絵コンテは2つの企画ツールから来るもので、あなたが打ち込むものではありません。

  • promptユーザー自身の言葉による依頼。
  • productfilm（デフォルト。すべてのショットが生成クリップ、長さで価格が決まり、パックを購入したアカウント向け）またはanimatic（描かれたフレームの上をカメラが動く、生成クリップなし、一律5クレジット、15〜60秒、すべてのアカウント向け）。
  • duration_sフィルムは15〜300秒、アニマティックは15〜60秒。
  • formatYouTubeや横型なら16:9、ショートや縦型なら9:16。
  • stylerealistic（シネマティックな生成実写映像）またはanimation（2Dアニメーションのフィルム）。フィルムでは各ショットがそれぞれのフレームから動く映像として生成され、アニマティックでは描かれたフレームにそのルックが保たれます。
  • languageenまたはitのナレーション。ひとりのナレーター。標準のフィルムには音楽、字幕、画面上のテキストはありません。
  • voice任意: narrator-en-m、narrator-en-f、narrator-it-m、narrator-it-fのいずれか。
  • treatment任意: kleo_adapt_promptが返したトリートメント（ログライン、切り口、オープニング、幕構成、結末、ルック、テンポ、ナレーター）。
  • storyboard任意: kleo_storyboard_guideに従って書かれた絵コンテ（演出ブロック、シーン、ショット、制限）。

価格

フィルム: 1クレジットで2秒（切り上げ）、最低10クレジット。15秒 = 10 · 20秒 = 10 · 30秒 = 15 · 60秒 = 30 · 90秒 = 45 · 3分 = 90 · 5分 = 150。アニマティック: 一律5クレジット、15〜60秒。接続すると7クレジットが付き、アニマティック1本分。フィルムはパックを購入したアカウントだけに作られます（クリップはKleoの費用負担で生成されるため、無料クレジットでフィルムが作れることはありません）。7 + €5のパック = 17でフィルムが開放され、30秒のショートが作れます。パックはユーロ建ての一回払いで、定期課金なし: €5 = 10クレジット · €15 = 35 · €40 = 100。

ジョブが受け付けられるまで課金されません

kleo_create_videoはまず正確なクレジット数を答えます。拒否された呼び出しには課金されず、kleo_cancel_jobは停止したレンダリングの未使用分クレジットを返金します。

レンダリング時間

フィルムはレンタルしたGPU上で通常25〜35分、アニマティックは15〜20分ほど。サーバーがジョブの見込み時間をアシスタントに伝えます。固定の時間ではありません。

04出力

出力は完成した動画。

MP4を1本: 4K（3840×2160または2160×3840）、60 fps、16:9か9:16、英語かイタリア語のひとりのナレーター付き。フィルムではすべてのショットが動く映像として生成されます。kleo_get_resultがファイルへのリンクをアシスタントに手渡し、リンクは7日間有効です。

KleoがYouTube、TikTok、その他のチャンネルに公開することはなく、標準のフィルムには音楽、字幕、画面上のテキストはありません。サーバーでは実写とアニメーションの2つのルックが稼働中で、ルックのページにそれぞれのサンプルがあります。

05アカウント

アカウントとジョブの扱い。

OAuthトークンとKleoキーはログや公開例に含めないでください。キーは非公開で、キーを持つ人がアカウントの持ち主です。ダッシュボードはありません。アカウントページ（読み取り専用の残高と決済リンク）はアシスタントに頼めば開け、kleo_accountがそれを返します。

レンダリングはクレジットを消費します。kleo_create_videoを実行する前に確認を求め、進行確認やキャンセルにはジョブ識別子を再利用してください。サーバーのコードは公開されています。
