一個影片製作的
MCP 伺服器。

Kleo 向任何 MCP 用戶端提供同一套影片工作流程：需求確認、故事大綱、分鏡、在為該工作租用的 GPU 上渲染，以及一部完成的 4K 60 fps 旁白影片的連結。一位旁白，兩種風格，兩種產品（影片，或同一份分鏡的動態分鏡），15 秒到 5 分鐘。沒有應用程式，也沒有儀表板；助理透過下面的工具完成工作。

01端點

透過 HTTPS 連接。

Kleo 是一個遠端 MCP 伺服器：一個位址，Streamable HTTP 傳輸，OAuth 2.1。在你的 MCP 用戶端設定位址，並在瀏覽器裡完成授權；沒有註冊表單，也沒有密碼。

  • 端點https://mcp.kleooai.com/mcp
  • 傳輸Streamable HTTP；每個用戶端都用同一個位址。
  • 驗證OAuth 2.1。授權過程中，用戶端會開啟 Kleo 自己的頁面；你按下免費開始，就回到用戶端，帳戶裡有 7 點數。沒有表單、沒有信用卡。
  • 沒有權杖時對端點發出 GET 會回應 401，並附帶 OAuth 資源中繼資料。它是協定端點，不是網頁：在瀏覽器裡開啟它並不是連接流程。
  • 用戶端Claude、ChatGPT、Grok、Claude Code、Cursor、VS Code、OpenCode、Gemini CLI、Windsurf、Gemini 應用程式，以及任何搭配 HTTP 傳輸的 MCP SDK。

02工作流程

製作順序。

工具依固定順序執行。助理讀取你的請求，從 kleo_adapt_prompt 取得故事大綱，依 kleo_storyboard_guide 寫出分鏡，然後才要求 Kleo 渲染。

kleo 工具，依助理執行的順序

工具 功能
kleo_adapt_prompt 用確認清單核對請求（主題、長度、格式、風格；選填的受眾、語氣、必須出現的東西），詢問缺少的部分，然後回傳故事大綱：主軸、切入角度、開場、幕次、結局、風格、節奏、旁白。
kleo_storyboard_guide 說明分鏡怎麼寫：執導方向、場景、鏡頭和限制。
kleo_create_video 檢查全部內容，明示確切的點數，然後在為該工作租用的 GPU 上開始渲染。接受 product: "film" 或 "animatic"。
kleo_get_job 以單次呼叫回報一個工作的進度。
kleo_wait_for_video 等待渲染並回報進度，直到影片就緒。
kleo_get_result 回傳完成影片的連結。
kleo_cancel_job 停止渲染，退回尚未用掉的點數。
kleo_list_templates 列出唯一的工作流程「影片」，及其格式、長度和聲音，還有帳戶剩餘的點數。動態分鏡是同一套工作流程的產品。
kleo_account 顯示點數、帳戶是否已付費（has_paid，決定能否訂製影片）、帳戶頁面的連結，以及私密的 Kleo 金鑰。
kleo_generate_thumbnail 測試版尚未提供。

確切的參數請以線上伺服器的工具結構描述為準。如果你的用戶端限制工具呼叫的執行時間，助理可以輪詢 kleo_get_job，而不是一直掛著 kleo_wait_for_video。

03參數

渲染需要什麼。

kleo_create_video 接收你以自己的話寫的請求，加上確認清單問到的選項。故事大綱和分鏡來自兩個規劃工具，不是來自你的鍵盤。

  • prompt使用者以自己的話寫的請求。
  • productfilm（預設：每個鏡頭都是生成的片段，依長度計價，限已購買點數包的帳戶）或 animatic（手繪畫格在移動的鏡頭下呈現，沒有生成的片段，固定 5 點數，15 到 60 秒，所有帳戶皆可）。
  • duration_s影片 15 到 300 秒，動態分鏡 15 到 60 秒。
  • format16:9 用於 YouTube 和橫式，9:16 用於 Shorts 和直式。
  • stylerealistic（生成的實景影像，電影感）或 animation（2D 動畫影片）。影片裡的每個鏡頭都是從各自的畫格生成的動態影像；動態分鏡則把風格保留在手繪畫格裡。
  • languageen 或 it 旁白。一位旁白；標準影片沒有音樂、沒有字幕、沒有畫面文字。
  • voice選填：narrator-en-m、narrator-en-f、narrator-it-m 或 narrator-it-f。
  • treatment選填：kleo_adapt_prompt 回傳的故事大綱（主軸、切入角度、開場、幕次、結局、風格、節奏、旁白）。
  • storyboard選填：依 kleo_storyboard_guide 寫出的分鏡（執導方向、場景、鏡頭、限制）。

價格

影片：一點數是兩秒，無條件進位，最少十點數：15 秒 = 10 · 20 秒 = 10 · 30 秒 = 15 · 60 秒 = 30 · 90 秒 = 45 · 3 分鐘 = 90 · 5 分鐘 = 150。動態分鏡：固定 5 點數，15 到 60 秒。連接即含 7 點數，一支動態分鏡；影片只為已購買點數包的帳戶製作（片段由 Kleo 出資生成，所以免費點數永遠買不到影片）：7 + €5 點數包 = 17，影片開放，一支 30 秒的 Shorts。點數包一次付清，以歐元計價，不必訂閱：€5 = 10 點數 · €15 = 35 · €40 = 100。

工作被接受之前不扣任何費用

kleo_create_video 會先回覆確切的點數；被拒絕的呼叫不會扣費，kleo_cancel_job 會退回已停止的渲染尚未用掉的點數。

渲染時間

影片在租用的 GPU 上通常需要 25–35 分鐘，動態分鏡約 15–20 分鐘；伺服器會把該工作的預估時間告訴助理。這不是固定的時間。

04輸出

輸出是一部完成的影片。

一個 MP4：4K（3840×2160 或 2160×3840）、60 fps，16:9 或 9:16，一位英語或義大利語的旁白，而且在影片裡，每個鏡頭都生成為動態影像。kleo_get_result 把檔案連結交給助理；連結 7 天內有效。

Kleo 絕不會發布到 YouTube、TikTok 或任何頻道，而標準影片沒有音樂、沒有字幕、沒有畫面文字。伺服器上有兩種風格，寫實和動畫；網站的風格頁各有一部範例。

05帳戶

帳戶與工作處理。

請讓 OAuth 權杖和 Kleo 金鑰遠離日誌和公開範例：金鑰是私密的，誰持有它，誰就擁有帳戶。沒有儀表板；帳戶頁面（唯讀的餘額和結帳連結）透過詢問助理取得，由 kleo_account 回傳。

渲染會花點數：在 kleo_create_video 執行前先請求確認，查詢進度或取消時重複使用同一個工作識別碼。伺服器程式碼是公開的。
