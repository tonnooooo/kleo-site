Kleo — это удалённый MCP-сервер. Он говорит на Model Context Protocol по Streamable HTTP с OAuth 2.1, поэтому один и тот же адрес работает в любом клиенте, а подключение — это одна кнопка на странице Kleo: без формы регистрации, без пароля, без карты. Начало бесплатно: 7 кредитов на счету в момент подключения — один аниматик. Добавьте Kleo в свой ассистент и опишите фильм, который хотите сделать.

01Подключение

Выберите свой ассистент.

Каждый клиент ниже использует один и тот же адрес и один и тот же старт в одну кнопку: вставляете адрес, открывается страница Kleo, вы нажимаете Start free — и вы снова в клиенте с 7 кредитами на счету. Вот шаги, которые мы проверили.

Claude приложение · веб

Адрес сервера https://mcp.kleooai.com/mcp
  1. Откройте Settings → Connectors и выберите Add custom connector.
  2. Назовите его Kleo, вставьте адрес выше и подтвердите. Откроется страница Kleo: нажмите Start free — и вы снова в Claude.
  3. В новом чате включите Kleo в меню инструментов и попросите: Сделай мне 45-секундный Short о…

Бесплатный тариф Claude допускает один пользовательский коннектор.

ChatGPT режим разработчика

Адрес сервера https://mcp.kleooai.com/mcp
  1. Откройте Settings → Apps & Connectors (в старых версиях — Connectors), затем Advanced settings и включите Developer mode.
  2. Вернитесь в Connectors и выберите Create: назовите его Kleo, вставьте адрес, выберите аутентификацию OAuth и сохраните. Откроется страница Kleo: нажмите Start free — и вы снова в ChatGPT.
  3. В чате включите Kleo в меню + и попросите видео. ChatGPT запросит подтверждение перед запуском рендера.

Требуется ChatGPT Plus, Pro, Business или Enterprise.

Grok коннекторы

Адрес сервера https://mcp.kleooai.com/mcp
  1. На grok.com или в приложении откройте Settings → Connectors и выберите Add connector → Custom.
  2. Назовите его Kleo, вставьте адрес и подтвердите. Откроется страница Kleo: нажмите Start free — и вы снова в Grok.
  3. В чате включите Kleo в списке коннекторов и попросите видео.

Claude Code cli

# добавьте Kleo один раз (добавьте --scope user, чтобы он был в каждом проекте) claude mcp add --transport http kleo https://mcp.kleooai.com/mcp # затем, внутри сессии: /mcp → Kleo → Authenticate
  1. Выполните команду выше, затем введите /mcp в сессии, выберите Kleo и Authenticate: в браузере откроется страница Kleo, нажмите Start free — и вы снова в Claude Code.
  2. Попросите: Используй kleo для 5-минутного видео об истории кофе, 16:9. Claude Code сам следит за прогрессом и передаёт вам ссылки.

Cursor mcp.json

Создайте или отредактируйте ~/.cursor/mcp.json (все проекты) или .cursor/mcp.json внутри одного проекта.

{ "mcpServers": { "kleo": { "url": "https://mcp.kleooai.com/mcp" } } }
  1. Сохраните файл: Cursor покажет Kleo в Settings → MCP. Нажмите Connect (или один раз вызовите любой инструмент): откроется страница Kleo, нажмите Start free — и вы снова в Cursor.

VS Code mcp.json

Создайте .vscode/mcp.json в своём рабочем пространстве (или выполните MCP: Add Server из палитры команд и вставьте адрес).

{ "servers": { "kleo": { "type": "http", "url": "https://mcp.kleooai.com/mcp" } } }
  1. Сохраните файл, затем нажмите Start над записью сервера. VS Code откроет страницу Kleo: нажмите Start free — и вы снова в VS Code.
  2. В Copilot Chat переключитесь в режим Agent: инструменты kleo появятся в списке инструментов.

OpenCode opencode.jsonc

Добавьте это в ~/.config/opencode/opencode.jsonc (глобально) или в opencode.jsonc в проекте, затем подключитесь из терминала.

{ "mcp": { "kleo": { "type": "remote", "url": "https://mcp.kleooai.com/mcp", "enabled": true } } }
# подключитесь один раз (откроется браузер) opencode mcp auth kleo
  1. Сохраните конфигурацию и выполните команду выше: в браузере откроется страница Kleo, нажмите Start free — и вы снова в OpenCode.
  2. Запустите opencode и попросите видео: инструменты kleo доступны в каждой сессии.

Gemini CLI cli

# добавьте Kleo (добавьте --scope user, чтобы он был в каждом проекте) gemini mcp add --transport http kleo https://mcp.kleooai.com/mcp
  1. Выполните команду выше, затем запустите gemini и введите /mcp auth kleo: в браузере откроется страница Kleo, нажмите Start free — и вы снова в Gemini CLI.
  2. Попросите видео в сессии. /mcp list показывает все инструменты kleo.

Windsurf, приложение Gemini и ваши собственные агенты http

Kleo — стандартный MCP-сервер на транспорте Streamable HTTP с OAuth 2.1. Любой совместимый клиент подключается по тому же адресу с тем же стартом в одну кнопку.

Адрес сервера https://mcp.kleooai.com/mcp
  1. Windsurf: Settings → MCP → Add server, вставьте адрес (в его mcp_config.json используется ключ "serverUrl").
  2. Приложение Gemini: Settings → Connected apps → Custom apps, вставьте адрес (сейчас требуется Google AI Pro или Ultra).
  3. Для собственного агента: используйте MCP SDK (Python или TypeScript) с HTTP-транспортом и один раз пройдите OAuth.

02Первый запрос

Начните с ясного запроса.

Ассистент сверяет ваш запрос с интейком Kleo — тема, длительность, формат, стиль — и спрашивает всё, чего не хватает, прежде чем писать тритмент. Назовите все четыре пункта, и он сразу возьмётся за работу. Вставьте это в свой первый чат:

«Используй Kleo, чтобы спланировать 30-секундный фильм о смотрителе маяка, который находит письмо в бутылке. Реалистичный стиль, закадровый голос на английском, 9:16. Покажи мне план и стоимость в кредитах до рендера».

На сервере доступны два стиля: реалистичный — сгенерированный игровой футаж, и анимация — 2D-анимационный фильм. Замените слово в промпте, чтобы получить другой.

03Кредиты

Проверьте баланс до запуска производства.

Подключение даёт 7 кредитов: аниматик вашей раскадровки стоит 5, и заказать его может любой аккаунт. Фильм делается только для аккаунтов, купивших пакет — любой пакет, — а 30-секундный фильм стоит 15 кредитов, поэтому первый фильм начинается с пакета за €5: 7 + 10 = 17 кредитов, хватает на 30-секундный Short.

Попросите у ассистента страницу своего аккаунта, чтобы купить кредиты, затем подтвердите, когда захотите запустить рендер. Ничего не списывается, пока Kleo не примет задачу: ассистент сначала называет точное число кредитов, а отклонённый запрос ничего не стоит.
