# Gatto — landing page

Static single-file site for Gatto, an MCP server that renders YouTube videos and Shorts from inside Claude, ChatGPT, Grok and Cursor. Served by GitHub Pages; no build step.

- Edit `index.html`, push to `main`, the site updates within a few minutes.
- Brand name and domain are placeholders: search for `Gatto` / `gatto` and `mcp.gatto.ai`.
