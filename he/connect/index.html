האולפן שלכם.

Kleo הוא שרת MCP מרוחק. הוא מדבר Model Context Protocol על גבי Streamable HTTP עם OAuth 2.1, ולכן אותה כתובת עובדת בכל לקוח, והחיבור הוא כפתור אחד בעמוד של Kleo עצמו — בלי טופס הרשמה, בלי סיסמה, בלי כרטיס. מתחילים בחינם: 7 קרדיטים בחשבון ברגע החיבור, אנימטיק אחד. הוסיפו אותו לעוזר שלכם ותארו את הסרט שאתם רוצים ליצור.

01חיבור

בחרו את העוזר שלכם.

כל לקוח שלמטה משתמש באותה כתובת ובאותה התחלה בכפתור אחד: מדביקים את הכתובת, העמוד של Kleo נפתח, לוחצים Start free, וחוזרים ללקוח עם 7 קרדיטים בחשבון. אלה השלבים שבדקנו.

Claude אפליקציה · דפדפן

כתובת השרת https://mcp.kleooai.com/mcp
  1. פתחו Settings → Connectors ובחרו Add custom connector.
  2. קראו לו Kleo, הדביקו את הכתובת שלמעלה ואשרו. העמוד של Kleo נפתח: לחצו Start free ואתם חוזרים ל-Claude.
  3. בצ'אט חדש, הפעילו את Kleo מתפריט הכלים ובקשו: תכין לי Short של 45 שניות על…

התוכנית החינמית של Claude מאפשרת מחבר מותאם אישית אחד.

המדריך המלא ל-Claude →

ChatGPT מצב מפתחים

כתובת השרת https://mcp.kleooai.com/mcp
  1. פתחו Settings → Apps & Connectors (בגרסאות ישנות יותר: Connectors), ואז Advanced settings, והפעילו את Developer mode.
  2. בחזרה ב-Connectors, בחרו Create: קראו לו Kleo, הדביקו את הכתובת, הגדירו את האימות ל-OAuth ושמרו. העמוד של Kleo נפתח: לחצו Start free ואתם חוזרים ל-ChatGPT.
  3. בצ'אט, הפעילו את Kleo מתפריט + ובקשו את הסרטון. ChatGPT מבקש מכם אישור לפני שהוא מתחיל רינדור.

דורש ChatGPT Plus, Pro, Business או Enterprise.

Grok מחברים

כתובת השרת https://mcp.kleooai.com/mcp
  1. ב-grok.com או באפליקציה, פתחו Settings → Connectors ובחרו Add connector → Custom.
  2. קראו לו Kleo, הדביקו את הכתובת ואשרו. העמוד של Kleo נפתח: לחצו Start free ואתם חוזרים ל-Grok.
  3. בצ'אט, הפעילו את Kleo ברשימת המחברים ובקשו את הסרטון.

Claude Code cli

# הוסיפו את Kleo פעם אחת (הוסיפו --scope user כדי שיהיה בכל פרויקט) claude mcp add --transport http kleo https://mcp.kleooai.com/mcp # ואז, בתוך סשן: /mcp → Kleo → Authenticate
  1. הריצו את הפקודה שלמעלה, ואז הקלידו /mcp בסשן, בחרו Kleo ו-Authenticate: העמוד של Kleo נפתח בדפדפן שלכם, לחצו Start free ואתם חוזרים ל-Claude Code.
  2. בקשו: השתמש ב-kleo לסרטון של 5 דקות על ההיסטוריה של הקפה, 16:9. Claude Code בודק בשבילכם את ההתקדמות ומוסר לכם את הקישורים.

Cursor mcp.json

צרו או ערכו את ~/.cursor/mcp.json (כל הפרויקטים) או את .cursor/mcp.json בתוך פרויקט אחד.

{ "mcpServers": { "kleo": { "url": "https://mcp.kleooai.com/mcp" } } }
  1. שמרו את הקובץ: Cursor מציג את Kleo תחת Settings → MCP. לחצו Connect (או השתמשו בכלי פעם אחת): העמוד של Kleo נפתח, לחצו Start free ואתם חוזרים ל-Cursor.

VS Code mcp.json

צרו .vscode/mcp.json בסביבת העבודה שלכם (או הריצו MCP: Add Server מה-Command Palette והדביקו את הכתובת).

{ "servers": { "kleo": { "type": "http", "url": "https://mcp.kleooai.com/mcp" } } }
  1. שמרו את הקובץ, ואז לחצו Start מעל רשומת השרת. VS Code פותח את העמוד של Kleo: לחצו Start free ואתם חוזרים ל-VS Code.
  2. ב-Copilot Chat, עברו למצב Agent: הכלים של kleo מופיעים בבורר הכלים.

OpenCode opencode.jsonc

הוסיפו את זה ל-~/.config/opencode/opencode.jsonc (גלובלי) או ל-opencode.jsonc בפרויקט, ואז התחברו מהטרמינל.

{ "mcp": { "kleo": { "type": "remote", "url": "https://mcp.kleooai.com/mcp", "enabled": true } } }
# התחברו פעם אחת (פותח את הדפדפן) opencode mcp auth kleo
  1. שמרו את ההגדרות והריצו את הפקודה שלמעלה: העמוד של Kleo נפתח בדפדפן, לחצו Start free ואתם חוזרים ל-OpenCode.
  2. הפעילו את opencode ובקשו את הסרטון: הכלים של kleo זמינים בכל סשן.

Gemini CLI cli

# הוסיפו את Kleo (הוסיפו --scope user כדי שיהיה בכל פרויקט) gemini mcp add --transport http kleo https://mcp.kleooai.com/mcp
  1. הריצו את הפקודה שלמעלה, ואז הפעילו את gemini והקלידו /mcp auth kleo: העמוד של Kleo נפתח בדפדפן שלכם, לחצו Start free ואתם חוזרים ל-Gemini CLI.
  2. בקשו את הסרטון בסשן. /mcp list מציג את כל הכלים של kleo.

Windsurf, אפליקציית Gemini והסוכנים שלכם http

Kleo הוא שרת MCP סטנדרטי על גבי תעבורת Streamable HTTP עם OAuth 2.1. כל לקוח תואם מתחבר באותה כתובת ובאותה התחלה בכפתור אחד.

כתובת השרת https://mcp.kleooai.com/mcp
  1. Windsurf: Settings → MCP → Add server, הדביקו את הכתובת (קובץ ה-mcp_config.json שלו משתמש במפתח "serverUrl").
  2. אפליקציית Gemini: Settings → Connected apps → Custom apps, הדביקו את הכתובת (כרגע דורש Google AI Pro או Ultra).
  3. לסוכן משלכם: השתמשו ב-MCP SDK (Python או TypeScript) עם תעבורת HTTP והשלימו את תהליך ה-OAuth פעם אחת.

02בקשה ראשונה

התחילו בבקשה ברורה.

העוזר קורא את הבקשה שלכם מול האינטייק של Kleo — נושא, אורך, פורמט, מראה — ושואל על כל מה שחסר לפני שהוא כותב את הטריטמנט. ציינו את כל הארבעה והוא ניגש ישר לעבודה. הדביקו את זה בצ'אט הראשון שלכם:

„השתמש ב-Kleo כדי לתכנן סרט של 30 שניות על שומר מגדלור שמגלה הודעה בבקבוק. מראה ריאליסטי, קריינות באנגלית, 9:16. הצג לי את המתווה ואת העלות בקרדיטים לפני הרינדור.”

שני מראות זמינים בשרת: ריאליסטי, פוטג' לייב-אקשן מיוצר, ואנימציה, סרט אנימציה דו-ממדי. החליפו את המילה בפרומפט כדי לקבל את השני.

03קרדיטים

בדקו את היתרה לפני ההפקה.

החיבור כולל 7 קרדיטים: אנימטיק של הסטוריבורד שלכם עולה 5 וכל חשבון יכול להזמין אחד. סרט נעשה רק לחשבונות שרכשו חבילה, כל חבילה, וסרט של 30 שניות עולה 15 קרדיטים, ולכן הסרט הראשון מתחיל בחבילת ה-€5: 7 + 10 = 17 קרדיטים, מספיק ל-Short של 30 שניות.

בקשו מהעוזר את עמוד החשבון שלכם כדי לרכוש קרדיטים, ואז אשרו כשתרצו שהרינדור יתחיל. שום דבר לא מחויב עד ש-Kleo מקבל את המשימה: העוזר מציין קודם את מספר הקרדיטים המדויק, ובקשה שנדחתה לא עולה דבר.
