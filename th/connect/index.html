Kleo คือเซิร์ฟเวอร์ MCP ระยะไกล ใช้ Model Context Protocol ผ่าน Streamable HTTP พร้อม OAuth 2.1 ที่อยู่เดียวกันจึงใช้ได้กับทุกไคลเอนต์ และการเชื่อมต่อคือปุ่มเดียวบนหน้าของ Kleo เอง ไม่มีแบบฟอร์มลงทะเบียน ไม่มีรหัสผ่าน ไม่ต้องใช้บัตร เริ่มต้นฟรี: รับ 7 เครดิตในบัญชีทันทีที่เชื่อมต่อ แอนิเมติกหนึ่งเรื่อง เพิ่ม Kleo ในผู้ช่วย AI ของคุณแล้วบรรยายภาพยนตร์ที่คุณอยากทำ

01เชื่อมต่อ

เลือกผู้ช่วย AI ของคุณ

ทุกไคลเอนต์ด้านล่างใช้ที่อยู่เดียวกันและการเริ่มต้นแบบปุ่มเดียวเหมือนกัน: วางที่อยู่ หน้าของ Kleo จะเปิดขึ้น คุณคลิก Start free แล้วกลับมาที่ไคลเอนต์พร้อม 7 เครดิตในบัญชี นี่คือขั้นตอนที่เราทดสอบแล้ว

Claude แอป · เว็บ

ที่อยู่เซิร์ฟเวอร์ https://mcp.kleooai.com/mcp
  1. เปิด Settings → Connectors แล้วเลือก Add custom connector
  2. ตั้งชื่อว่า Kleo วางที่อยู่ด้านบน แล้วยืนยัน หน้าของ Kleo จะเปิดขึ้น: คลิก Start free แล้วคุณจะกลับมาที่ Claude
  3. ในแชตใหม่ เปิดใช้ Kleo จากเมนูเครื่องมือแล้วถามว่า: ทำ Short ความยาว 45 วินาทีให้หน่อย เรื่อง…

แผนฟรีของ Claude อนุญาตให้มีตัวเชื่อมต่อแบบกำหนดเองได้หนึ่งตัว

ChatGPT โหมดนักพัฒนา

ที่อยู่เซิร์ฟเวอร์ https://mcp.kleooai.com/mcp
  1. เปิด Settings → Apps & Connectors (ในเวอร์ชันเก่าเรียกว่า Connectors) จากนั้นไปที่ Advanced settings แล้วเปิด Developer mode
  2. กลับมาที่ Connectors เลือก Create: ตั้งชื่อว่า Kleo วางที่อยู่ ตั้งค่าการยืนยันตัวตนเป็น OAuth แล้วบันทึก หน้าของ Kleo จะเปิดขึ้น: คลิก Start free แล้วคุณจะกลับมาที่ ChatGPT
  3. ในแชต เปิดใช้ Kleo จากเมนู + แล้วขอวิดีโอได้เลย ChatGPT จะขอให้คุณยืนยันก่อนเริ่มเรนเดอร์

ต้องใช้ ChatGPT Plus, Pro, Business หรือ Enterprise

คู่มือ ChatGPT ฉบับเต็ม →

Grok ตัวเชื่อมต่อ

ที่อยู่เซิร์ฟเวอร์ https://mcp.kleooai.com/mcp
  1. บน grok.com หรือในแอป เปิด Settings → Connectors แล้วเลือก Add connector → Custom
  2. ตั้งชื่อว่า Kleo วางที่อยู่ แล้วยืนยัน หน้าของ Kleo จะเปิดขึ้น: คลิก Start free แล้วคุณจะกลับมาที่ Grok
  3. ในแชต เปิดใช้ Kleo ในรายการตัวเชื่อมต่อแล้วขอวิดีโอได้เลย

Claude Code cli

# เพิ่ม Kleo ครั้งเดียว (เพิ่ม --scope user เพื่อให้ใช้ได้ในทุกโปรเจกต์) claude mcp add --transport http kleo https://mcp.kleooai.com/mcp # จากนั้น ภายในเซสชัน: /mcp → Kleo → Authenticate
  1. รันคำสั่งด้านบน จากนั้นพิมพ์ /mcp ในเซสชัน เลือก Kleo แล้ว Authenticate: หน้าของ Kleo จะเปิดในเบราว์เซอร์ คลิก Start free แล้วคุณจะกลับมาที่ Claude Code
  2. ถามว่า: ใช้ kleo ทำวิดีโอ 5 นาทีเรื่องประวัติของกาแฟ 16:9 Claude Code ตรวจความคืบหน้าให้คุณและส่งลิงก์ให้

Cursor mcp.json

สร้างหรือแก้ไข ~/.cursor/mcp.json (ทุกโปรเจกต์) หรือ .cursor/mcp.json ภายในโปรเจกต์เดียว

{ "mcpServers": { "kleo": { "url": "https://mcp.kleooai.com/mcp" } } }
  1. บันทึกไฟล์: Cursor จะแสดง Kleo ใน Settings → MCP คลิก Connect (หรือใช้เครื่องมือหนึ่งครั้ง): หน้าของ Kleo จะเปิดขึ้น คลิก Start free แล้วคุณจะกลับมาที่ Cursor

VS Code mcp.json

สร้าง .vscode/mcp.json ในเวิร์กสเปซของคุณ (หรือรัน MCP: Add Server จาก Command Palette แล้ววางที่อยู่)

{ "servers": { "kleo": { "type": "http", "url": "https://mcp.kleooai.com/mcp" } } }
  1. บันทึกไฟล์ แล้วคลิก Start เหนือรายการเซิร์ฟเวอร์ VS Code จะเปิดหน้าของ Kleo: คลิก Start free แล้วคุณจะกลับมาที่ VS Code
  2. ใน Copilot Chat สลับไปโหมด Agent: เครื่องมือ kleo จะปรากฏในตัวเลือกเครื่องมือ

OpenCode opencode.jsonc

เพิ่มสิ่งนี้ใน ~/.config/opencode/opencode.jsonc (ส่วนกลาง) หรือใน opencode.jsonc ของโปรเจกต์ แล้วเชื่อมต่อจากเทอร์มินัล

{ "mcp": { "kleo": { "type": "remote", "url": "https://mcp.kleooai.com/mcp", "enabled": true } } }
# เชื่อมต่อครั้งเดียว (เปิดเบราว์เซอร์) opencode mcp auth kleo
  1. บันทึกการตั้งค่าแล้วรันคำสั่งด้านบน: หน้าของ Kleo จะเปิดในเบราว์เซอร์ คลิก Start free แล้วคุณจะกลับมาที่ OpenCode
  2. เริ่ม opencode แล้วขอวิดีโอ: เครื่องมือ kleo พร้อมใช้ในทุกเซสชัน

Gemini CLI cli

# เพิ่ม Kleo (เพิ่ม --scope user เพื่อให้ใช้ได้ในทุกโปรเจกต์) gemini mcp add --transport http kleo https://mcp.kleooai.com/mcp
  1. รันคำสั่งด้านบน จากนั้นเริ่ม gemini แล้วพิมพ์ /mcp auth kleo: หน้าของ Kleo จะเปิดในเบราว์เซอร์ คลิก Start free แล้วคุณจะกลับมาที่ Gemini CLI
  2. ขอวิดีโอในเซสชันได้เลย /mcp list แสดงเครื่องมือ kleo ทั้งหมด

Windsurf แอป Gemini และเอเจนต์ของคุณเอง http

Kleo คือเซิร์ฟเวอร์ MCP มาตรฐานผ่านทรานสปอร์ต Streamable HTTP พร้อม OAuth 2.1 ไคลเอนต์ที่รองรับทุกตัวเชื่อมต่อด้วยที่อยู่เดียวกันและการเริ่มต้นแบบปุ่มเดียวเหมือนกัน

ที่อยู่เซิร์ฟเวอร์ https://mcp.kleooai.com/mcp
  1. Windsurf: Settings → MCP → Add server วางที่อยู่ (ไฟล์ mcp_config.json ของมันใช้คีย์ "serverUrl")
  2. แอป Gemini: Settings → Connected apps → Custom apps วางที่อยู่ (ปัจจุบันต้องใช้ Google AI Pro หรือ Ultra)
  3. สำหรับเอเจนต์ของคุณเอง: ใช้ MCP SDK (Python หรือ TypeScript) กับทรานสปอร์ต HTTP และทำขั้นตอน OAuth ให้เสร็จครั้งเดียว

02คำขอแรก

เริ่มด้วยคำขอที่ชัดเจน

ผู้ช่วย AI อ่านคำขอของคุณเทียบกับรายการรับบรีฟของ Kleo — หัวข้อ ความยาว รูปแบบ ลุค — และถามสิ่งที่ขาดไปก่อนเขียนทรีตเมนต์ ระบุครบทั้งสี่แล้วมันจะเริ่มงานทันที วางข้อความนี้ในแชตแรกของคุณ:

“ใช้ Kleo วางแผนภาพยนตร์ 30 วินาที เรื่องผู้ดูแลประภาคารที่พบจดหมายในขวด ลุคสมจริง เสียงบรรยายภาษาอังกฤษ 9:16 แสดงโครงเรื่องและจำนวนเครดิตให้ดูก่อนเรนเดอร์”

เซิร์ฟเวอร์มีสองลุคให้เลือก: สมจริง ฟุตเทจไลฟ์แอ็กชันที่สร้างขึ้น และ แอนิเมชัน ภาพยนตร์แอนิเมชัน 2D เปลี่ยนคำในพรอมต์เพื่อรับอีกลุคหนึ่ง

03เครดิต

ตรวจยอดคงเหลือก่อนผลิต

การเชื่อมต่อรวม 7 เครดิต: แอนิเมติกจากสตอรีบอร์ดของคุณราคา 5 เครดิต และทุกบัญชีสั่งได้ ภาพยนตร์ทำให้เฉพาะบัญชีที่ซื้อแพ็กแล้ว แพ็กใดก็ได้ และภาพยนตร์ 30 วินาทีราคา 15 เครดิต ภาพยนตร์เรื่องแรกจึงเริ่มด้วยแพ็ก €5: 7 + 10 = 17 เครดิต พอสำหรับ Short ความยาว 30 วินาที

ขอหน้าบัญชีจากผู้ช่วย AI เพื่อซื้อเครดิต แล้วยืนยันเมื่อคุณต้องการให้เริ่มเรนเดอร์ จะไม่เรียกเก็บอะไรเลยจนกว่า Kleo จะรับงาน: ผู้ช่วยแจ้งจำนวนเครดิตที่แน่นอนก่อน และคำขอที่ถูกปฏิเสธไม่มีค่าใช้จ่าย
