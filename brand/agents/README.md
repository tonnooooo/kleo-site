# Assistant marks

Monochrome SVGs sourced from https://github.com/lobehub/lobe-icons/tree/master/packages/static-svg/icons on 2026-09-23. See LICENSE for the source project's license. Brand marks remain the property of their respective owners; these marks identify client setup instructions, not partnerships or endorsements. OpenAI's mark identifies ChatGPT and Codex; Claude's mark identifies Claude and Claude Code.

Local assets use CSS masks to inherit the site's existing light/dark palette. No external logo requests or tracking.
