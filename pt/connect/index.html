O seu chat.
O seu estúdio.

O Kleo é um servidor MCP remoto. Ele fala o Model Context Protocol por Streamable HTTP com OAuth 2.1, então o mesmo endereço funciona em todos os clientes, e conectar é um único botão na própria página do Kleo — sem formulário de cadastro, sem senha, sem cartão. É grátis para começar: 7 créditos na sua conta no momento em que você conecta, um animatic. Adicione-o ao seu assistente e descreva o filme que quer fazer.

01Conectar

Escolha o seu assistente.

Todos os clientes abaixo usam o mesmo endereço e o mesmo início com um botão: cole o endereço, a página do Kleo abre, você clica em Começar grátis e volta ao cliente com 7 créditos na conta. Estes são os passos que testamos.

Claude app · web

Endereço do servidor https://mcp.kleooai.com/mcp
  1. Abra Configurações → Conectores e escolha Adicionar conector personalizado.
  2. Dê o nome Kleo, cole o endereço acima e confirme. A página do Kleo abre: clique em Começar grátis e você volta ao Claude.
  3. Em um novo chat, ative o Kleo no menu de ferramentas e peça: Faça um Short de 45 segundos sobre…

ChatGPT modo desenvolvedor

Endereço do servidor https://mcp.kleooai.com/mcp
  1. Abra Configurações → Apps & Conectores (chamado Conectores em versões anteriores), depois Configurações avançadas, e ative o Modo desenvolvedor.
  2. De volta em Conectores, escolha Criar: dê o nome Kleo, cole o endereço, defina a autenticação como OAuth e salve. A página do Kleo abre: clique em Começar grátis e você volta ao ChatGPT.
  3. No chat, ative o Kleo no menu + e peça o vídeo. O ChatGPT pede a sua confirmação antes de iniciar um render.

Claude Code cli

# adicione o Kleo uma vez (adicione --scope user para tê-lo em todos os projetos) claude mcp add --transport http kleo https://mcp.kleooai.com/mcp # depois, dentro de uma sessão: /mcp → Kleo → Authenticate
  1. Execute o comando acima, depois digite /mcp numa sessão, escolha Kleo e Authenticate: a página do Kleo abre no seu navegador, clique em Começar grátis e você volta ao Claude Code.
  2. Peça: Use o kleo para um vídeo de 5 minutos sobre a história do café, 16:9. O Claude Code acompanha o progresso por você e entrega os links.

Cursor mcp.json

Crie ou edite ~/.cursor/mcp.json (todos os projetos) ou .cursor/mcp.json dentro de um projeto.

{ "mcpServers": { "kleo": { "url": "https://mcp.kleooai.com/mcp" } } }
  1. Salve o arquivo: o Cursor lista o Kleo em Settings → MCP. Clique em Connect (ou use uma ferramenta uma vez): a página do Kleo abre, clique em Começar grátis e você volta ao Cursor.

VS Code mcp.json

Crie .vscode/mcp.json no seu workspace (ou execute MCP: Add Server na Command Palette e cole o endereço).

{ "servers": { "kleo": { "type": "http", "url": "https://mcp.kleooai.com/mcp" } } }
  1. Salve o arquivo e clique em Start acima da entrada do servidor. O VS Code abre a página do Kleo: clique em Começar grátis e você volta ao VS Code.
  2. No Copilot Chat, mude para o modo Agent: as ferramentas kleo aparecem no seletor de ferramentas.

OpenCode opencode.jsonc

Adicione isto a ~/.config/opencode/opencode.jsonc (global) ou a opencode.jsonc no projeto, depois conecte pelo terminal.

{ "mcp": { "kleo": { "type": "remote", "url": "https://mcp.kleooai.com/mcp", "enabled": true } } }
# conecte uma vez (abre o navegador) opencode mcp auth kleo
  1. Salve a configuração e execute o comando acima: a página do Kleo abre no navegador, clique em Começar grátis e você volta ao OpenCode.
  2. Inicie o opencode e peça o vídeo: as ferramentas kleo estão disponíveis em todas as sessões.

Gemini CLI cli

# adicione o Kleo (adicione --scope user para tê-lo em todos os projetos) gemini mcp add --transport http kleo https://mcp.kleooai.com/mcp
  1. Execute o comando acima, depois inicie o gemini e digite /mcp auth kleo: a página do Kleo abre no seu navegador, clique em Começar grátis e você volta ao Gemini CLI.
  2. Peça o vídeo na sessão. /mcp list mostra todas as ferramentas kleo.

Windsurf, o app Gemini e os seus próprios agentes http

O Kleo é um servidor MCP padrão sobre o transporte Streamable HTTP com OAuth 2.1. Qualquer cliente compatível conecta com o mesmo endereço e o mesmo início com um botão.

Endereço do servidor https://mcp.kleooai.com/mcp
  1. Windsurf: Settings → MCP → Add server, cole o endereço (o seu mcp_config.json usa a chave "serverUrl").
  2. App Gemini: Configurações → Apps conectados → Apps personalizados, cole o endereço (atualmente requer Google AI Pro ou Ultra).
  3. Para o seu próprio agente: use um SDK MCP (Python ou TypeScript) com o transporte HTTP e conclua o fluxo OAuth uma vez.

02Primeiro pedido

Comece com um pedido claro.

O assistente lê o seu pedido a partir da triagem do Kleo — assunto, duração, formato, look — e pergunta o que estiver faltando antes de escrever o treatment. Diga os quatro e ele vai direto ao trabalho. Cole isto no seu primeiro chat:

“Use o Kleo para planejar um filme de 30 segundos sobre um faroleiro que descobre uma mensagem numa garrafa. Look realista, narração em inglês, 9:16. Mostre o esboço e o custo em créditos antes de renderizar.”

Dois looks estão disponíveis no servidor: realista, footage live-action gerado, e animação, um filme de animação 2D. Troque a palavra no prompt para obter o outro.

03Créditos

Verifique o seu saldo antes da produção.

Conectar inclui 7 créditos: um animatic do seu storyboard custa 5 e toda conta pode pedir um. Um filme é feito apenas para contas que compraram um pacote, qualquer pacote, e um filme de 30 segundos custa 15 créditos, então o primeiro filme começa com o pacote de €5: 7 + 10 = 17 créditos, o suficiente para um Short de 30 segundos.

Peça ao assistente a página da sua conta para comprar créditos, depois confirme quando quiser que o render comece. Nada é cobrado até o Kleo aceitar o job: o assistente informa primeiro os créditos exatos, e um pedido recusado não custa nada.
