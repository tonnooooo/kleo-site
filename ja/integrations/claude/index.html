動画を作る、
ClaudeとKleoで。

Claudeはあなたがフィルムを演出する場所です。カスタムコネクタとしてClaudeに追加されたKleoが、映像、ナレーション、そして完成した4KのMP4を生成し、リンクは同じチャットに届きます。

Kleoを接続 → サンプルフィルムを見る 設定手順 ↓
01設定

KleoをClaudeに追加する。

KleoはリモートMCPサーバーです。インストールするアプリも登録フォームもありません。Claudeはカスタムコネクタを通じてKleoに接続し、接続はKleo自身のページのボタンひとつで完了します。以下の手順はClaudeアプリでもウェブでも同じで、すべてのClaudeプランで使えます。無料プランではカスタムコネクタを1つ追加できます。

  1. Claudeで設定 → コネクタを開き、カスタムコネクタを追加を選びます。
  2. 名前をKleoにして、下のアドレスを貼り付け、確定します。
  3. Kleoのページが開くので、Start freeをクリックします。Claudeに戻ると、新しいKleoアカウントに7クレジットが入っています。フォームもパスワードもカードも不要で、5クレジットのアニマティック1本分です。フィルムはパックを購入したアカウントだけに作られ、最低10クレジットかかるため、最初のフィルムの前に€5のパック（10クレジット）を追加します。30秒のフィルムは15クレジットです。
  4. 新しいチャットでツールメニューからKleoをオンにして、フィルムを頼みます。
サーバーアドレス https://mcp.kleooai.com/mcp

ClaudeはAnthropicのアシスタントです。KleoはClaudeがカスタムコネクタを通じて接続する別のサービスで、同じアドレスがChatGPT、Grok、Claude Code、Cursor、その他のMCPクライアントでも使えます——接続ページをご覧ください。

02最初のプロンプト

作りたいフィルムを頼む。

題材、長さ、フォーマット、ルックをひとつのメッセージで伝えます。視聴者、トーン、フィルムに必ず入れたいものは任意です。依頼に抜けがあれば、Claudeは企画を始める前に尋ねます。長さ、フォーマット、ルックを勝手に決めることはありません。

「Kleoを使って、夜明けの静かな湖を渡る小さな木のボートについての30秒フィルムを作って。実写ルック、16:9、英語ナレーション、落ち着いたトーンで。レンダリングを始める前にトリートメントと正確なクレジット数を見せて。」

  • ルック2つのルックが使えます。実写はシネマティックな質感の生成された実写映像、アニメーションは2Dアニメーションのフィルムです。フィルムのルックを見る →
  • フォーマットYouTube向けの16:9か、ショート向けの9:16。
  • 長さ15秒から5分まで。
  • ナレーション英語かイタリア語。
03チャットの中で

チャットの中で次に起こること。

Kleoのツールは決まった順序で実行され、Claudeがあなたのために操作します。各ステップであなたが読み、修正し、承認します。あなたがゴーサインを出してジョブが受け付けられるまで、一切課金されません。

01 kleo_adapt_prompt

トリートメント

Claudeがあなたの依頼をKleoのインテークに照らして読み取ります。題材、長さ、フォーマット、ルックは必須。視聴者、トーン、必ず入れたいものは任意です。足りないものはひとつのメッセージで尋ねます。そのうえでトリートメントを見せます。ログライン、切り口、オープニングの画、幕構成、結末、ルック、テンポ、ナレーター。先に進む前に、何でも変えられます。

02 kleo_storyboard_guide

絵コンテ

ClaudeがKleoの絵コンテガイド（演出ブロック、シーン、ショットとその制限）を取得し、あなたが承認したトリートメントのもとで絵コンテを書きます。フィルムはここで作られます。読んで、変更を頼んでください。

03 kleo_create_video

レンダリング

Kleoがすべてを確認し、フィルムの正確なクレジット数を答えます。あなたのOKが出たら、ClaudeがそのジョブのためだけにレンタルしたGPUでレンダリングを開始します。ジョブが受け付けられる前に課金されることはなく、拒否された呼び出しには費用がかかりません。

04 kleo_wait_for_video

リンク

Claudeは進行を報告しながらレンダリングを待ち、Kleoが完成したMP4のリンクを手渡すまで見守ります。通常25〜35分後です。リンクは7日間有効。Kleoがフィルムをどこかに公開することはありません。あなたがダウンロードして、好きな場所に投稿します。

04フィルム

手に入るもの。

  • 出力4K（3840×2160または2160×3840）、60 fpsのMP4。YouTube向けの16:9、ショート向けの9:16。
  • 長さフィルムは15秒から5分、アニマティックは15〜60秒。
  • ルック実写（シネマティックな生成実写映像）かアニメーション（2Dアニメーションのフィルム）。フィルムでは各ショットがそれぞれのフレームから動く映像として生成されます。
  • 製品フィルム、または同じ絵コンテのアニマティック。描かれたフレームの上をカメラが動き、同じナレーターとグラフィックレイヤー、生成クリップなし。アニマティックはすべてのアカウントで注文でき、フィルムはパックを購入したアカウントだけに作られます。
  • ナレーションひとりのナレーター、英語かイタリア語。BGMなし、字幕なし、画面上のテキストなし。
  • クレジットフィルム: 1クレジット = 2秒（切り上げ）、最低10クレジット。15秒 = 10、30秒 = 15、60秒 = 30、5分 = 150。アニマティック: 一律5クレジット。最初に7クレジットが付き、パックは€5 = 10、€15 = 35、€40 = 100、一回払いで定期課金なし。
  • 時間レンダリングはレンタルしたGPU上で通常25〜35分。Kleoがチャットで見込み時間を伝えます。

05トラブルシューティング

うまくいかないときは。

ClaudeにKleoが表示されない。

貼り付けたアドレスを確認してください。正確には https://mcp.kleooai.com/mcp で、https で始まり /mcp の後には何もありません。名前をKleoにしてコネクタをもう一度追加します。追加した後も、オンにするまでチャットではオフのままです。新しいチャットを開き、ツールメニューからKleoをオンにしてください。無料プランではカスタムコネクタは1つだけなので、Kleoをその1つにする必要があります。

Kleoのページが開かない、またはウィンドウがブロックされた。

コネクタを確定すると、Claudeがサインイン用にKleoのページを開きます。Start freeボタンひとつで、入力するものはありません。ブラウザがポップアップとしてブロックした場合は、Claudeのポップアップを許可してコネクタをもう一度確定してください。ページが開くのでStart freeをクリックすると、Claudeに戻ります。

クレジットが足りない。

接続すると7クレジットが付きます。これで作れるのはアニマティック（5）で、フィルムは作れません。フィルムはパックを購入したアカウントだけに作られ、30秒のフィルムは15クレジットです。€5のパック（10クレジット）で17クレジットになり、レンダリングを開始できます。ClaudeにKleoのアカウントページ（kleo_account）を頼むと、残高と決済リンクが表示されます（€5 = 10クレジット、€15 = 35、€40 = 100。ユーロ建ての一回払い、定期課金なし）。拒否された呼び出しには課金されていません。

フィルムが完成する前に待機がタイムアウトした。

長いレンダリングは1回のツール呼び出しより長くかかることがありますが、ジョブはGPU上で動き続けています。Claudeにジョブの状態（kleo_get_job）を尋ねるか、もう一度待つよう（kleo_wait_for_video）頼み、それからリンク（kleo_get_result）を頼んでください。1本目を確認するために2本目のフィルムを頼まないでください。

レンダリングを止めたい。

Claudeにジョブのキャンセル（kleo_cancel_job）を頼みます。レンダリングが止まり、未使用分のクレジットが残高に戻ります。
