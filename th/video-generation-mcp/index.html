เซิร์ฟเวอร์ MCP
สำหรับผลิตวิดีโอ

Kleo เปิดขั้นตอนการทำภาพยนตร์หนึ่งชุดให้ไคลเอนต์ MCP ใดก็ได้: รับบรีฟ ทรีตเมนต์ สตอรีบอร์ด การเรนเดอร์บน GPU ที่เช่าสำหรับงานนั้น และลิงก์ไปยังภาพยนตร์พร้อมเสียงบรรยายที่เสร็จสมบูรณ์แบบ 4K ที่ 60 fps ผู้บรรยายหนึ่งเสียง สองลุค สองผลิตภัณฑ์ (ภาพยนตร์ หรือแอนิเมติกจากสตอรีบอร์ดเดียวกัน) ความยาว 15 วินาทีถึง 5 นาที ไม่มีแอปและไม่มีแดชบอร์ด ผู้ช่วย AI ทำงานผ่านเครื่องมือด้านล่าง

01เอนด์พอยต์

เชื่อมต่อผ่าน HTTPS

Kleo คือเซิร์ฟเวอร์ MCP ระยะไกล: ที่อยู่เดียว ทรานสปอร์ต Streamable HTTP และ OAuth 2.1 ตั้งค่าที่อยู่ในไคลเอนต์ MCP ของคุณแล้วทำการอนุญาตให้เสร็จในเบราว์เซอร์ ไม่มีแบบฟอร์มลงทะเบียนและไม่มีรหัสผ่าน

  • เอนด์พอยต์https://mcp.kleooai.com/mcp
  • ทรานสปอร์ตStreamable HTTP ที่อยู่เดียวกันในทุกไคลเอนต์
  • การยืนยันตัวตนOAuth 2.1 ระหว่างการอนุญาต ไคลเอนต์จะเปิดหน้าของ Kleo เอง คุณคลิก Start free แล้วกลับมาที่ไคลเอนต์พร้อม 7 เครดิตในบัญชี ไม่มีแบบฟอร์ม ไม่ต้องใช้บัตร
  • เมื่อไม่มีโทเค็นGET ไปยังเอนด์พอยต์จะตอบ 401 พร้อมเมตาดาตาของทรัพยากร OAuth นี่คือเอนด์พอยต์ของโปรโตคอล ไม่ใช่หน้าเว็บ: การเปิดในเบราว์เซอร์ไม่ใช่ขั้นตอนการเชื่อมต่อ
  • ไคลเอนต์Claude, ChatGPT, Grok, Claude Code, Cursor, VS Code, OpenCode, Gemini CLI, Windsurf, แอป Gemini และ MCP SDK ใดๆ ที่ใช้ทรานสปอร์ต HTTP

ขั้นตอนเชื่อมต่อสำหรับทุกไคลเอนต์ →

จากเทอร์มินัลหรือเอดิเตอร์

ไคลเอนต์ที่ทดสอบแล้วสองตัวเป็นตัวอย่าง ขั้นตอนอื่นๆ ตั้งแต่ Claude และ ChatGPT ไปจนถึง VS Code และ Gemini CLI อยู่ที่ หน้าเชื่อมต่อ

Claude Code cli

# เพิ่ม Kleo ครั้งเดียว claude mcp add --transport http kleo https://mcp.kleooai.com/mcp # จากนั้น ภายในเซสชัน: /mcp → Kleo → Authenticate

หน้าของ Kleo จะเปิดในเบราว์เซอร์ คลิก Start free แล้วคุณจะกลับมาที่ Claude Code

Cursor ~/.cursor/mcp.json

{ "mcpServers": { "kleo": { "url": "https://mcp.kleooai.com/mcp" } } }

บันทึกไฟล์ เมื่อ Cursor เชื่อมต่อ หน้าของ Kleo จะเปิดขึ้น: คลิก Start free แล้วคุณจะกลับมาที่ Cursor

02ขั้นตอนการทำงาน

ลำดับการผลิต

เครื่องมือทำงานตามลำดับที่กำหนด ผู้ช่วย AI อ่านคำขอของคุณ รับทรีตเมนต์จาก kleo_adapt_prompt เขียนสตอรีบอร์ดตาม kleo_storyboard_guide แล้วจึงขอให้ Kleo เรนเดอร์

เครื่องมือ kleo ตามลำดับที่ผู้ช่วย AI เรียกใช้

เครื่องมือ ทำอะไร
kleo_adapt_prompt อ่านคำขอเทียบกับรายการรับบรีฟ (หัวข้อ ความยาว รูปแบบ ลุค; กลุ่มผู้ชม น้ำเสียง สิ่งที่ต้องปรากฏ เป็นทางเลือก) ถามสิ่งที่ขาดไป แล้วส่งทรีตเมนต์กลับมา: ล็อกไลน์ มุมมอง ฉากเปิด องก์ ตอนจบ ลุค จังหวะ ผู้บรรยาย
kleo_storyboard_guide อธิบายวิธีเขียนสตอรีบอร์ด: บล็อกการกำกับ ฉาก ช็อต และขอบเขต
kleo_create_video ตรวจสอบทุกอย่าง แจ้งจำนวนเครดิตที่แน่นอน แล้วเริ่มเรนเดอร์บน GPU ที่เช่าสำหรับงานนั้น รับ product: "film" หรือ "animatic"
kleo_get_job รายงานความคืบหน้าของงานในการเรียกครั้งเดียว
kleo_wait_for_video รอการเรนเดอร์และรายงานความคืบหน้าจนกว่าภาพยนตร์จะพร้อม
kleo_get_result ส่งลิงก์ไปยังภาพยนตร์ที่เสร็จแล้วกลับมา
kleo_cancel_job หยุดการเรนเดอร์และคืนเครดิตที่ยังไม่ได้ใช้
kleo_list_templates แสดงขั้นตอนการทำงานหนึ่งเดียว คือภาพยนตร์ พร้อมรูปแบบ ความยาว และเสียง และเครดิตที่เหลือในบัญชี แอนิเมติกเป็นผลิตภัณฑ์ของขั้นตอนการทำงานเดียวกันนี้
kleo_account แสดงเครดิต สถานะว่าบัญชีจ่ายเงินแล้วหรือไม่ (has_paid ซึ่งกำหนดว่าสั่งภาพยนตร์ได้หรือไม่) ลิงก์ไปยังหน้าบัญชี และกุญแจ Kleo ส่วนตัว
kleo_generate_thumbnail ยังไม่มีในเบต้า

ใช้สคีมาเครื่องมือของเซิร์ฟเวอร์จริงสำหรับอาร์กิวเมนต์ที่แน่นอน หากไคลเอนต์ของคุณจำกัดระยะเวลาที่การเรียกเครื่องมือทำงานได้ ผู้ช่วย AI สามารถเรียก kleo_get_job เป็นระยะแทนการเปิด kleo_wait_for_video ค้างไว้

03พารามิเตอร์

การเรนเดอร์ต้องใช้อะไรบ้าง

kleo_create_video รับคำขอในคำพูดของคุณบวกกับตัวเลือกที่รายการรับบรีฟถามไป ทรีตเมนต์และสตอรีบอร์ดมาจากเครื่องมือวางแผนสองตัว ไม่ใช่จากคีย์บอร์ดของคุณ

  • promptคำขอในคำพูดของผู้ใช้เอง
  • productfilm (ค่าเริ่มต้น: ทุกช็อตเป็นคลิปที่สร้างขึ้น คิดราคาตามความยาว สำหรับบัญชีที่ซื้อแพ็กแล้ว) หรือ animatic (เฟรมที่วาดไว้ใต้กล้องที่เคลื่อนไหว ไม่มีคลิปที่สร้างขึ้น ราคาคงที่ 5 เครดิต ความยาว 15 ถึง 60 วินาที สำหรับทุกบัญชี)
  • duration_s15 ถึง 300 วินาทีสำหรับภาพยนตร์ 15 ถึง 60 สำหรับแอนิเมติก
  • format16:9 สำหรับ YouTube และแนวนอน 9:16 สำหรับ Short และแนวตั้ง
  • stylerealistic (ฟุตเทจไลฟ์แอ็กชันที่สร้างขึ้น ให้ความรู้สึกแบบภาพยนตร์) หรือ animation (ภาพยนตร์แอนิเมชัน 2D) ในภาพยนตร์ ทุกช็อตถูกสร้างเป็นฟุตเทจเคลื่อนไหวจากเฟรมของตัวเอง แอนิเมติกคงลุคไว้ในเฟรมที่วาด
  • languageเสียงบรรยาย en หรือ it ผู้บรรยายหนึ่งเสียง ไม่มีดนตรี ไม่มีคำบรรยาย ไม่มีข้อความบนหน้าจอในภาพยนตร์มาตรฐาน
  • voiceทางเลือก: narrator-en-m, narrator-en-f, narrator-it-m หรือ narrator-it-f
  • treatmentทางเลือก: ทรีตเมนต์ที่ kleo_adapt_prompt ส่งกลับมา (ล็อกไลน์ มุมมอง ฉากเปิด องก์ ตอนจบ ลุค จังหวะ ผู้บรรยาย)
  • storyboardทางเลือก: สตอรีบอร์ดที่เขียนตาม kleo_storyboard_guide (บล็อกการกำกับ ฉาก ช็อต ขอบเขต)

ราคา

ภาพยนตร์: หนึ่งเครดิตเท่ากับสองวินาที ปัดขึ้น ขั้นต่ำสิบเครดิต: 15 วินาที = 10 · 20 วินาที = 10 · 30 วินาที = 15 · 60 วินาที = 30 · 90 วินาที = 45 · 3 นาที = 90 · 5 นาที = 150 แอนิเมติก: ราคาคงที่ 5 เครดิต ความยาว 15 ถึง 60 วินาที การเชื่อมต่อรวม 7 เครดิต แอนิเมติกหนึ่งเรื่อง ภาพยนตร์ทำให้เฉพาะบัญชีที่ซื้อแพ็กแล้ว (คลิปของภาพยนตร์ถูกสร้างขึ้นด้วยค่าใช้จ่ายของ Kleo เครดิตฟรีจึงซื้อภาพยนตร์ไม่ได้): 7 + แพ็ก €5 = 17 ภาพยนตร์เปิดให้ทำได้ เป็น Short ความยาว 30 วินาที แพ็กจ่ายครั้งเดียวเป็นยูโร ไม่มีค่าบริการรายเดือน: €5 = 10 เครดิต · €15 = 35 · €40 = 100

จะไม่เรียกเก็บอะไรเลยจนกว่างานจะได้รับการยอมรับ

kleo_create_video ตอบด้วยจำนวนเครดิตที่แน่นอนก่อน การเรียกที่ถูกปฏิเสธไม่มีค่าใช้จ่าย และ kleo_cancel_job คืนเครดิตที่การเรนเดอร์ที่ถูกหยุดยังไม่ได้ใช้

เวลาเรนเดอร์

ภาพยนตร์โดยทั่วไปใช้เวลา 25–35 นาทีบน GPU ที่เช่า แอนิเมติกประมาณ 15–20 นาที เซิร์ฟเวอร์บอกเวลาโดยประมาณของงานให้ผู้ช่วย AI ไม่ใช่เวลาที่ตายตัว

04ผลลัพธ์

วิดีโอที่เสร็จสมบูรณ์คือผลลัพธ์

ไฟล์ MP4 หนึ่งไฟล์: 4K (3840×2160 หรือ 2160×3840) ที่ 60 fps 16:9 หรือ 9:16 พร้อมผู้บรรยายหนึ่งเสียงภาษาอังกฤษหรืออิตาลี และในภาพยนตร์ ทุกช็อตถูกสร้างเป็นฟุตเทจเคลื่อนไหว kleo_get_result ส่งลิงก์ไฟล์ให้ผู้ช่วย AI ลิงก์ใช้ได้ 7 วัน

Kleo ไม่เคยเผยแพร่ไปยัง YouTube, TikTok หรือช่องทางใด และภาพยนตร์มาตรฐานไม่มีดนตรี ไม่มีคำบรรยาย และไม่มีข้อความบนหน้าจอ เซิร์ฟเวอร์เปิดใช้สองลุค สมจริงและแอนิเมชัน เว็บไซต์แสดงตัวอย่างของแต่ละลุคบนหน้าลุค

05บัญชี

การจัดการบัญชีและงาน

เก็บโทเค็น OAuth และกุญแจ Kleo ให้พ้นจากล็อกและตัวอย่างสาธารณะ: กุญแจเป็นของส่วนตัว และใครถือกุญแจก็เป็นเจ้าของบัญชี ไม่มีแดชบอร์ด หน้าบัญชี (ยอดคงเหลือแบบอ่านอย่างเดียวและลิงก์ชำระเงิน) เข้าถึงได้โดยถามผู้ช่วย AI และ kleo_account ส่งกลับมา

การเรนเดอร์ใช้เครดิต: ขอการยืนยันก่อนที่ kleo_create_video จะทำงาน และใช้ตัวระบุงานเดิมเมื่อตรวจสอบความคืบหน้าหรือยกเลิก โค้ดของเซิร์ฟเวอร์เป็นสาธารณะ
