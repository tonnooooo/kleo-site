Make videos & pictures in ChatGPT with Kleo

Install Kleo in ChatGPTHow to connect?
  1. Click Install: the Kleo address is copied and ChatGPT opens its Connectors settings.
  2. Choose Create (turn on Developer mode first if ChatGPT asks), name it Kleo and paste the address.
  3. Press Start free on Kleo’s page, then ask: "make me a 5-second video of a paper boat in the rain".
Install Kleo in ClaudeHow to connect?
  1. Click Install: the Kleo address is copied and Claude opens Settings → Connectors.
  2. Choose Add custom connector, name it Kleo and paste the address.
  3. Press Start free on Kleo’s page, then ask Claude for a video, a picture or a whole film.
How to connect?
claude mcp add --transport http kleo https://mcp.kleooai.com/mcp
  1. Click Copy the command.
  2. Paste it in your terminal and press Enter.
  3. Run /mcp in Claude Code, choose kleo, sign in, and ask for a video.
Install Kleo in CursorHow to connect?
  1. Click Install: Cursor opens and asks to add Kleo.
  2. Confirm, then sign in to Kleo when Cursor asks.
  3. Ask the agent for a video or a picture.
