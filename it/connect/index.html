Kleo è un server MCP remoto. Parla il Model Context Protocol su Streamable HTTP con OAuth 2.1, quindi lo stesso indirizzo funziona in ogni client, e collegarsi è un solo pulsante sulla pagina di Kleo — nessun modulo di registrazione, nessuna password, nessuna carta. Si parte gratis: 7 crediti sul tuo account nel momento in cui ti colleghi, un animatic. Aggiungilo al tuo assistente e descrivi il film che vuoi fare.

Cursor mcp.json

Crea o modifica ~/.cursor/mcp.json (tutti i progetti) oppure .cursor/mcp.json dentro un singolo progetto.

{ "mcpServers": { "kleo": { "url": "https://mcp.kleooai.com/mcp" } } }
  1. Salva il file: Cursor elenca Kleo in Settings → MCP. Clicca Connect (o usa uno strumento una volta): si apre la pagina di Kleo, clicca Inizia gratis e sei di nuovo in Cursor.

VS Code mcp.json

Crea .vscode/mcp.json nel tuo workspace (oppure esegui MCP: Add Server dalla Command Palette e incolla l'indirizzo).

{ "servers": { "kleo": { "type": "http", "url": "https://mcp.kleooai.com/mcp" } } }
  1. Salva il file, poi clicca Start sopra la voce del server. VS Code apre la pagina di Kleo: clicca Inizia gratis e sei di nuovo in VS Code.
  2. In Copilot Chat, passa alla modalità Agent: gli strumenti kleo compaiono nel selettore degli strumenti.

OpenCode opencode.jsonc

Aggiungi questo a ~/.config/opencode/opencode.jsonc (globale) oppure a opencode.jsonc nel progetto, poi collegati dal terminale.

{ "mcp": { "kleo": { "type": "remote", "url": "https://mcp.kleooai.com/mcp", "enabled": true } } }
# collegati una volta (apre il browser) opencode mcp auth kleo
  1. Salva la configurazione ed esegui il comando qui sopra: la pagina di Kleo si apre nel browser, clicca Inizia gratis e sei di nuovo in OpenCode.
  2. Avvia opencode e chiedi il video: gli strumenti kleo sono disponibili in ogni sessione.

Windsurf, l'app Gemini e i tuoi agenti http

Kleo è un server MCP standard sul trasporto Streamable HTTP con OAuth 2.1. Qualsiasi client compatibile si collega con lo stesso indirizzo e lo stesso avvio con un solo pulsante.

Indirizzo del server https://mcp.kleooai.com/mcp
  1. Windsurf: Settings → MCP → Add server, incolla l'indirizzo (il suo mcp_config.json usa la chiave "serverUrl").
  2. App Gemini: Impostazioni → App collegate → App personalizzate, incolla l'indirizzo (al momento richiede Google AI Pro o Ultra).
  3. Per il tuo agente: usa un SDK MCP (Python o TypeScript) con il trasporto HTTP e completa il flusso OAuth una volta.

02Prima richiesta

Parti da una richiesta chiara.

L'assistente legge la tua richiesta rispetto all'intake di Kleo — soggetto, durata, formato, look — e chiede quello che manca prima di scrivere il treatment. Indica tutti e quattro e si mette subito al lavoro. Incolla questo nella tua prima chat:

“Usa Kleo per pianificare un film di 30 secondi su un guardiano del faro che scopre un messaggio in bottiglia. Look realistico, narrazione in inglese, 9:16. Mostrami la scaletta e il costo in crediti prima del render.”

Sul server sono disponibili due look: realistico, girato live-action generato, e animazione, un film animato 2D. Cambia la parola nel prompt per ottenere l'altro.

03Crediti

Controlla il saldo prima della produzione.

Il collegamento include 7 crediti: un animatic del tuo storyboard costa 5 e ogni account può ordinarne uno. Un film si fa solo per gli account che hanno comprato un pacchetto, uno qualsiasi, e un film di 30 secondi costa 15 crediti, quindi il primo film parte dal pacchetto da 5 €: 7 + 10 = 17 crediti, abbastanza per uno Short di 30 secondi.

Chiedi all'assistente la pagina del tuo account per comprare crediti, poi conferma quando vuoi che il render parta. Niente viene addebitato finché Kleo non accetta il job: l'assistente indica prima i crediti esatti, e una richiesta rifiutata non costa nulla.
