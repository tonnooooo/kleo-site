Claude와 Kleo로
영상을 만드세요.

Claude에서 필름을 연출합니다. Claude에 사용자 지정 커넥터로 추가된 Kleo가 푸티지, 내레이션, 완성된 4K MP4를 생성하고, 링크는 같은 채팅에 도착합니다.

01설정

Claude에 Kleo를 추가하세요.

Kleo는 원격 MCP 서버입니다. 설치할 앱도, 가입 양식도 없습니다. Claude는 사용자 지정 커넥터를 통해 Kleo에 접근하고, 연결은 Kleo 페이지의 버튼 하나로 끝납니다. 아래 단계는 Claude 앱과 웹에서 같고, 모든 Claude 플랜에서 작동합니다. 무료 플랜에서는 사용자 지정 커넥터를 하나 추가할 수 있습니다.

  1. Claude에서 설정 → 커넥터를 열고 사용자 지정 커넥터 추가를 선택하세요.
  2. 이름을 Kleo로 정하고 아래 주소를 붙여 넣은 뒤 확인하세요.
  3. Kleo 페이지가 열리면 무료로 시작을 누르세요. 새 Kleo 계정에 7크레딧이 담긴 채로 Claude로 돌아옵니다. 양식도, 비밀번호도, 카드도 없습니다. 5크레딧짜리 애니매틱 한 편에 충분합니다. 필름은 팩을 구매한 계정에만 만들어 드리고 최소 10크레딧이므로, 첫 필름 전에 €5 팩(10크레딧)이 필요합니다. 30초 필름은 15크레딧입니다.
  4. 새 채팅에서 도구 메뉴에서 Kleo를 켜고 필름을 요청하세요.
서버 주소 https://mcp.kleooai.com/mcp

Claude는 Anthropic의 어시스턴트입니다. Kleo는 Claude가 사용자 지정 커넥터로 접근하는 별도의 서비스이며, 같은 주소가 ChatGPT, Grok, Claude Code, Cursor 등 모든 MCP 클라이언트에서 작동합니다. 연결 페이지를 참고하세요.

02첫 프롬프트

원하는 필름을 요청하세요.

주제, 길이, 포맷, 룩을 한 메시지에 말하세요. 대상 시청자, 톤, 필름에 꼭 들어가야 할 것은 선택 사항입니다. 요청에서 빠진 것은 Claude가 계획을 세우기 전에 물어봅니다. 길이, 포맷, 룩을 절대 대신 고르지 않습니다.

“Kleo로 새벽에 고요한 호수를 건너는 작은 나무배 이야기로 30초짜리 필름을 만들어 줘. 리얼리스틱 룩, 16:9, 영어 내레이션, 차분한 톤. 렌더링을 시작하기 전에 트리트먼트와 정확한 크레딧을 보여 줘.”

  • 룩두 가지 룩을 쓸 수 있습니다. 시네마틱한 느낌의 생성된 실사 푸티지인 리얼리스틱과 2D 애니메이션 필름인 애니메이션. 필름 룩 보기 →
  • 포맷YouTube용 16:9 또는 쇼츠용 9:16.
  • 길이15초에서 5분까지.
  • 내레이션영어 또는 이탈리아어.
03채팅 안에서

채팅에서 그다음에 일어나는 일.

Kleo의 도구는 정해진 순서로 실행되며 Claude가 대신 이끕니다. 당신은 각 단계에서 읽고, 고치고, 승인합니다. 당신이 진행을 허락하고 작업이 수락되기 전까지는 아무것도 청구되지 않습니다.

01 kleo_adapt_prompt

트리트먼트

Claude가 요청을 Kleo의 인테이크에 비추어 읽습니다. 주제, 길이, 포맷, 룩은 필수이고 대상 시청자, 톤, 꼭 들어가야 할 것은 선택 사항입니다. 빠진 것은 한 메시지로 물어봅니다. 그다음 트리트먼트를 보여줍니다. 로그라인, 앵글, 오프닝 이미지, 막 구성, 결말, 룩, 페이싱, 내레이터. 넘어가기 전에 무엇이든 바꾸세요.

02 kleo_storyboard_guide

스토리보드

Claude가 Kleo의 스토리보드 가이드(연출 블록, 장면, 샷과 그 한도)를 가져와, 당신이 승인한 트리트먼트를 바탕으로 스토리보드를 씁니다. 필름은 여기서 만들어집니다. 읽고 수정을 요청하세요.

03 kleo_create_video

렌더링

Kleo가 모든 것을 확인한 뒤 필름의 정확한 크레딧을 알려줍니다. 당신이 승인하면 Claude가 그 작업 하나를 위해 대여한 GPU에서 렌더링을 시작합니다. 작업이 수락되기 전에는 아무것도 청구되지 않으며, 거부된 호출에는 비용이 들지 않습니다.

04 kleo_wait_for_video

링크

Claude가 진행 상황을 알려주며 렌더링을 기다리고, Kleo가 완성된 MP4 링크를 넘겨줍니다. 보통 25–35분 뒤입니다. 링크는 7일간 유효합니다. Kleo는 필름을 어디에도 게시하지 않습니다. 다운로드해서 원하는 곳에 올리세요.

04필름

받게 되는 것.

  • 출력4K(3840×2160 또는 2160×3840), 60 fps의 MP4. YouTube용 16:9, 쇼츠용 9:16.
  • 길이필름은 15초에서 5분, 애니매틱은 15초에서 60초.
  • 룩리얼리스틱(생성된 실사 푸티지, 시네마틱) 또는 애니메이션(2D 애니메이션 필름). 필름에서는 모든 샷이 각자의 프레임에서 움직이는 푸티지로 생성됩니다.
  • 제품필름, 또는 같은 스토리보드의 애니매틱. 애니매틱은 그려진 프레임 위로 카메라가 움직이고, 같은 내레이터와 그래픽 레이어가 들어가며, 생성된 클립은 없습니다. 모든 계정에서 애니매틱을 주문할 수 있고, 필름은 팩을 구매한 계정에만 만들어 드립니다.
  • 내레이션내레이터 한 명, 영어 또는 이탈리아어. 배경 음악도, 자막도, 화면 속 텍스트도 없습니다.
  • 크레딧필름: 1크레딧 = 2초(올림), 최소 10크레딧. 15초 = 10, 30초 = 15, 60초 = 30, 5분 = 150. 애니매틱: 5크레딧 정액. 시작 크레딧은 7이고, 팩은 €5 = 10, €15 = 35, €40 = 100, 한 번만 결제하며 정기 결제는 없습니다.
  • 시간렌더링은 대여한 GPU에서 보통 25–35분 걸립니다. Kleo가 채팅에서 예상 시간을 알려줍니다.

05문제 해결

무언가 작동하지 않을 때.

Claude에 Kleo가 나타나지 않습니다.

붙여 넣은 주소를 확인하세요. 정확히 https://mcp.kleooai.com/mcp이어야 하며, https로 시작하고 /mcp 뒤에는 아무것도 없어야 합니다. Kleo라는 이름으로 커넥터를 다시 추가하세요. 추가한 뒤에도 채팅에서 켜기 전까지는 꺼져 있습니다. 새 채팅을 열고 도구 메뉴에서 Kleo를 켜세요. 무료 플랜에서는 사용자 지정 커넥터가 하나만 허용되므로, 그 하나가 Kleo여야 합니다.

Kleo 페이지가 열리지 않았거나 창이 차단되었습니다.

커넥터를 확인하면 Claude가 로그인을 위해 Kleo 페이지를 엽니다. 무료로 시작 버튼 하나뿐이고 채울 것은 없습니다. 브라우저가 팝업으로 차단했다면 Claude의 팝업을 허용하고 커넥터를 다시 확인하세요. 페이지가 열리면 무료로 시작을 누르고 Claude로 돌아옵니다.

크레딧이 부족합니다.

연결하면 7크레딧을 드립니다. 이 크레딧으로 애니매틱(5)은 살 수 있지만 필름은 살 수 없습니다. 필름은 팩을 구매한 계정에만 만들어 드리고 30초 필름은 15크레딧이므로, €5 팩(10크레딧)을 더하면 17크레딧이 되어 렌더링을 시작할 수 있습니다. Claude에게 Kleo 계정 페이지(kleo_account)를 요청하세요. 잔액과 결제 링크가 표시됩니다(€5 = 10크레딧, €15 = 35, €40 = 100. EUR 일회성 결제, 정기 결제 없음). 거부된 호출에는 아무것도 청구되지 않았습니다.

필름이 준비되기 전에 대기 시간이 초과되었습니다.

긴 렌더링은 도구 호출 한 번보다 오래 걸릴 수 있지만, 작업은 GPU에서 계속 진행됩니다. Claude에게 작업 상태(kleo_get_job)를 묻거나 다시 기다리게(kleo_wait_for_video) 한 뒤 링크(kleo_get_result)를 요청하세요. 첫 필름을 확인하려고 두 번째 필름을 요청하지 마세요.

렌더링을 중단하고 싶습니다.

Claude에게 작업 취소(kleo_cancel_job)를 요청하세요. 렌더링이 멈추고 사용하지 않은 크레딧은 잔액으로 돌아갑니다.
