Kleo es un servidor MCP remoto. Habla el Model Context Protocol sobre Streamable HTTP con OAuth 2.1, así que la misma dirección funciona en todos los clientes, y conectarse es un solo botón en la propia página de Kleo — sin formulario de registro, sin contraseña, sin tarjeta. Es gratis para empezar: 7 créditos en tu cuenta en cuanto te conectas, un animatic. Añádelo a tu asistente y describe la película que quieres hacer.

01Conectar

Elige tu asistente.

Todos los clientes de abajo usan la misma dirección y el mismo inicio de un solo botón: pegas la dirección, se abre la página de Kleo, pulsas Empezar gratis y vuelves al cliente con 7 créditos en la cuenta. Estos son los pasos que hemos probado.

Claude app · web

Dirección del servidor https://mcp.kleooai.com/mcp
  1. Abre Configuración → Conectores y elige Añadir conector personalizado.
  2. Llámalo Kleo, pega la dirección de arriba y confirma. Se abre la página de Kleo: pulsa Empezar gratis y vuelves a Claude.
  3. En un chat nuevo, activa Kleo desde el menú de herramientas y pide: Hazme un Short de 45 segundos sobre…

El plan gratuito de Claude permite un conector personalizado.

ChatGPT modo desarrollador

Dirección del servidor https://mcp.kleooai.com/mcp
  1. Abre Configuración → Apps y conectores (llamado Conectores en versiones anteriores), luego Configuración avanzada, y activa el Modo desarrollador.
  2. De vuelta en Conectores, elige Crear: llámalo Kleo, pega la dirección, pon la autenticación en OAuth y guarda. Se abre la página de Kleo: pulsa Empezar gratis y vuelves a ChatGPT.
  3. En el chat, activa Kleo desde el menú + y pide el vídeo. ChatGPT te pide confirmación antes de iniciar un render.

Requiere ChatGPT Plus, Pro, Business o Enterprise.

Claude Code cli

# añade Kleo una vez (añade --scope user para tenerlo en todos los proyectos) claude mcp add --transport http kleo https://mcp.kleooai.com/mcp # después, dentro de una sesión: /mcp → Kleo → Authenticate
  1. Ejecuta el comando de arriba, luego escribe /mcp en una sesión, elige Kleo y Authenticate: la página de Kleo se abre en tu navegador, pulsa Empezar gratis y vuelves a Claude Code.
  2. Pide: Usa kleo para un vídeo de 5 minutos sobre la historia del café, 16:9. Claude Code comprueba el progreso por ti y te entrega los enlaces.

Cursor mcp.json

Crea o edita ~/.cursor/mcp.json (todos los proyectos) o .cursor/mcp.json dentro de un proyecto.

{ "mcpServers": { "kleo": { "url": "https://mcp.kleooai.com/mcp" } } }
  1. Guarda el archivo: Cursor muestra Kleo en Configuración → MCP. Pulsa Connect (o usa una herramienta una vez): se abre la página de Kleo, pulsa Empezar gratis y vuelves a Cursor.

VS Code mcp.json

Crea .vscode/mcp.json en tu espacio de trabajo (o ejecuta MCP: Add Server desde la paleta de comandos y pega la dirección).

{ "servers": { "kleo": { "type": "http", "url": "https://mcp.kleooai.com/mcp" } } }
  1. Guarda el archivo y pulsa Start encima de la entrada del servidor. VS Code abre la página de Kleo: pulsa Empezar gratis y vuelves a VS Code.
  2. En Copilot Chat, cambia al modo Agent: las herramientas kleo aparecen en el selector de herramientas.

OpenCode opencode.jsonc

Añade esto a ~/.config/opencode/opencode.jsonc (global) o a opencode.jsonc en el proyecto, y luego conéctate desde el terminal.

{ "mcp": { "kleo": { "type": "remote", "url": "https://mcp.kleooai.com/mcp", "enabled": true } } }
# conéctate una vez (abre el navegador) opencode mcp auth kleo
  1. Guarda la configuración y ejecuta el comando de arriba: la página de Kleo se abre en el navegador, pulsa Empezar gratis y vuelves a OpenCode.
  2. Inicia opencode y pide el vídeo: las herramientas kleo están disponibles en todas las sesiones.

Gemini CLI cli

# añade Kleo (añade --scope user para tenerlo en todos los proyectos) gemini mcp add --transport http kleo https://mcp.kleooai.com/mcp
  1. Ejecuta el comando de arriba, luego inicia gemini y escribe /mcp auth kleo: la página de Kleo se abre en tu navegador, pulsa Empezar gratis y vuelves a Gemini CLI.
  2. Pide el vídeo en la sesión. /mcp list muestra todas las herramientas kleo.

Windsurf, la app de Gemini y tus propios agentes http

Kleo es un servidor MCP estándar sobre el transporte Streamable HTTP con OAuth 2.1. Cualquier cliente compatible se conecta con la misma dirección y el mismo inicio de un solo botón.

Dirección del servidor https://mcp.kleooai.com/mcp
  1. Windsurf: Configuración → MCP → Añadir servidor, pega la dirección (su mcp_config.json usa la clave "serverUrl").
  2. App de Gemini: Configuración → Apps conectadas → Apps personalizadas, pega la dirección (actualmente requiere Google AI Pro o Ultra).
  3. Para tu propio agente: usa un SDK de MCP (Python o TypeScript) con el transporte HTTP y completa el flujo OAuth una vez.

02Primera petición

Empieza con una petición clara.

El asistente contrasta tu petición con el intake de Kleo — tema, duración, formato, look — y pregunta lo que falte antes de escribir el tratamiento. Di los cuatro y se pone a trabajar de inmediato. Pega esto en tu primer chat:

«Usa Kleo para planificar una película de 30 segundos sobre un farero que descubre un mensaje en una botella. Look realista, narración en inglés, 9:16. Muéstrame el esquema y el coste en créditos antes de renderizar.»

Hay dos looks disponibles en el servidor: realista, metraje de imagen real generado, y animación, una película de animación 2D. Cambia la palabra en el prompt para obtener el otro.

03Créditos

Comprueba tu saldo antes de producir.

Conectarse incluye 7 créditos: un animatic de tu storyboard cuesta 5 y cualquier cuenta puede pedir uno. Una película solo se hace para cuentas que han comprado un pack, cualquier pack, y una película de 30 segundos cuesta 15 créditos, así que la primera película empieza con el pack de 5 €: 7 + 10 = 17 créditos, suficiente para un Short de 30 segundos.

Pide al asistente la página de tu cuenta para comprar créditos y luego confirma cuándo quieres que empiece el render. No se cobra nada hasta que Kleo acepta el trabajo: el asistente indica primero los créditos exactos, y una petición rechazada no cuesta nada.
