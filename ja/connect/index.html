KleoはリモートMCPサーバーです。Streamable HTTPとOAuth 2.1でModel Context Protocolを話すため、同じアドレスがすべてのクライアントで使え、接続はKleo自身のページのボタンひとつ——登録フォームも、パスワードも、カードも不要です。無料で始められ、接続した瞬間にアカウントへ7クレジット、アニマティック1本分。アシスタントに追加して、作りたいフィルムを伝えてください。

01接続

アシスタントを選ぶ。

以下のどのクライアントも、同じアドレスと同じボタンひとつの開始手順を使います。アドレスを貼り付けるとKleoのページが開き、Start freeをクリックすれば、7クレジットがアカウントに入った状態でクライアントに戻ります。以下は私たちが実際にテストした手順です。

Claude アプリ · ウェブ

サーバーアドレス https://mcp.kleooai.com/mcp
  1. 設定 → コネクタを開き、カスタムコネクタを追加を選びます。
  2. 名前をKleoにして上のアドレスを貼り付け、確定します。Kleoのページが開くのでStart freeをクリックすると、Claudeに戻ります。
  3. 新しいチャットでツールメニューからKleoをオンにして、こう頼みます: 45秒のショートを作って。テーマは……

Claudeの無料プランではカスタムコネクタを1つ追加できます。

Claude完全ガイド →

ChatGPT 開発者モード

サーバーアドレス https://mcp.kleooai.com/mcp
  1. 設定 → アプリ & コネクタ（旧バージョンではコネクタ）を開き、詳細設定で開発者モードをオンにします。
  2. コネクタに戻って作成を選び、名前をKleoにしてアドレスを貼り付け、認証をOAuthに設定して保存します。Kleoのページが開くのでStart freeをクリックすると、ChatGPTに戻ります。
  3. チャットで+メニューからKleoをオンにして、動画を頼みます。ChatGPTはレンダリングを始める前に確認を求めます。

ChatGPT Plus、Pro、Business、Enterpriseのいずれかが必要です。

ChatGPT完全ガイド →

Grok コネクタ

サーバーアドレス https://mcp.kleooai.com/mcp
  1. grok.comまたはアプリで設定 → コネクタを開き、コネクタを追加 → カスタムを選びます。
  2. 名前をKleoにしてアドレスを貼り付け、確定します。Kleoのページが開くのでStart freeをクリックすると、Grokに戻ります。
  3. チャットでコネクタ一覧からKleoをオンにして、動画を頼みます。

Claude Code cli

# Kleoを一度だけ追加（--scope user を付けるとすべてのプロジェクトで使えます） claude mcp add --transport http kleo https://mcp.kleooai.com/mcp # その後、セッション内で: /mcp → Kleo → Authenticate
  1. 上のコマンドを実行し、セッション内で/mcpと入力してKleo、Authenticateを選びます。ブラウザでKleoのページが開くのでStart freeをクリックすると、Claude Codeに戻ります。
  2. こう頼みます: kleoでコーヒーの歴史についての5分の動画を作って、16:9で。Claude Codeが進行を確認し、リンクを手渡します。

Cursor mcp.json

~/.cursor/mcp.json（すべてのプロジェクト）または特定のプロジェクト内の.cursor/mcp.jsonを作成または編集します。

{ "mcpServers": { "kleo": { "url": "https://mcp.kleooai.com/mcp" } } }
  1. ファイルを保存すると、Cursorの設定 → MCPにKleoが表示されます。Connectをクリック（またはツールを一度使用）するとKleoのページが開くので、Start freeをクリックすればCursorに戻ります。

VS Code mcp.json

ワークスペースに.vscode/mcp.jsonを作成します（またはコマンドパレットからMCP: Add Serverを実行してアドレスを貼り付けます）。

{ "servers": { "kleo": { "type": "http", "url": "https://mcp.kleooai.com/mcp" } } }
  1. ファイルを保存し、サーバー項目の上にあるStartをクリックします。VS CodeがKleoのページを開くので、Start freeをクリックすればVS Codeに戻ります。
  2. Copilot ChatでAgentモードに切り替えると、ツール選択にkleoのツールが表示されます。

OpenCode opencode.jsonc

以下を~/.config/opencode/opencode.jsonc（グローバル）またはプロジェクト内のopencode.jsoncに追加し、ターミナルから接続します。

{ "mcp": { "kleo": { "type": "remote", "url": "https://mcp.kleooai.com/mcp", "enabled": true } } }
# 一度だけ接続（ブラウザが開きます） opencode mcp auth kleo
  1. 設定を保存して上のコマンドを実行すると、ブラウザでKleoのページが開きます。Start freeをクリックすればOpenCodeに戻ります。
  2. opencodeを起動して動画を頼みます。kleoのツールはすべてのセッションで使えます。

Gemini CLI cli

# Kleoを追加（--scope user を付けるとすべてのプロジェクトで使えます） gemini mcp add --transport http kleo https://mcp.kleooai.com/mcp
  1. 上のコマンドを実行し、geminiを起動して/mcp auth kleoと入力します。ブラウザでKleoのページが開くのでStart freeをクリックすると、Gemini CLIに戻ります。
  2. セッション内で動画を頼みます。/mcp listでkleoのすべてのツールが表示されます。

Windsurf、Geminiアプリ、自作のエージェント http

KleoはStreamable HTTPトランスポートとOAuth 2.1を使う標準的なMCPサーバーです。互換性のあるクライアントなら、同じアドレスと同じボタンひとつの開始手順で接続できます。

サーバーアドレス https://mcp.kleooai.com/mcp
  1. Windsurf: Settings → MCP → Add serverでアドレスを貼り付けます（mcp_config.jsonではキー"serverUrl"を使います）。
  2. Geminiアプリ: 設定 → 接続済みアプリ → カスタムアプリでアドレスを貼り付けます（現在はGoogle AI ProまたはUltraが必要です）。
  3. 自作のエージェントの場合: MCP SDK（PythonまたはTypeScript）をHTTPトランスポートで使い、OAuthフローを一度完了させます。

02最初の依頼

明確な依頼から始める。

アシスタントはあなたの依頼をKleoのインテーク——題材、長さ、フォーマット、ルック——に照らして読み取り、トリートメントを書く前に足りないものを尋ねます。4つすべてを伝えれば、すぐに作業に入ります。最初のチャットにこれを貼り付けてください:

「Kleoを使って、ボトルメッセージを見つける灯台守の30秒フィルムを企画して。実写ルック、英語ナレーション、9:16。レンダリングの前に構成とクレジット数を見せて。」

サーバーでは2つのルックが使えます。実写は生成された実写映像、アニメーションは2Dアニメーションのフィルムです。プロンプトの言葉を入れ替えれば、もう一方のルックになります。

03クレジット

制作の前に残高を確認する。

接続すると7クレジットが付きます。絵コンテのアニマティックは5クレジットで、すべてのアカウントが注文できます。フィルムはパック（どのパックでも）を購入したアカウントだけに作られ、30秒のフィルムは15クレジットなので、最初のフィルムは€5のパックから始まります。7 + 10 = 17クレジット、30秒のショートに十分です。

アシスタントにアカウントページを頼んでクレジットを購入し、レンダリングを始めたいタイミングで確認します。Kleoがジョブを受け付けるまで一切課金されません。アシスタントがまず正確なクレジット数を提示し、拒否された依頼には費用がかかりません。
