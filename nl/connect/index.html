Kleo is een remote MCP-server. Hij spreekt het Model Context Protocol over Streamable HTTP met OAuth 2.1, dus hetzelfde adres werkt in elke client, en verbinden is één knop op de eigen pagina van Kleo — geen registratieformulier, geen wachtwoord, geen kaart. Gratis beginnen: 7 credits op je account zodra je verbindt, één animatic. Voeg Kleo toe aan je assistent en beschrijf de film die je wilt maken.

01Verbinden

Kies je assistent.

Elke client hieronder gebruikt hetzelfde adres en dezelfde start met één knop: plak het adres, de pagina van Kleo opent, je klikt op Gratis beginnen en je bent terug in de client met 7 credits op je account. Dit zijn de stappen die we hebben getest.

ChatGPT ontwikkelaarsmodus

Claude Code cli

# voeg Kleo één keer toe (met --scope user heb je hem in elk project) claude mcp add --transport http kleo https://mcp.kleooai.com/mcp # daarna, in een sessie: /mcp → Kleo → Authenticate
  1. Voer het commando hierboven uit, typ dan /mcp in een sessie, kies Kleo en Authenticate: de pagina van Kleo opent in je browser, klik op Gratis beginnen en je bent terug in Claude Code.
  2. Vraag: Gebruik kleo voor een video van 5 minuten over de geschiedenis van koffie, 16:9. Claude Code volgt de voortgang voor je en geeft je de links.

Cursor mcp.json

Maak of bewerk ~/.cursor/mcp.json (alle projecten) of .cursor/mcp.json binnen één project.

{ "mcpServers": { "kleo": { "url": "https://mcp.kleooai.com/mcp" } } }
  1. Sla het bestand op: Cursor toont Kleo onder Settings → MCP. Klik op Connect (of gebruik één keer een tool): de pagina van Kleo opent, klik op Gratis beginnen en je bent terug in Cursor.

VS Code mcp.json

Maak .vscode/mcp.json in je workspace (of voer MCP: Add Server uit vanuit het Command Palette en plak het adres).

{ "servers": { "kleo": { "type": "http", "url": "https://mcp.kleooai.com/mcp" } } }
  1. Sla het bestand op en klik dan op Start boven de serverregel. VS Code opent de pagina van Kleo: klik op Gratis beginnen en je bent terug in VS Code.
  2. Schakel in Copilot Chat over naar de modus Agent: de kleo-tools verschijnen in de toolkiezer.

OpenCode opencode.jsonc

Voeg dit toe aan ~/.config/opencode/opencode.jsonc (globaal) of aan opencode.jsonc in het project, en verbind daarna vanuit de terminal.

{ "mcp": { "kleo": { "type": "remote", "url": "https://mcp.kleooai.com/mcp", "enabled": true } } }
# verbind één keer (opent de browser) opencode mcp auth kleo
  1. Sla de configuratie op en voer het commando hierboven uit: de pagina van Kleo opent in de browser, klik op Gratis beginnen en je bent terug in OpenCode.
  2. Start opencode en vraag om de video: de kleo-tools zijn in elke sessie beschikbaar.

Gemini CLI cli

# voeg Kleo toe (met --scope user heb je hem in elk project) gemini mcp add --transport http kleo https://mcp.kleooai.com/mcp
  1. Voer het commando hierboven uit, start dan gemini en typ /mcp auth kleo: de pagina van Kleo opent in je browser, klik op Gratis beginnen en je bent terug in Gemini CLI.
  2. Vraag in de sessie om de video. /mcp list toont elke kleo-tool.

Windsurf, de Gemini-app en je eigen agents http

Kleo is een standaard MCP-server over het Streamable HTTP-transport met OAuth 2.1. Elke compatibele client verbindt met hetzelfde adres en dezelfde start met één knop.

Serveradres https://mcp.kleooai.com/mcp
  1. Windsurf: Settings → MCP → Add server, plak het adres (zijn mcp_config.json gebruikt de sleutel "serverUrl").
  2. Gemini-app: Instellingen → Gekoppelde apps → Aangepaste apps, plak het adres (vereist momenteel Google AI Pro of Ultra).
  3. Voor je eigen agent: gebruik een MCP SDK (Python of TypeScript) met het HTTP-transport en doorloop de OAuth-flow één keer.

02Eerste verzoek

Begin met een helder verzoek.

De assistent legt je verzoek naast de intake van Kleo — onderwerp, lengte, formaat, look — en vraagt naar alles wat ontbreekt voordat hij het treatment schrijft. Noem alle vier en hij gaat meteen aan het werk. Plak dit in je eerste chat:

“Gebruik Kleo om een film van 30 seconden te plannen over een vuurtorenwachter die een flessenpost ontdekt. Realistische look, Engelse voice-over, 9:16. Laat me de opzet en de kosten in credits zien voordat de render start.”

Er zijn twee looks beschikbaar op de server: realistisch, gegenereerde live-action-footage, en animatie, een 2D-animatiefilm. Wissel het woord in de prompt en je krijgt de andere.

03Credits

Controleer je saldo vóór de productie.

Verbinden geeft je 7 credits: een animatic van je storyboard kost 5 en elk account kan er een bestellen. Een film wordt alleen gemaakt voor accounts die een pack hebben gekocht, welke pack dan ook, en een film van 30 seconden kost 15 credits, dus de eerste film begint met de pack van €5: 7 + 10 = 17 credits, genoeg voor een Short van 30 seconden.

Vraag de assistent om je accountpagina om credits te kopen, en bevestig wanneer je wilt dat de render start. Er wordt niets afgeschreven tot Kleo de job accepteert: de assistent noemt eerst de exacte credits, en een geweigerd verzoek kost niets.
