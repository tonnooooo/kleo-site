Dein Chat.
Dein Studio.

Kleo ist ein Remote-MCP-Server. Er spricht das Model Context Protocol über Streamable HTTP mit OAuth 2.1, deshalb funktioniert dieselbe Adresse in jedem Client, und das Verbinden ist ein einziger Button auf Kleos eigener Seite – kein Anmeldeformular, kein Passwort, keine Karte. Der Start ist kostenlos: 7 Credits auf deinem Konto, sobald du dich verbindest, ein Animatic. Füge Kleo zu deinem Assistenten hinzu und beschreib den Film, den du machen willst.

01Verbinden

Wähle deinen Assistenten.

Jeder Client unten benutzt dieselbe Adresse und denselben Ein-Button-Start: Adresse einfügen, Kleos Seite öffnet sich, du klickst auf Kostenlos starten, und du bist zurück im Client mit 7 Credits auf dem Konto. Das sind die Schritte, die wir getestet haben.

Cursor mcp.json

Erstelle oder bearbeite ~/.cursor/mcp.json (alle Projekte) oder .cursor/mcp.json in einem einzelnen Projekt.

{ "mcpServers": { "kleo": { "url": "https://mcp.kleooai.com/mcp" } } }
  1. Speichere die Datei: Cursor listet Kleo unter Einstellungen → MCP. Klick auf Connect (oder benutze einmal ein Tool): Kleos Seite öffnet sich, klick auf Kostenlos starten, und du bist zurück in Cursor.

VS Code mcp.json

Erstelle .vscode/mcp.json in deinem Workspace (oder führe MCP: Add Server aus der Befehlspalette aus und füge die Adresse ein).

{ "servers": { "kleo": { "type": "http", "url": "https://mcp.kleooai.com/mcp" } } }
  1. Speichere die Datei und klick dann auf Start über dem Servereintrag. VS Code öffnet Kleos Seite: Klick auf Kostenlos starten, und du bist zurück in VS Code.
  2. Wechsle im Copilot Chat in den Agent-Modus: Die kleo-Tools erscheinen in der Tool-Auswahl.

OpenCode opencode.jsonc

Füge das hier in ~/.config/opencode/opencode.jsonc (global) oder in opencode.jsonc im Projekt ein und verbinde dich dann vom Terminal aus.

{ "mcp": { "kleo": { "type": "remote", "url": "https://mcp.kleooai.com/mcp", "enabled": true } } }
# einmal verbinden (öffnet den Browser) opencode mcp auth kleo
  1. Speichere die Konfiguration und führe den Befehl oben aus: Kleos Seite öffnet sich im Browser, klick auf Kostenlos starten, und du bist zurück in OpenCode.
  2. Starte opencode und bitte um das Video: Die kleo-Tools sind in jeder Sitzung verfügbar.

Windsurf, die Gemini-App und deine eigenen Agenten http

Kleo ist ein Standard-MCP-Server über den Streamable-HTTP-Transport mit OAuth 2.1. Jeder kompatible Client verbindet sich mit derselben Adresse und demselben Ein-Button-Start.

Serveradresse https://mcp.kleooai.com/mcp
  1. Windsurf: Settings → MCP → Add server, Adresse einfügen (seine mcp_config.json benutzt den Schlüssel "serverUrl").
  2. Gemini-App: Einstellungen → Verbundene Apps → Benutzerdefinierte Apps, Adresse einfügen (erfordert derzeit Google AI Pro oder Ultra).
  3. Für deinen eigenen Agenten: Nutze ein MCP-SDK (Python oder TypeScript) mit dem HTTP-Transport und durchlaufe den OAuth-Flow einmal.

02Erste Anfrage

Fang mit einer klaren Anfrage an.

Der Assistent liest deine Anfrage gegen Kleos Intake – Thema, Länge, Format, Look – und fragt nach allem, was fehlt, bevor er das Treatment schreibt. Nenn alle vier, und er legt sofort los. Füge das in deinen ersten Chat ein:

„Plane mit Kleo einen 30-Sekunden-Film über einen Leuchtturmwärter, der eine Flaschenpost entdeckt. Realistischer Look, englische Erzählstimme, 9:16. Zeig mir die Gliederung und die Credits, bevor gerendert wird.“

Zwei Looks stehen auf dem Server zur Verfügung: realistisch, generiertes Realfilm-Footage, und Animation, ein 2D-Animationsfilm. Tausch das Wort im Prompt aus, um den anderen zu bekommen.

03Credits

Prüfe dein Guthaben vor der Produktion.

Das Verbinden bringt 7 Credits mit: Ein Animatic deines Storyboards kostet 5, und jedes Konto kann eines bestellen. Ein Film wird nur für Konten gemacht, die ein Paket gekauft haben, egal welches, und ein 30-Sekunden-Film kostet 15 Credits – der erste Film beginnt also mit dem 5-€-Paket: 7 + 10 = 17 Credits, genug für einen 30-Sekunden-Short.

Frag den Assistenten nach deiner Kontoseite, um Credits zu kaufen, und bestätige dann, wenn der Render starten soll. Berechnet wird nichts, bis Kleo den Job annimmt: Der Assistent nennt zuerst die genauen Credits, und eine abgelehnte Anfrage kostet nichts.
