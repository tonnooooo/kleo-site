Plan a longer explainer in clear chapters

A longer explainer needs a progression of questions rather than an extended introduction. Kleo's current public pages describe films up to five minutes; check the live limits before planning a deliverable around a longer running time.

A practical method

  1. Divide the subject into a few non-overlapping questions.
  2. Give each section a clear visual purpose and transition.
  3. Read the full narration for repetition before approving the treatment.

An example brief to adapt

Written illustration of this method; not a report of a rendered film or a customer result.

Outline a three-minute narrated explainer from my supplied source pack. Use an opening question, three connected sections and a concise conclusion. Explain what each section adds. Keep the visuals illustrative and flag any facts missing from the sources before production.

Review before moving on

  • Does each section advance the explanation?
  • Is the opening proportionate?
  • Does the request fit the current duration limit?

Record a concrete observation beside each check: a line in the treatment, a source passage or a timestamp in the downloaded film. If you cannot inspect an item yet, leave it open. A request in a brief is an intention; the result is what must be reviewed.

What to avoid

A sequence of unrelated mini-essays can feel longer than its running time. Remove repeated definitions and maintain one overall question through the film.
