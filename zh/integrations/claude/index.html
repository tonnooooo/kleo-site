01设置

把 Kleo 添加到 Claude。

Kleo 是一个远程 MCP 服务器。没有应用要安装，没有注册表单：Claude 通过自定义连接器访问它，而连接只是 Kleo 自己页面上的一个按钮。下面的步骤在 Claude 应用和网页版中相同，适用于 Claude 的每个方案；免费方案允许一个自定义连接器。

  1. 在 Claude 中打开设置 → 连接器，选择添加自定义连接器。
  2. 命名为 Kleo，粘贴下面的地址，确认。
  3. Kleo 的页面打开：点击免费开始。你回到了 Claude，新的 Kleo 账户里有 7 积分。没有表单，没有密码，没有银行卡：足够做一部 5 积分的动态分镜。影片只为购买过积分包的账户制作，且至少 10 积分，所以第一部影片之前要先加一个 €5 积分包（10 积分）；一部 30 秒的影片是 15 积分。
  4. 在新对话中，从工具菜单开启 Kleo，然后提出影片需求。
服务器地址 https://mcp.kleooai.com/mcp

Claude 是 Anthropic 的助手。Kleo 是一个独立的服务，Claude 通过自定义连接器访问它；同一个地址也适用于 ChatGPT、Grok、Claude Code、Cursor 和任何其他 MCP 客户端——见连接页面。

02第一条提示词

说出你想要的影片。

在一条消息里说清主题、时长、格式和风格。受众、语调和影片中必须出现的内容是可选的。你的请求里漏掉的，Claude 会在规划任何东西之前问清；它从不替你选时长、格式或风格。

“用 Kleo 做一部 30 秒的影片，讲一条小木船在黎明时分驶过平静的湖面。写实风格，16:9，英语旁白，语调平静。开始渲染前先给我看剧本大纲和准确的积分数。”

  • 风格两种风格可选：写实，带电影感的生成真人实拍画面；动画，一部 2D 动画影片。查看影片风格 →
  • 格式YouTube 用 16:9，Short 用 9:16。
  • 时长15 秒到 5 分钟。
  • 旁白英语或意大利语。
03在对话中

接下来对话里会发生什么。

Kleo 的工具按固定顺序运行，由 Claude 替你驱动。每一步你都可以阅读、修改和批准；在你点头、任务被接受之前不会扣任何费用。

01 kleo_adapt_prompt

剧本大纲

Claude 对照 Kleo 的需求清单读取你的请求。主题、时长、格式和风格是必填的；受众、语调和必须出现的内容是可选的。缺什么，它就在一条消息里问清。然后它给你看剧本大纲：故事梗概、切入角度、开场画面、幕次、结局、风格、节奏和旁白。继续之前想改什么都可以改。

02 kleo_storyboard_guide

分镜

Claude 获取 Kleo 的分镜指南（一段导演思路、场景、镜头及其限制），并在你批准的剧本大纲之下写出分镜。影片就在这里成形；请阅读它并提出修改。

03 kleo_create_video

渲染

Kleo 检查全部内容，并回复这部影片准确的积分数。得到你的同意后，Claude 在为这一个任务租用的 GPU 上开始渲染。任务被接受之前不会扣任何费用，被拒绝的调用不收费。

04 kleo_wait_for_video

链接

Claude 等待渲染并汇报进度，直到 Kleo 交出成片 MP4 的链接，通常在 25–35 分钟之后。链接 7 天内有效。Kleo 从不把影片发布到任何地方：你下载它，想发到哪里都可以。

04影片

你会得到什么。

  • 输出一个 4K（3840×2160 或 2160×3840）60 fps 的 MP4：YouTube 用 16:9，Short 用 9:16。
  • 时长影片 15 秒到 5 分钟；动态分镜 15 到 60 秒。
  • 风格写实（生成的真人实拍感画面，电影感）或动画（一部 2D 动画影片）。影片中每个镜头都从各自的画帧生成为动态画面。
  • 产品影片，或同一套分镜的动态分镜：运动镜头下的手绘画帧，同样的旁白和图形层，没有生成的视频片段。每个账户都可以订购动态分镜；影片只为购买过积分包的账户制作。
  • 旁白一位旁白，英语或意大利语。没有背景音乐，没有字幕，没有屏幕文字。
  • 积分影片：1 积分 = 2 秒，向上取整，最低 10 积分：15 秒 = 10，30 秒 = 15，60 秒 = 30，5 分钟 = 150。动态分镜：固定 5 积分。起步有 7 积分；积分包为 €5 = 10、€15 = 35、€40 = 100，一次付清，无需订阅。
  • 时间一次渲染在租用的 GPU 上通常需要 25–35 分钟；Kleo 会在对话里告诉你预计时间。

05故障排除

如果有什么不正常。

Claude 里看不到 Kleo。

检查你粘贴的地址：必须正好是 https://mcp.kleooai.com/mcp，带 https，/mcp 之后什么都没有。用 Kleo 这个名字再添加一次连接器。添加之后，它在对话里仍然是关闭的，直到你开启它：打开新对话，从工具菜单开启 Kleo。免费方案只允许一个自定义连接器，所以 Kleo 必须是那一个。

Kleo 的页面没有打开，或窗口被拦截了。

当你确认连接器时，Claude 会打开 Kleo 的页面进行登录：一个免费开始按钮，没有任何要填的。如果你的浏览器把它当作弹出窗口拦截了，请允许 Claude 的弹出窗口，再确认一次连接器；页面打开，点击免费开始，你就回到了 Claude。

积分不够。

连接会给你 7 积分：它们可以买一部动态分镜（5），永远买不到影片。影片只为购买过积分包的账户制作，一部 30 秒的影片是 15 积分：有了 €5 积分包（10 积分）你就有 17，渲染可以开始。向 Claude 索要你的 Kleo 账户页面（kleo_account）：上面显示余额和结账链接（€5 = 10 积分，€15 = 35，€40 = 100；以欧元一次性付款，无需订阅）。被拒绝的调用没有扣费。

影片还没好，等待就超时了。

一次长时间的渲染可能超过单次工具调用的时限，但任务仍在它的 GPU 上继续。让 Claude 查询任务状态（kleo_get_job）或再等一次（kleo_wait_for_video），然后索要链接（kleo_get_result）。不要为了查看第一部影片而再要一部。

你想停止渲染。

让 Claude 取消任务（kleo_cancel_job）。渲染停止，未花掉的积分退回你的余额。
