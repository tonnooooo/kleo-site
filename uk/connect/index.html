Kleo — це віддалений MCP-сервер. Він працює за Model Context Protocol через Streamable HTTP з OAuth 2.1, тож одна й та сама адреса підходить для кожного клієнта, а підключення — це одна кнопка на власній сторінці Kleo: без форми реєстрації, без пароля, без картки. Початок безкоштовний: 7 кредитів на рахунку в момент підключення, один аніматик. Додайте Kleo до свого асистента й опишіть фільм, який хочете зробити.

01Підключення

Виберіть свій асистент.

Кожен клієнт нижче використовує ту саму адресу й той самий старт однією кнопкою: вставляєте адресу, відкривається сторінка Kleo, ви натискаєте Start free — і ви знову в клієнті із 7 кредитами на рахунку. Ось кроки, які ми перевірили.

Адреса сервера https://mcp.kleooai.com/mcp

  2. Назвіть його Kleo, вставте адресу вище й підтвердьте. Відкриється сторінка Kleo: натисніть Start free — і ви знову в Claude.
  3. У новому чаті увімкніть Kleo в меню інструментів і попросіть: Зроби мені 45-секундний Short про…

ChatGPT режим розробника

Адреса сервера https://mcp.kleooai.com/mcp
  1. Відкрийте Settings → Apps & Connectors (у старіших версіях — Connectors), далі Advanced settings, і увімкніть Developer mode.
  2. Поверніться в Connectors і виберіть Create: назвіть його Kleo, вставте адресу, виберіть автентифікацію OAuth і збережіть. Відкриється сторінка Kleo: натисніть Start free — і ви знову в ChatGPT.
  3. У чаті увімкніть Kleo через меню + і попросіть відео. ChatGPT попросить підтвердження, перш ніж запустити рендер.

Grok конектори

Адреса сервера https://mcp.kleooai.com/mcp
  1. На grok.com або в застосунку відкрийте Settings → Connectors і виберіть Add connector → Custom.
  2. Назвіть його Kleo, вставте адресу й підтвердьте. Відкриється сторінка Kleo: натисніть Start free — і ви знову в Grok.
  3. У чаті увімкніть Kleo в списку конекторів і попросіть відео.

Claude Code cli

# додайте Kleo один раз (додайте --scope user, щоб мати його в кожному проєкті) claude mcp add --transport http kleo https://mcp.kleooai.com/mcp # далі, всередині сесії: /mcp → Kleo → Authenticate
  1. Виконайте команду вище, потім у сесії введіть /mcp, виберіть Kleo і Authenticate: у браузері відкриється сторінка Kleo, натисніть Start free — і ви знову в Claude Code.
  2. Попросіть: Use kleo for a 5-minute video on the history of coffee, 16:9. Claude Code сам стежить за прогресом і передає вам посилання.

Cursor mcp.json

Створіть або відредагуйте ~/.cursor/mcp.json (усі проєкти) або .cursor/mcp.json усередині одного проєкту.

{ "mcpServers": { "kleo": { "url": "https://mcp.kleooai.com/mcp" } } }
  1. Збережіть файл: Cursor покаже Kleo у Settings → MCP. Натисніть Connect (або один раз скористайтеся інструментом): відкриється сторінка Kleo, натисніть Start free — і ви знову в Cursor.

VS Code mcp.json

Створіть .vscode/mcp.json у своєму робочому просторі (або виконайте MCP: Add Server з палітри команд і вставте адресу).

{ "servers": { "kleo": { "type": "http", "url": "https://mcp.kleooai.com/mcp" } } }
  1. Збережіть файл, потім натисніть Start над записом сервера. VS Code відкриє сторінку Kleo: натисніть Start free — і ви знову у VS Code.
  2. У Copilot Chat перейдіть у режим Agent: інструменти kleo з’являться в списку інструментів.

OpenCode opencode.jsonc

Додайте це до ~/.config/opencode/opencode.jsonc (глобально) або до opencode.jsonc у проєкті, потім підключіться з термінала.

{ "mcp": { "kleo": { "type": "remote", "url": "https://mcp.kleooai.com/mcp", "enabled": true } } }
# підключіться один раз (відкриє браузер) opencode mcp auth kleo
  1. Збережіть конфігурацію й виконайте команду вище: у браузері відкриється сторінка Kleo, натисніть Start free — і ви знову в OpenCode.
  2. Запустіть opencode і попросіть відео: інструменти kleo доступні в кожній сесії.

Gemini CLI cli

# додайте Kleo (додайте --scope user, щоб мати його в кожному проєкті) gemini mcp add --transport http kleo https://mcp.kleooai.com/mcp
  1. Виконайте команду вище, потім запустіть gemini і введіть /mcp auth kleo: у браузері відкриється сторінка Kleo, натисніть Start free — і ви знову в Gemini CLI.
  2. Попросіть відео в сесії. /mcp list показує всі інструменти kleo.

Windsurf, застосунок Gemini і ваші власні агенти http

Kleo — стандартний MCP-сервер із транспортом Streamable HTTP та OAuth 2.1. Будь-який сумісний клієнт підключається за тією самою адресою з тим самим стартом однією кнопкою.

Адреса сервера https://mcp.kleooai.com/mcp
  1. Windsurf: Settings → MCP → Add server, вставте адресу (його mcp_config.json використовує ключ "serverUrl").
  2. Застосунок Gemini: Settings → Connected apps → Custom apps, вставте адресу (наразі потрібен Google AI Pro або Ultra).
  3. Для власного агента: скористайтеся MCP SDK (Python або TypeScript) з HTTP-транспортом і один раз пройдіть OAuth.

02Перший запит

Почніть із чіткого запиту.

Асистент звіряє ваш запит зі списком уточнень Kleo — тема, тривалість, формат, стиль — і запитує про все, чого бракує, перш ніж написати тритмент. Назвіть усі чотири — і він одразу береться до роботи. Вставте це у свій перший чат:

«Скористайся Kleo, щоб спланувати 30-секундний фільм про доглядача маяка, який знаходить послання в пляшці. Реалістичний стиль, нарація англійською, 9:16. Покажи мені план і вартість у кредитах, перш ніж запускати рендер.»

На сервері доступні два стилі: реалістичний — згенероване ігрове відео, і анімаційний — 2D-анімаційний фільм. Замініть слово в промпті, щоб отримати інший.

03Кредити

Перевірте баланс перед виробництвом.

Підключення включає 7 кредитів: аніматик вашого сторіборду коштує 5, і замовити його може кожен обліковий запис. Фільм створюється лише для облікових записів, які купили пакет, будь-який, а 30-секундний фільм коштує 15 кредитів, тож перший фільм починається з пакета за €5: 7 + 10 = 17 кредитів, досить на 30-секундний Short.

Попросіть асистента показати сторінку вашого облікового запису, щоб купити кредити, а потім підтвердьте, коли хочете запустити рендер. Нічого не списується, доки Kleo не прийме завдання: асистент спершу називає точну кількість кредитів, а відхилений запит нічого не коштує.

Що відбувається після підключення.

Робочий процес, інструмент за інструментом

Уточнення, тритмент, сторіборд, рендер, посилання: що робить кожен інструмент kleo, у тому порядку, в якому їх запускає асистент, і як перевіряються кредити, перш ніж орендувати GPU.
