知っていること。

最終更新 2026年9月14日

要約。あなたはKleoにメールアドレスもパスワードも渡さないので、Kleoはそれを持っていません。あなたのアカウントは、ブラウザ内の署名付きクッキーです。

Kleoは動画を作り、クレジットを数えるために必要なものを保持します。あなたが依頼した内容、Kleoが書いた絵コンテ、Kleoが作ったファイル。完成したファイルは7日後に削除されます。

このウェブサイトにはトラッカーも、アナリティクスも、広告もなく、クッキーを一切設定しません。唯一記憶するのは、各ページの下部にある切り替えであなたが選んだ言語で、ブラウザのローカルストレージに保存され、あなたのブラウザ以外の誰にも読まれません。言語を選ぶまでは、各ページはブラウザが優先する言語で開きます。

あなたのアカウントはクッキーです

Start freeを押すと、Kleoは名前もアドレスもないアカウントを作成し、Kleoサーバー自身のドメインにkleo_idというクッキーでそれを記憶します。クッキーに含まれるのはアカウント番号と署名だけで、それ以外は何もありません。有効期間は約400日です。

アカウントはそのブラウザの中にあるため、クッキーを消去するとアカウントは失われ——残りのクレジットも一緒に失われます——事前にKleoキーを保存していた場合を除きます。アシスタントはいつでもキーを表示できます。

Kleoが匿名アカウントに保存するアドレスはあなたのものではありません。@anon.kleo.invalidで終わる内部のプレースホルダーで、アカウントテーブルが常にアドレスを必要としてきたためです。Kleoはそこに書き込むことができず、あなたを特定するものでもありません。

あなたのインターネット上のアドレス

KleoはあなたのIPアドレスを保存しません。ひとりの人がその日の初期アカウントをすべて取ってしまうのを防ぐため、その一方向のフィンガープリント——アドレスと秘密の値から計算した数値で、アドレスに戻すことはできません——を保存します。用途はひとつだけ、今日同じ場所から何件の新規アカウントが作られたかを数えることです。

他に誰が見るか

Kleoはひとりの人間のプロジェクトで、少数のサービスの上に成り立っています。あなたの動画を作るために、依頼が通過するのは以下のサービスです:

  • Cloudflare — Kleoのサーバー、データベース、そして完成したファイルが7日間置かれるストレージを運用します。一部の絵コンテはCloudflare自身のAIによっても書かれます。
  • Vast.ai — Kleoが動画にかかる分だけGPUマシンをレンタルするマーケットプレイス。マシンは絵コンテを受け取って動画を返し、ジョブが終わると破棄されます。
  • kie.ai — Kleoのフレームとプロンプトから、フィルムのショットの動く映像を生成します。アニマティックはクリップを注文しないため、その内容がkie.aiに届くことはありません。
  • GitHub — このウェブサイトをホストします。
  • Stripe — 決済画面を通じてクレジットパックの支払いを処理します。あなたのカード情報がKleoに届くことはありません。
  • 接続したアシスタント — Claude、ChatGPT、Grok、Cursor、その他。あなたが入力するものはまずそこに入力され、それぞれのプライバシーポリシーの対象になります。Kleoは、アシスタントが送ってくる依頼以外、あなたの会話を見ることはできません。

これらのマシンはひとつの国にあるわけではありません。レンタルしたGPUは所有者が置いている場所ならどこにでもあり得るため、動画は世界のどこでレンダリングされることもあります。

Kleoが決してしないこと

  • 広告はなく、誰にも何も販売しません。
  • このウェブサイトにアナリティクス、トラッキングピクセル、クッキーはありません。ページからページへあなたを追うものは何もありません。
  • あなたのプロンプトと動画が、Kleoやその他何かの学習に使われることはありません。映像プロバイダーのkie.aiは、フィルムのショットのプロンプトとフレームを自身の規約のもとで処理します。アニマティックは何も送りません。
  • Kleoはメールを送りません。送る先のアドレスを持たず、ニュースレターも存在しません。

データを取得する、または削除する

kleooai@gmail.comにアカウント番号を添えて（非公開のKleoキーは決して送らないでください）——番号はアシスタントが表示できます——ご希望をお書きください。保管されている内容のコピー、訂正、またはアカウント全体の削除。削除は取り消せません。クレジットも一緒に消えます。

Kleoはひとりの人間が運営しています。ここに納得できない点があれば、まずご連絡ください。お住まいの国のデータ保護当局に苦情を申し立てる権利もあります。
