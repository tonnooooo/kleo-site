Chat Anda.
Studio Anda.

Kleo adalah server MCP jarak jauh. Ia berbicara dengan Model Context Protocol melalui Streamable HTTP dengan OAuth 2.1, jadi alamat yang sama bekerja di setiap klien, dan menghubungkannya cukup satu tombol di halaman Kleo sendiri — tanpa formulir pendaftaran, tanpa kata sandi, tanpa kartu. Gratis untuk memulai: 7 kredit masuk ke akun Anda begitu Anda terhubung, satu animatic. Tambahkan ke asisten Anda dan jelaskan film yang ingin Anda buat.

01Hubungkan

Pilih asisten Anda.

Setiap klien di bawah ini memakai alamat yang sama dan cara mulai satu tombol yang sama: tempel alamatnya, halaman Kleo terbuka, Anda mengklik Start free, dan Anda kembali ke klien dengan 7 kredit di akun. Ini langkah-langkah yang sudah kami uji.

Claude aplikasi · web

Alamat server https://mcp.kleooai.com/mcp
  1. Buka Settings → Connectors dan pilih Add custom connector.
  2. Beri nama Kleo, tempel alamat di atas, lalu konfirmasi. Halaman Kleo terbuka: klik Start free dan Anda kembali ke Claude.
  3. Di chat baru, aktifkan Kleo dari menu tools dan minta: Buatkan saya Short 45 detik tentang…

Paket Claude gratis mengizinkan satu konektor kustom.

ChatGPT developer mode

Alamat server https://mcp.kleooai.com/mcp
  1. Buka Settings → Apps & Connectors (disebut Connectors di versi lama), lalu Advanced settings, dan aktifkan Developer mode.
  2. Kembali di Connectors, pilih Create: beri nama Kleo, tempel alamatnya, atur autentikasi ke OAuth, lalu simpan. Halaman Kleo terbuka: klik Start free dan Anda kembali ke ChatGPT.
  3. Di chat, aktifkan Kleo dari menu + dan minta videonya. ChatGPT meminta konfirmasi Anda sebelum memulai render.

Memerlukan ChatGPT Plus, Pro, Business, atau Enterprise.

Grok konektor

Alamat server https://mcp.kleooai.com/mcp
  1. Di grok.com atau di aplikasi, buka Settings → Connectors dan pilih Add connector → Custom.
  2. Beri nama Kleo, tempel alamatnya, lalu konfirmasi. Halaman Kleo terbuka: klik Start free dan Anda kembali ke Grok.
  3. Di chat, aktifkan Kleo di daftar konektor dan minta videonya.

Claude Code cli

# tambahkan Kleo sekali (tambahkan --scope user agar tersedia di setiap proyek) claude mcp add --transport http kleo https://mcp.kleooai.com/mcp # lalu, di dalam sesi: /mcp → Kleo → Authenticate
  1. Jalankan perintah di atas, lalu ketik /mcp di sebuah sesi, pilih Kleo dan Authenticate: halaman Kleo terbuka di browser Anda, klik Start free dan Anda kembali ke Claude Code.
  2. Minta: Gunakan kleo untuk video 5 menit tentang sejarah kopi, 16:9. Claude Code memeriksa progresnya untuk Anda dan menyerahkan tautannya.

Cursor mcp.json

Buat atau edit ~/.cursor/mcp.json (semua proyek) atau .cursor/mcp.json di dalam satu proyek.

{ "mcpServers": { "kleo": { "url": "https://mcp.kleooai.com/mcp" } } }
  1. Simpan berkasnya: Cursor mencantumkan Kleo di Settings → MCP. Klik Connect (atau gunakan sebuah tool sekali): halaman Kleo terbuka, klik Start free dan Anda kembali ke Cursor.

VS Code mcp.json

Buat .vscode/mcp.json di workspace Anda (atau jalankan MCP: Add Server dari Command Palette dan tempel alamatnya).

{ "servers": { "kleo": { "type": "http", "url": "https://mcp.kleooai.com/mcp" } } }
  1. Simpan berkasnya, lalu klik Start di atas entri server. VS Code membuka halaman Kleo: klik Start free dan Anda kembali ke VS Code.
  2. Di Copilot Chat, beralih ke mode Agent: tool kleo muncul di pemilih tool.

OpenCode opencode.jsonc

Tambahkan ini ke ~/.config/opencode/opencode.jsonc (global) atau ke opencode.jsonc di dalam proyek, lalu hubungkan dari terminal.

{ "mcp": { "kleo": { "type": "remote", "url": "https://mcp.kleooai.com/mcp", "enabled": true } } }
# hubungkan sekali (membuka browser) opencode mcp auth kleo
  1. Simpan konfigurasinya dan jalankan perintah di atas: halaman Kleo terbuka di browser, klik Start free dan Anda kembali ke OpenCode.
  2. Jalankan opencode dan minta videonya: tool kleo tersedia di setiap sesi.

Gemini CLI cli

# tambahkan Kleo (tambahkan --scope user agar tersedia di setiap proyek) gemini mcp add --transport http kleo https://mcp.kleooai.com/mcp
  1. Jalankan perintah di atas, lalu jalankan gemini dan ketik /mcp auth kleo: halaman Kleo terbuka di browser Anda, klik Start free dan Anda kembali ke Gemini CLI.
  2. Minta videonya di dalam sesi. /mcp list menampilkan setiap tool kleo.

Windsurf, aplikasi Gemini, dan agen Anda sendiri http

Kleo adalah server MCP standar melalui transport Streamable HTTP dengan OAuth 2.1. Klien apa pun yang kompatibel terhubung dengan alamat yang sama dan cara mulai satu tombol yang sama.

Alamat server https://mcp.kleooai.com/mcp
  1. Windsurf: Settings → MCP → Add server, tempel alamatnya (mcp_config.json-nya memakai kunci "serverUrl").
  2. Aplikasi Gemini: Settings → Connected apps → Custom apps, tempel alamatnya (saat ini memerlukan Google AI Pro atau Ultra).
  3. Untuk agen Anda sendiri: gunakan MCP SDK (Python atau TypeScript) dengan transport HTTP dan selesaikan alur OAuth sekali.

02Permintaan pertama

Mulai dengan permintaan yang jelas.

Asisten membaca permintaan Anda berdasarkan intake Kleo — subjek, durasi, format, look — dan menanyakan apa pun yang kurang sebelum menulis treatment. Sebutkan keempatnya dan ia langsung bekerja. Tempel ini di chat pertama Anda:

“Gunakan Kleo untuk merencanakan film 30 detik tentang penjaga mercusuar yang menemukan pesan dalam botol. Look realistis, narasi bahasa Inggris, 9:16. Tunjukkan kerangkanya dan biaya kreditnya sebelum me-render.”

Dua look tersedia di server: realistis, footage live-action yang dihasilkan, dan animasi, film animasi 2D. Ganti kata di prompt untuk mendapatkan yang satunya.

03Kredit

Periksa saldo Anda sebelum produksi.

Menghubungkan sudah termasuk 7 kredit: animatic dari storyboard Anda berharga 5 dan setiap akun bisa memesannya. Film hanya dibuat untuk akun yang sudah membeli paket, paket apa pun, dan film 30 detik berharga 15 kredit, jadi film pertama dimulai dengan paket €5: 7 + 10 = 17 kredit, cukup untuk Short 30 detik.

Minta halaman akun Anda kepada asisten untuk membeli kredit, lalu konfirmasi ketika Anda ingin render dimulai. Tidak ada yang ditagih sampai Kleo menerima job: asisten menyebutkan jumlah kredit yang pasti lebih dulu, dan permintaan yang ditolak tidak berbiaya apa pun.
