Twój czat.
Twoje studio.

Kleo to zdalny serwer MCP. Mówi Model Context Protocol przez Streamable HTTP z OAuth 2.1, więc ten sam adres działa w każdym kliencie, a podłączenie to jeden przycisk na stronie Kleo — bez formularza rejestracji, bez hasła, bez karty. Start jest darmowy: 7 kredytów na koncie w chwili podłączenia, jeden animatik. Dodaj Kleo do swojego asystenta i opisz film, który chcesz zrobić.

01Podłączenie

Wybierz swojego asystenta.

Każdy klient poniżej używa tego samego adresu i tego samego startu jednym przyciskiem: wklejasz adres, otwiera się strona Kleo, klikasz Start free i wracasz do klienta z 7 kredytami na koncie. Oto kroki, które przetestowaliśmy.

Claude aplikacja · web

Adres serwera https://mcp.kleooai.com/mcp
  1. Otwórz Settings → Connectors i wybierz Add custom connector.
  2. Nazwij go Kleo, wklej powyższy adres i potwierdź. Otwiera się strona Kleo: kliknij Start free i wracasz do Claude.
  3. W nowym czacie włącz Kleo w menu narzędzi i poproś: Zrób mi 45-sekundowy Short o…

Darmowy plan Claude pozwala na jeden własny konektor.

ChatGPT tryb dewelopera

Adres serwera https://mcp.kleooai.com/mcp
  1. Otwórz Settings → Apps & Connectors (w starszych wersjach Connectors), potem Advanced settings i włącz Developer mode.
  2. Z powrotem w Connectors wybierz Create: nazwij go Kleo, wklej adres, ustaw uwierzytelnianie na OAuth i zapisz. Otwiera się strona Kleo: kliknij Start free i wracasz do ChatGPT.
  3. Na czacie włącz Kleo w menu + i poproś o film. ChatGPT prosi Cię o potwierdzenie, zanim zacznie render.

Wymaga ChatGPT Plus, Pro, Business lub Enterprise.

Grok konektory

Adres serwera https://mcp.kleooai.com/mcp
  1. Na grok.com lub w aplikacji otwórz Settings → Connectors i wybierz Add connector → Custom.
  2. Nazwij go Kleo, wklej adres i potwierdź. Otwiera się strona Kleo: kliknij Start free i wracasz do Groka.
  3. Na czacie włącz Kleo na liście konektorów i poproś o wideo.

Claude Code cli

# dodaj Kleo raz (dodaj --scope user, żeby mieć je w każdym projekcie) claude mcp add --transport http kleo https://mcp.kleooai.com/mcp # potem, w sesji: /mcp → Kleo → Authenticate
  1. Uruchom powyższe polecenie, potem w sesji wpisz /mcp, wybierz Kleo i Authenticate: strona Kleo otwiera się w przeglądarce, kliknij Start free i wracasz do Claude Code.
  2. Poproś: Użyj kleo do 5-minutowego filmu o historii kawy, 16:9. Claude Code sam sprawdza postęp i przekazuje Ci linki.

Cursor mcp.json

Utwórz lub edytuj ~/.cursor/mcp.json (wszystkie projekty) albo .cursor/mcp.json w jednym projekcie.

{ "mcpServers": { "kleo": { "url": "https://mcp.kleooai.com/mcp" } } }
  1. Zapisz plik: Cursor pokaże Kleo w Settings → MCP. Kliknij Connect (albo użyj raz dowolnego narzędzia): otwiera się strona Kleo, kliknij Start free i wracasz do Cursora.

VS Code mcp.json

Utwórz .vscode/mcp.json w swoim obszarze roboczym (albo uruchom MCP: Add Server z palety poleceń i wklej adres).

{ "servers": { "kleo": { "type": "http", "url": "https://mcp.kleooai.com/mcp" } } }
  1. Zapisz plik, potem kliknij Start nad wpisem serwera. VS Code otwiera stronę Kleo: kliknij Start free i wracasz do VS Code.
  2. W Copilot Chat przełącz się w tryb Agent: narzędzia kleo pojawią się w wyborze narzędzi.

OpenCode opencode.jsonc

Dodaj to do ~/.config/opencode/opencode.jsonc (globalnie) albo do opencode.jsonc w projekcie, potem podłącz z terminala.

{ "mcp": { "kleo": { "type": "remote", "url": "https://mcp.kleooai.com/mcp", "enabled": true } } }
# podłącz raz (otwiera przeglądarkę) opencode mcp auth kleo
  1. Zapisz konfigurację i uruchom powyższe polecenie: strona Kleo otwiera się w przeglądarce, kliknij Start free i wracasz do OpenCode.
  2. Uruchom opencode i poproś o wideo: narzędzia kleo są dostępne w każdej sesji.

Gemini CLI cli

# dodaj Kleo (dodaj --scope user, żeby mieć je w każdym projekcie) gemini mcp add --transport http kleo https://mcp.kleooai.com/mcp
  1. Uruchom powyższe polecenie, potem uruchom gemini i wpisz /mcp auth kleo: strona Kleo otwiera się w przeglądarce, kliknij Start free i wracasz do Gemini CLI.
  2. Poproś o wideo w sesji. /mcp list pokazuje każde narzędzie kleo.

Windsurf, aplikacja Gemini i Twoje własne agenty http

Kleo to standardowy serwer MCP na transporcie Streamable HTTP z OAuth 2.1. Każdy kompatybilny klient podłącza się tym samym adresem i tym samym startem jednym przyciskiem.

Adres serwera https://mcp.kleooai.com/mcp
  1. Windsurf: Settings → MCP → Add server, wklej adres (jego mcp_config.json używa klucza "serverUrl").
  2. Aplikacja Gemini: Settings → Connected apps → Custom apps, wklej adres (obecnie wymaga Google AI Pro lub Ultra).
  3. Dla własnego agenta: użyj MCP SDK (Python lub TypeScript) z transportem HTTP i przejdź raz przez flow OAuth.

02Pierwsza prośba

Zacznij od jasnej prośby.

Asystent porównuje Twoją prośbę z pytaniami wstępnymi Kleo — temat, długość, format, styl — i dopytuje o to, czego brakuje, zanim napisze treatment. Podaj wszystkie cztery, a od razu bierze się do pracy. Wklej to w pierwszym czacie:

„Użyj Kleo, żeby zaplanować 30-sekundowy film o latarniku, który znajduje list w butelce. Styl realistyczny, narracja po angielsku, 9:16. Pokaż mi zarys i koszt w kredytach, zanim zaczniesz render.”

Na serwerze dostępne są dwa style: realistyczny, generowany materiał aktorski, i animowany, animowany film 2D. Zamień słowo w prompcie, żeby dostać drugi.

03Kredyty

Sprawdź saldo przed produkcją.

Podłączenie daje 7 kredytów: animatik Twojego storyboardu kosztuje 5 i może go zamówić każde konto. Film powstaje tylko dla kont, które kupiły pakiet, dowolny pakiet, a 30-sekundowy film kosztuje 15 kredytów, więc pierwszy film zaczyna się od pakietu za 5 €: 7 + 10 = 17 kredytów, wystarczy na 30-sekundowego Shorta.

Poproś asystenta o stronę swojego konta, żeby kupić kredyty, a potem potwierdź, kiedy render ma się zacząć. Nic nie jest pobierane, dopóki Kleo nie przyjmie zadania: asystent najpierw podaje dokładną liczbę kredytów, a odrzucona prośba nie kosztuje nic.
