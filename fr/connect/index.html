Kleo est un serveur MCP distant. Il parle le Model Context Protocol en Streamable HTTP avec OAuth 2.1, donc la même adresse fonctionne dans tous les clients, et la connexion tient en un seul bouton sur la page de Kleo — pas de formulaire d'inscription, pas de mot de passe, pas de carte. C'est gratuit pour commencer : 7 crédits sur votre compte dès la connexion, une animatique. Ajoutez-le à votre assistant et décrivez le film que vous voulez faire.

01Connexion

Choisissez votre assistant.

Chaque client ci-dessous utilise la même adresse et le même démarrage en un bouton : vous collez l'adresse, la page de Kleo s'ouvre, vous cliquez sur Commencer gratuitement, et vous revenez dans le client avec 7 crédits sur le compte. Voici les étapes que nous avons testées.

Claude application · web

Adresse du serveur https://mcp.kleooai.com/mcp
  1. Ouvrez Paramètres → Connecteurs et choisissez Ajouter un connecteur personnalisé.
  2. Nommez-le Kleo, collez l'adresse ci-dessus et confirmez. La page de Kleo s'ouvre : cliquez sur Commencer gratuitement et vous revenez dans Claude.
  3. Dans une nouvelle conversation, activez Kleo depuis le menu des outils et demandez : Fais-moi un Short de 45 secondes sur…

L'offre gratuite de Claude autorise un connecteur personnalisé.

ChatGPT mode développeur

Adresse du serveur https://mcp.kleooai.com/mcp
  1. Ouvrez Paramètres → Applications & connecteurs (appelé Connecteurs dans les versions plus anciennes), puis Paramètres avancés, et activez le Mode développeur.
  2. De retour dans Connecteurs, choisissez Créer : nommez-le Kleo, collez l'adresse, réglez l'authentification sur OAuth et enregistrez. La page de Kleo s'ouvre : cliquez sur Commencer gratuitement et vous revenez dans ChatGPT.
  3. Dans la conversation, activez Kleo depuis le menu + et demandez la vidéo. ChatGPT vous demande confirmation avant de lancer un rendu.

Nécessite ChatGPT Plus, Pro, Business ou Enterprise.

Grok connecteurs

Adresse du serveur https://mcp.kleooai.com/mcp
  1. Sur grok.com ou dans l'application, ouvrez Paramètres → Connecteurs et choisissez Ajouter un connecteur → Personnalisé.
  2. Nommez-le Kleo, collez l'adresse et confirmez. La page de Kleo s'ouvre : cliquez sur Commencer gratuitement et vous revenez dans Grok.
  3. Dans la conversation, activez Kleo dans la liste des connecteurs et demandez la vidéo.

Claude Code cli

# ajouter Kleo une fois (ajoutez --scope user pour l'avoir dans tous les projets) claude mcp add --transport http kleo https://mcp.kleooai.com/mcp # puis, dans une session : /mcp → Kleo → Authenticate
  1. Lancez la commande ci-dessus, puis tapez /mcp dans une session, choisissez Kleo et Authenticate : la page de Kleo s'ouvre dans votre navigateur, cliquez sur Commencer gratuitement et vous revenez dans Claude Code.
  2. Demandez : Utilise kleo pour une vidéo de 5 minutes sur l'histoire du café, 16:9. Claude Code suit l'avancement pour vous et vous remet les liens.

Cursor mcp.json

Créez ou modifiez ~/.cursor/mcp.json (tous les projets) ou .cursor/mcp.json dans un seul projet.

{ "mcpServers": { "kleo": { "url": "https://mcp.kleooai.com/mcp" } } }
  1. Enregistrez le fichier : Cursor affiche Kleo sous Settings → MCP. Cliquez sur Connect (ou utilisez un outil une fois) : la page de Kleo s'ouvre, cliquez sur Commencer gratuitement et vous revenez dans Cursor.

VS Code mcp.json

Créez .vscode/mcp.json dans votre espace de travail (ou lancez MCP: Add Server depuis la palette de commandes et collez l'adresse).

{ "servers": { "kleo": { "type": "http", "url": "https://mcp.kleooai.com/mcp" } } }
  1. Enregistrez le fichier, puis cliquez sur Start au-dessus de l'entrée du serveur. VS Code ouvre la page de Kleo : cliquez sur Commencer gratuitement et vous revenez dans VS Code.
  2. Dans Copilot Chat, passez en mode Agent : les outils kleo apparaissent dans le sélecteur d'outils.

OpenCode opencode.jsonc

Ajoutez ceci à ~/.config/opencode/opencode.jsonc (global) ou à opencode.jsonc dans le projet, puis connectez-vous depuis le terminal.

{ "mcp": { "kleo": { "type": "remote", "url": "https://mcp.kleooai.com/mcp", "enabled": true } } }
# se connecter une fois (ouvre le navigateur) opencode mcp auth kleo
  1. Enregistrez la configuration et lancez la commande ci-dessus : la page de Kleo s'ouvre dans le navigateur, cliquez sur Commencer gratuitement et vous revenez dans OpenCode.
  2. Lancez opencode et demandez la vidéo : les outils kleo sont disponibles dans chaque session.

Gemini CLI cli

# ajouter Kleo (ajoutez --scope user pour l'avoir dans tous les projets) gemini mcp add --transport http kleo https://mcp.kleooai.com/mcp
  1. Lancez la commande ci-dessus, puis démarrez gemini et tapez /mcp auth kleo : la page de Kleo s'ouvre dans votre navigateur, cliquez sur Commencer gratuitement et vous revenez dans Gemini CLI.
  2. Demandez la vidéo dans la session. /mcp list affiche tous les outils kleo.

Windsurf, l'application Gemini et vos propres agents http

Kleo est un serveur MCP standard sur le transport Streamable HTTP avec OAuth 2.1. Tout client compatible se connecte avec la même adresse et le même démarrage en un bouton.

Adresse du serveur https://mcp.kleooai.com/mcp
  1. Windsurf : Settings → MCP → Add server, collez l'adresse (son mcp_config.json utilise la clé "serverUrl").
  2. Application Gemini : Paramètres → Applications connectées → Applications personnalisées, collez l'adresse (nécessite actuellement Google AI Pro ou Ultra).
  3. Pour votre propre agent : utilisez un SDK MCP (Python ou TypeScript) avec le transport HTTP et effectuez le flux OAuth une fois.

02Première requête

Commencez par une requête claire.

L'assistant lit votre requête à l'aune du cadrage de Kleo — sujet, durée, format, look — et demande ce qui manque avant d'écrire le traitement. Dites les quatre et il se met directement au travail. Collez ceci dans votre première conversation :

« Utilise Kleo pour planifier un film de 30 secondes sur un gardien de phare qui découvre un message dans une bouteille. Look réaliste, narration en anglais, 9:16. Montre-moi le synopsis et le coût en crédits avant le rendu. »

Deux looks sont disponibles sur le serveur : réaliste, des séquences de prises de vue réelles générées, et animation, un film d'animation 2D. Changez le mot dans le prompt pour obtenir l'autre.

03Crédits

Vérifiez votre solde avant la production.

La connexion inclut 7 crédits : une animatique de votre storyboard coûte 5 et tout compte peut en commander une. Un film n'est réalisé que pour les comptes qui ont acheté un pack, n'importe lequel, et un film de 30 secondes coûte 15 crédits, donc le premier film commence avec le pack à 5 € : 7 + 10 = 17 crédits, de quoi faire un Short de 30 secondes.

Demandez à l'assistant votre page de compte pour acheter des crédits, puis confirmez quand vous voulez lancer le rendu. Rien n'est débité tant que Kleo n'a pas accepté le job : l'assistant annonce d'abord les crédits exacts, et une requête refusée ne coûte rien.
