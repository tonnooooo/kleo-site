आपकी चैट।
आपका स्टूडियो।

Kleo एक रिमोट MCP सर्वर है। यह OAuth 2.1 के साथ Streamable HTTP पर Model Context Protocol बोलता है, इसलिए वही पता हर क्लाइंट में काम करता है, और कनेक्ट करना Kleo के अपने पेज पर बस एक बटन है — न साइन-अप फ़ॉर्म, न पासवर्ड, न कार्ड। शुरुआत मुफ़्त है: कनेक्ट करते ही आपके अकाउंट में 7 क्रेडिट, एक एनिमैटिक। इसे अपने असिस्टेंट में जोड़ें और बताएँ कि आप कौन-सी फ़िल्म बनाना चाहते हैं।

01कनेक्ट करें

अपना असिस्टेंट चुनें।

नीचे दिया हर क्लाइंट वही पता और वही एक-बटन वाली शुरुआत इस्तेमाल करता है: पता पेस्ट करें, Kleo का पेज खुलता है, आप Start free पर क्लिक करते हैं, और आप अकाउंट में 7 क्रेडिट के साथ वापस क्लाइंट में हैं। ये वे स्टेप हैं जो हमने टेस्ट किए।

Claude ऐप · वेब

सर्वर का पता https://mcp.kleooai.com/mcp
  1. Settings → Connectors खोलें और Add custom connector चुनें।
  2. नाम Kleo रखें, ऊपर दिया पता पेस्ट करें और कन्फ़र्म करें। Kleo का पेज खुलता है: Start free पर क्लिक करें और आप वापस Claude में हैं।
  3. नई चैट में, टूल्स मेनू से Kleo चालू करें और कहें: मेरे लिए 45 सेकंड का Short बनाओ, जिसमें…

Claude के फ़्री प्लान में एक कस्टम कनेक्टर की अनुमति है।

ChatGPT डेवलपर मोड

सर्वर का पता https://mcp.kleooai.com/mcp
  1. Settings → Apps & Connectors खोलें (पुराने वर्ज़न में Connectors), फिर Advanced settings, और Developer mode चालू करें।
  2. वापस Connectors में, Create चुनें: नाम Kleo रखें, पता पेस्ट करें, ऑथेंटिकेशन OAuth पर सेट करें और सेव करें। Kleo का पेज खुलता है: Start free पर क्लिक करें और आप वापस ChatGPT में हैं।
  3. चैट में, + मेनू से Kleo चालू करें और वीडियो माँगें। रेंडर शुरू करने से पहले ChatGPT आपसे कन्फ़र्म करने को कहता है।

इसके लिए ChatGPT Plus, Pro, Business या Enterprise चाहिए।

Grok कनेक्टर

सर्वर का पता https://mcp.kleooai.com/mcp
  1. grok.com पर या ऐप में, Settings → Connectors खोलें और Add connector → Custom चुनें।
  2. नाम Kleo रखें, पता पेस्ट करें और कन्फ़र्म करें। Kleo का पेज खुलता है: Start free पर क्लिक करें और आप वापस Grok में हैं।
  3. चैट में, कनेक्टर की सूची से Kleo चालू करें और वीडियो माँगें।

Claude Code cli

# Kleo एक बार जोड़ें (हर प्रोजेक्ट में रखने के लिए --scope user जोड़ें) claude mcp add --transport http kleo https://mcp.kleooai.com/mcp # फिर, सेशन के अंदर: /mcp → Kleo → Authenticate
  1. ऊपर दी गई कमांड चलाएँ, फिर सेशन में /mcp टाइप करें, Kleo और Authenticate चुनें: Kleo का पेज आपके ब्राउज़र में खुलता है, Start free पर क्लिक करें और आप वापस Claude Code में हैं।
  2. कहें: Use kleo for a 5-minute video on the history of coffee, 16:9। Claude Code आपके लिए प्रगति जाँचता है और आपको लिंक सौंप देता है।

Cursor mcp.json

~/.cursor/mcp.json (सभी प्रोजेक्ट) या किसी एक प्रोजेक्ट के अंदर .cursor/mcp.json बनाएँ या एडिट करें।

{ "mcpServers": { "kleo": { "url": "https://mcp.kleooai.com/mcp" } } }
  1. फ़ाइल सेव करें: Cursor Settings → MCP के नीचे Kleo दिखाता है। Connect पर क्लिक करें (या एक बार कोई टूल इस्तेमाल करें): Kleo का पेज खुलता है, Start free पर क्लिक करें और आप वापस Cursor में हैं।

VS Code mcp.json

अपने वर्कस्पेस में .vscode/mcp.json बनाएँ (या Command Palette से MCP: Add Server चलाएँ और पता पेस्ट करें)।

{ "servers": { "kleo": { "type": "http", "url": "https://mcp.kleooai.com/mcp" } } }
  1. फ़ाइल सेव करें, फिर सर्वर एंट्री के ऊपर Start पर क्लिक करें। VS Code Kleo का पेज खोलता है: Start free पर क्लिक करें और आप वापस VS Code में हैं।
  2. Copilot Chat में Agent मोड पर जाएँ: kleo टूल टूल पिकर में दिखते हैं।

OpenCode opencode.jsonc

इसे ~/.config/opencode/opencode.jsonc (ग्लोबल) में या प्रोजेक्ट की opencode.jsonc में जोड़ें, फिर टर्मिनल से कनेक्ट करें।

{ "mcp": { "kleo": { "type": "remote", "url": "https://mcp.kleooai.com/mcp", "enabled": true } } }
# एक बार कनेक्ट करें (ब्राउज़र खुलता है) opencode mcp auth kleo
  1. कॉन्फ़िग सेव करें और ऊपर दी गई कमांड चलाएँ: Kleo का पेज ब्राउज़र में खुलता है, Start free पर क्लिक करें और आप वापस OpenCode में हैं।
  2. opencode शुरू करें और वीडियो माँगें: kleo टूल हर सेशन में उपलब्ध हैं।

Gemini CLI cli

# Kleo जोड़ें (हर प्रोजेक्ट में रखने के लिए --scope user जोड़ें) gemini mcp add --transport http kleo https://mcp.kleooai.com/mcp
  1. ऊपर दी गई कमांड चलाएँ, फिर gemini शुरू करें और /mcp auth kleo टाइप करें: Kleo का पेज आपके ब्राउज़र में खुलता है, Start free पर क्लिक करें और आप वापस Gemini CLI में हैं।
  2. सेशन में वीडियो माँगें। /mcp list हर kleo टूल दिखाता है।

Windsurf, Gemini ऐप और आपके अपने एजेंट http

Kleo OAuth 2.1 के साथ Streamable HTTP ट्रांसपोर्ट पर एक स्टैंडर्ड MCP सर्वर है। कोई भी कम्पैटिबल क्लाइंट उसी पते और उसी एक-बटन वाली शुरुआत से कनेक्ट होता है।

सर्वर का पता https://mcp.kleooai.com/mcp
  1. Windsurf: Settings → MCP → Add server, पता पेस्ट करें (इसकी mcp_config.json में की "serverUrl" इस्तेमाल होती है)।
  2. Gemini ऐप: Settings → Connected apps → Custom apps, पता पेस्ट करें (फ़िलहाल Google AI Pro या Ultra चाहिए)।
  3. अपने एजेंट के लिए: HTTP ट्रांसपोर्ट के साथ कोई MCP SDK (Python या TypeScript) इस्तेमाल करें और OAuth फ़्लो एक बार पूरा करें।

02पहली रिक्वेस्ट

एक साफ़ रिक्वेस्ट से शुरू करें।

असिस्टेंट आपकी रिक्वेस्ट को Kleo के इनटेक — विषय, लंबाई, फ़ॉर्मैट, लुक — से मिलाकर पढ़ता है और ट्रीटमेंट लिखने से पहले जो कुछ छूटा हो, वह पूछता है। चारों बता दें और वह सीधे काम पर लग जाता है। अपनी पहली चैट में यह पेस्ट करें:

“Kleo से एक लाइटहाउस कीपर पर 30 सेकंड की फ़िल्म प्लान करो, जिसे बोतल में एक संदेश मिलता है। रियलिस्टिक लुक, अंग्रेज़ी नैरेशन, 9:16। रेंडर से पहले मुझे आउटलाइन और क्रेडिट की कीमत दिखाओ।”

सर्वर पर दो लुक उपलब्ध हैं: रियलिस्टिक, जेनरेटेड लाइव-एक्शन फ़ुटेज, और एनिमेशन, एक 2D एनिमेटेड फ़िल्म। दूसरा लुक पाने के लिए प्रॉम्प्ट में शब्द बदल दें।

03क्रेडिट

प्रोडक्शन से पहले अपना बैलेंस जाँचें।

कनेक्ट करने पर 7 क्रेडिट शामिल हैं: आपके स्टोरीबोर्ड के एनिमैटिक की कीमत 5 है और हर अकाउंट एक ऑर्डर कर सकता है। फ़िल्म सिर्फ़ उन अकाउंट के लिए बनती है जिन्होंने पैक ख़रीदा है, कोई भी पैक, और 30 सेकंड की फ़िल्म की कीमत 15 क्रेडिट है, इसलिए पहली फ़िल्म €5 के पैक से शुरू होती है: 7 + 10 = 17 क्रेडिट, 30 सेकंड के Short के लिए काफ़ी।

क्रेडिट ख़रीदने के लिए असिस्टेंट से अपना अकाउंट पेज माँगें, फिर जब रेंडर शुरू कराना हो, कन्फ़र्म करें। जब तक Kleo जॉब स्वीकार नहीं करता, कुछ भी चार्ज नहीं होता: असिस्टेंट पहले सटीक क्रेडिट बताता है, और अस्वीकृत रिक्वेस्ट की कोई कीमत नहीं।
