당신의 스튜디오.

Kleo는 원격 MCP 서버입니다. Streamable HTTP와 OAuth 2.1 위에서 Model Context Protocol로 통신하므로 같은 주소가 모든 클라이언트에서 작동하고, 연결은 Kleo 페이지의 버튼 하나로 끝납니다. 가입 양식도, 비밀번호도, 카드도 없습니다. 무료로 시작할 수 있습니다. 연결하는 순간 계정에 7크레딧, 애니매틱 한 편 분량이 들어옵니다. 어시스턴트에 추가하고 만들고 싶은 필름을 설명하세요.

01연결

어시스턴트를 고르세요.

아래 모든 클라이언트는 같은 주소와 같은 원버튼 시작을 사용합니다. 주소를 붙여 넣으면 Kleo 페이지가 열리고, 무료로 시작을 누르면 계정에 7크레딧이 담긴 채로 클라이언트로 돌아옵니다. 저희가 직접 테스트한 단계입니다.

Claude 앱 · 웹

서버 주소 https://mcp.kleooai.com/mcp
  1. 설정 → 커넥터를 열고 사용자 지정 커넥터 추가를 선택하세요.
  2. 이름을 Kleo로 정하고 위 주소를 붙여 넣은 뒤 확인하세요. Kleo 페이지가 열리면 무료로 시작을 누르세요. 그러면 다시 Claude로 돌아옵니다.
  3. 새 채팅에서 도구 메뉴에서 Kleo를 켜고 이렇게 요청하세요: …에 관한 45초짜리 쇼츠를 만들어 줘

Claude 무료 플랜에서는 사용자 지정 커넥터를 하나 추가할 수 있습니다.

ChatGPT 개발자 모드

서버 주소 https://mcp.kleooai.com/mcp
  1. 설정 → 앱 & 커넥터(이전 버전에서는 커넥터)를 열고 고급 설정에서 개발자 모드를 켜세요.
  2. 다시 커넥터로 돌아가 만들기를 선택하세요. 이름은 Kleo, 주소를 붙여 넣고 인증을 OAuth로 설정한 뒤 저장하세요. Kleo 페이지가 열리면 무료로 시작을 누르세요. 그러면 다시 ChatGPT로 돌아옵니다.
  3. 채팅에서 + 메뉴로 Kleo를 켜고 영상을 요청하세요. ChatGPT는 렌더링을 시작하기 전에 확인을 요청합니다.

Grok 커넥터

서버 주소 https://mcp.kleooai.com/mcp
  1. grok.com 또는 앱에서 설정 → 커넥터를 열고 커넥터 추가 → 사용자 지정을 선택하세요.
  2. 이름을 Kleo로 정하고 주소를 붙여 넣은 뒤 확인하세요. Kleo 페이지가 열리면 무료로 시작을 누르세요. 그러면 다시 Grok으로 돌아옵니다.
  3. 채팅에서 커넥터 목록의 Kleo를 켜고 영상을 요청하세요.

Claude Code cli

# Kleo를 한 번만 추가 (모든 프로젝트에서 쓰려면 --scope user 추가) claude mcp add --transport http kleo https://mcp.kleooai.com/mcp # 그다음 세션 안에서: /mcp → Kleo → Authenticate
  1. 위 명령을 실행한 뒤 세션에서 /mcp를 입력하고 Kleo와 Authenticate를 선택하세요. 브라우저에 Kleo 페이지가 열리면 무료로 시작을 누르세요. 그러면 다시 Claude Code로 돌아옵니다.
  2. 이렇게 요청하세요: kleo로 커피의 역사에 관한 5분짜리 영상을 16:9로 만들어 줘. Claude Code가 진행 상황을 대신 확인하고 링크를 전달합니다.

Cursor mcp.json

~/.cursor/mcp.json(모든 프로젝트) 또는 프로젝트 안의 .cursor/mcp.json을 만들거나 편집하세요.

{ "mcpServers": { "kleo": { "url": "https://mcp.kleooai.com/mcp" } } }
  1. 파일을 저장하면 Cursor의 설정 → MCP에 Kleo가 나타납니다. Connect를 누르거나 도구를 한 번 사용하세요. Kleo 페이지가 열리면 무료로 시작을 누르세요. 그러면 다시 Cursor로 돌아옵니다.

VS Code mcp.json

워크스페이스에 .vscode/mcp.json을 만드세요(또는 명령 팔레트에서 MCP: Add Server를 실행하고 주소를 붙여 넣으세요).

{ "servers": { "kleo": { "type": "http", "url": "https://mcp.kleooai.com/mcp" } } }
  1. 파일을 저장한 뒤 서버 항목 위의 Start를 누르세요. VS Code가 Kleo 페이지를 열면 무료로 시작을 누르세요. 그러면 다시 VS Code로 돌아옵니다.
  2. Copilot Chat에서 Agent 모드로 전환하면 도구 선택기에 kleo 도구가 나타납니다.

OpenCode opencode.jsonc

~/.config/opencode/opencode.jsonc(전역) 또는 프로젝트의 opencode.jsonc에 다음을 추가한 뒤 터미널에서 연결하세요.

{ "mcp": { "kleo": { "type": "remote", "url": "https://mcp.kleooai.com/mcp", "enabled": true } } }
# 한 번만 연결 (브라우저가 열립니다) opencode mcp auth kleo
  1. 설정을 저장하고 위 명령을 실행하세요. 브라우저에 Kleo 페이지가 열리면 무료로 시작을 누르세요. 그러면 다시 OpenCode로 돌아옵니다.
  2. opencode를 시작하고 영상을 요청하세요. kleo 도구는 모든 세션에서 사용할 수 있습니다.

Gemini CLI cli

# Kleo 추가 (모든 프로젝트에서 쓰려면 --scope user 추가) gemini mcp add --transport http kleo https://mcp.kleooai.com/mcp
  1. 위 명령을 실행한 뒤 gemini를 시작하고 /mcp auth kleo를 입력하세요. 브라우저에 Kleo 페이지가 열리면 무료로 시작을 누르세요. 그러면 다시 Gemini CLI로 돌아옵니다.
  2. 세션에서 영상을 요청하세요. /mcp list로 모든 kleo 도구를 볼 수 있습니다.

Windsurf, Gemini 앱, 그리고 직접 만든 에이전트 http

Kleo는 OAuth 2.1을 갖춘 Streamable HTTP 전송 방식의 표준 MCP 서버입니다. 호환되는 클라이언트라면 무엇이든 같은 주소와 같은 원버튼 시작으로 연결됩니다.

서버 주소 https://mcp.kleooai.com/mcp
  1. Windsurf: 설정 → MCP → 서버 추가에서 주소를 붙여 넣으세요(mcp_config.json에서는 "serverUrl" 키를 사용합니다).
  2. Gemini 앱: 설정 → 연결된 앱 → 사용자 지정 앱에서 주소를 붙여 넣으세요(현재 Google AI Pro 또는 Ultra가 필요합니다).
  3. 직접 만든 에이전트라면 MCP SDK(Python 또는 TypeScript)를 HTTP 전송 방식으로 사용하고 OAuth 흐름을 한 번 완료하세요.

02첫 요청

분명한 요청으로 시작하세요.

어시스턴트는 요청을 Kleo의 인테이크(주제, 길이, 포맷, 룩)에 비추어 읽고, 트리트먼트를 쓰기 전에 빠진 것을 물어봅니다. 네 가지를 모두 말하면 곧바로 작업에 들어갑니다. 첫 채팅에 이것을 붙여 넣으세요:

“Kleo로 병에 담긴 편지를 발견하는 등대지기 이야기로 30초짜리 필름을 계획해 줘. 리얼리스틱 룩, 영어 내레이션, 9:16. 렌더링 전에 개요와 크레딧 비용을 보여 줘.”

서버에서 두 가지 룩을 사용할 수 있습니다. 생성된 실사 푸티지인 리얼리스틱과 2D 애니메이션 필름인 애니메이션. 프롬프트의 단어만 바꾸면 다른 룩이 됩니다.

03크레딧

제작 전에 잔액을 확인하세요.

연결하면 7크레딧이 포함됩니다. 스토리보드의 애니매틱은 5크레딧이며 모든 계정에서 주문할 수 있습니다. 필름은 어느 팩이든 팩을 구매한 계정에만 만들어 드리고, 30초 필름은 15크레딧이므로 첫 필름은 €5 팩에서 시작합니다. 7 + 10 = 17크레딧, 30초 쇼츠 한 편에 충분합니다.

어시스턴트에게 계정 페이지를 요청해 크레딧을 구매한 뒤, 렌더링을 시작하고 싶을 때 확인하세요. Kleo가 작업을 수락하기 전까지는 아무것도 청구되지 않습니다. 어시스턴트가 정확한 크레딧을 먼저 알려주며, 거부된 요청에는 비용이 들지 않습니다.
