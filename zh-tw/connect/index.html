Kleo 是一個遠端 MCP 伺服器。它透過 Streamable HTTP 搭配 OAuth 2.1 使用 Model Context Protocol，所以同一個位址在每個用戶端都能用，而連接只是 Kleo 自己頁面上的一個按鈕——沒有註冊表單、沒有密碼、沒有信用卡。免費開始：連接的那一刻，你的帳戶就有 7 點數，可做一支動態分鏡。把它加進你的助理，描述你想做的影片。

01連接

選擇你的助理。

下面每個用戶端都用同一個位址、同一個一鍵開始：貼上位址，Kleo 的頁面開啟，按下免費開始，你就回到用戶端，帳戶裡有 7 點數。這些是我們實際測試過的步驟。

Claude 應用程式 · 網頁版

伺服器位址 https://mcp.kleooai.com/mcp
  1. 開啟設定 → 連接器,選擇新增自訂連接器。
  2. 命名為 Kleo,貼上上方位址，然後確認。Kleo 的頁面會開啟：按下免費開始,就回到 Claude 了。
  3. 在新的對話裡，從工具選單開啟 Kleo,然後說：幫我做一支 45 秒的 Shorts,講……

Claude 免費方案允許一個自訂連接器。

ChatGPT 開發者模式

伺服器位址 https://mcp.kleooai.com/mcp
  1. 開啟設定 → 應用程式與連接器(舊版稱為連接器),接著進入進階設定,開啟開發者模式。
  2. 回到連接器,選擇建立:命名為 Kleo,貼上位址，驗證方式設為 OAuth,然後儲存。Kleo 的頁面會開啟：按下免費開始,就回到 ChatGPT 了。
  3. 在對話中，從 + 選單開啟 Kleo,然後要求製作影片。ChatGPT 會在開始渲染前請你確認。

需要 ChatGPT Plus、Pro、Business 或 Enterprise。

Grok 連接器

伺服器位址 https://mcp.kleooai.com/mcp
  1. 在 grok.com 或應用程式裡，開啟設定 → 連接器，選擇新增連接器 → 自訂。

Claude Code cli

# 加入 Kleo 一次（加上 --scope user 可在每個專案使用） claude mcp add --transport http kleo https://mcp.kleooai.com/mcp # 然後，在工作階段裡： /mcp → Kleo → Authenticate
  1. 執行上方指令，然後在工作階段裡輸入 /mcp，選擇 Kleo 和 Authenticate：Kleo 的頁面會在瀏覽器開啟，按下免費開始，就回到 Claude Code 了。
  2. 提出要求：用 kleo 做一支 5 分鐘的影片，講咖啡的歷史，16:9。Claude Code 會替你跟進進度，並把連結交給你。

Cursor mcp.json

建立或編輯 ~/.cursor/mcp.json（所有專案）或單一專案裡的 .cursor/mcp.json。

{ "mcpServers": { "kleo": { "url": "https://mcp.kleooai.com/mcp" } } }
  1. 儲存檔案：Cursor 會在設定 → MCP 下列出 Kleo。按下連接（或使用任一工具一次）：Kleo 的頁面會開啟，按下免費開始，就回到 Cursor 了。

VS Code mcp.json

在你的工作區建立 .vscode/mcp.json（或從命令選擇區執行 MCP: Add Server 並貼上位址）。

{ "servers": { "kleo": { "type": "http", "url": "https://mcp.kleooai.com/mcp" } } }
  1. 儲存檔案，然後按下伺服器項目上方的啟動。VS Code 會開啟 Kleo 的頁面：按下免費開始，就回到 VS Code 了。
  2. 在 Copilot Chat 裡切換到代理模式：kleo 工具就會出現在工具選擇器裡。

OpenCode opencode.jsonc

把這段加進 ~/.config/opencode/opencode.jsonc（全域）或專案裡的 opencode.jsonc，然後從終端機連接。

{ "mcp": { "kleo": { "type": "remote", "url": "https://mcp.kleooai.com/mcp", "enabled": true } } }
# 連接一次（會開啟瀏覽器） opencode mcp auth kleo
  1. 儲存設定並執行上方指令：Kleo 的頁面會在瀏覽器開啟，按下免費開始，就回到 OpenCode 了。
  2. 啟動 opencode 並要求製作影片：kleo 工具在每個工作階段都可以使用。

Gemini CLI cli

# 加入 Kleo（加上 --scope user 可在每個專案使用） gemini mcp add --transport http kleo https://mcp.kleooai.com/mcp
  1. 執行上方指令，然後啟動 gemini 並輸入 /mcp auth kleo：Kleo 的頁面會在瀏覽器開啟，按下免費開始，就回到 Gemini CLI 了。
  2. 在工作階段裡要求製作影片。/mcp list 會列出每個 kleo 工具。

Windsurf、Gemini 應用程式和你自己的代理 http

Kleo 是一個標準的 MCP 伺服器，使用 Streamable HTTP 傳輸搭配 OAuth 2.1。任何相容的用戶端都用同一個位址、同一個一鍵開始來連接。

伺服器位址 https://mcp.kleooai.com/mcp
  1. Windsurf：設定 → MCP → 新增伺服器，貼上位址（它的 mcp_config.json 使用 "serverUrl" 這個鍵）。
  2. Gemini 應用程式：設定 → 已連接的應用程式 → 自訂應用程式，貼上位址（目前需要 Google AI Pro 或 Ultra）。
  3. 你自己的代理：使用 MCP SDK（Python 或 TypeScript）搭配 HTTP 傳輸，完成一次 OAuth 流程即可。

02第一個請求

從一個清楚的請求開始。

助理會用 Kleo 的確認清單核對你的請求——主題、長度、格式、風格——缺什麼就先問，再寫故事大綱。四項都說清楚，它就直接開工。把這段貼進你的第一個對話：

「用 Kleo 規劃一部 30 秒的影片，講一位燈塔看守人發現瓶中信。寫實風格，英語旁白，9:16。開始渲染前先讓我看大綱和點數費用。」

伺服器上有兩種風格：寫實，生成的實景影像；動畫，2D 動畫影片。把提示詞裡的那個詞換掉，就得到另一種。

03點數

製作前先確認餘額。

連接即含 7 點數：你分鏡的動態分鏡要 5 點，每個帳戶都可以訂製一支。影片只為已購買點數包（任一種）的帳戶製作，而一部 30 秒的影片要 15 點數，所以第一部影片從 €5 點數包開始：7 + 10 = 17 點數，足夠做一支 30 秒的 Shorts。

向助理索取你的帳戶頁面來購買點數，然後在你想開始渲染時確認。Kleo 接受工作之前不會扣任何費用：助理會先明示確切的點數，被拒絕的請求不花一毛錢。
