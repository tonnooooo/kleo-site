01設定

把 Kleo 加進 Claude。

Kleo 是一個遠端 MCP 伺服器。不必安裝任何應用程式，也沒有註冊表單：Claude 透過自訂連接器連上它，而連接只是 Kleo 自己頁面上的一個按鈕。下面的步驟在 Claude 應用程式和網頁版都相同，也適用於每個 Claude 方案；免費方案允許一個自訂連接器。

  1. 在 Claude 裡開啟設定 → 連接器，選擇新增自訂連接器。
  2. 命名為 Kleo，貼上下方位址，然後確認。
  3. Kleo 的頁面會開啟：按下免費開始。你就回到 Claude 了，新的 Kleo 帳戶裡有 7 點數。沒有表單、沒有密碼、沒有信用卡：足夠做一支 5 點數的動態分鏡。影片只為已購買點數包的帳戶製作，最少 10 點數，所以第一部影片之前要先加購 €5 點數包（10 點數）；一部 30 秒的影片是 15 點。
  4. 在新的對話裡，從工具選單開啟 Kleo，然後要求製作影片。
伺服器位址 https://mcp.kleooai.com/mcp

Claude 是 Anthropic 的助理。Kleo 是一個獨立的服務，Claude 透過自訂連接器連上它；同一個位址在 ChatGPT、Grok、Claude Code、Cursor 和任何其他 MCP 用戶端都能用——請見連接頁面。

02第一個提示詞

說出你想要的影片。

在一則訊息裡說明主題、長度、格式和風格。受眾、語氣和影片裡必須出現的東西是選填。你的請求漏掉的，Claude 會在規劃任何東西之前先問；它絕不會替你決定長度、格式或風格。

「用 Kleo 做一部 30 秒的影片，講一艘小木船在黎明時分渡過寧靜的湖面。寫實風格，16:9，英語旁白，語氣平靜。開始渲染前先讓我看故事大綱和確切的點數。」

  • 風格有兩種風格：寫實，生成的實景影像，帶有電影感；動畫，2D 動畫影片。看看影片風格 →
  • 格式YouTube 用 16:9，Shorts 用 9:16。
  • 長度15 秒到 5 分鐘。
  • 旁白英語或義大利語。
03在對話裡

接下來對話裡會發生什麼。

Kleo 的工具依固定順序執行，由 Claude 替你操作。每一步你都可以閱讀、修正和確認；在你點頭且工作被接受之前，不會扣任何費用。

01 kleo_adapt_prompt

故事大綱

Claude 會用 Kleo 的確認清單核對你的請求。主題、長度、格式和風格為必填；受眾、語氣和必須出現的東西為選填。缺什麼，它會在一則訊息裡問完。接著讓你看故事大綱：主軸、切入角度、開場畫面、幕次、結局、風格、節奏和旁白。繼續之前，想改什麼都可以。

02 kleo_storyboard_guide

分鏡

Claude 會取得 Kleo 的分鏡指南（一段執導方向、場景、鏡頭及其限制），並依據你確認的故事大綱寫出分鏡。影片就是在這裡成形的；請讀過，並提出修改。

03 kleo_create_video

渲染

Kleo 會檢查全部內容，並回覆這部影片確切的點數。你同意後，Claude 就在為這一個工作租用的 GPU 上開始渲染。工作被接受之前不會扣任何費用，被拒絕的呼叫不花一毛錢。

04 kleo_wait_for_video

連結

Claude 會等待渲染並回報進度，直到 Kleo 交出完成 MP4 的連結，通常在 25–35 分鐘後。連結 7 天內有效。Kleo 絕不會把影片發布到任何地方：你自己下載，想貼哪就貼哪。

04影片

你會得到什麼。

  • 輸出一個 4K（3840×2160 或 2160×3840）、60 fps 的 MP4：YouTube 用 16:9，Shorts 用 9:16。
  • 長度影片 15 秒到 5 分鐘；動態分鏡 15 到 60 秒。
  • 風格寫實（生成的實景影像，電影感）或動畫（2D 動畫影片）。影片裡的每個鏡頭都是從各自的畫格生成的動態影像。
  • 產品影片，或同一份分鏡的動態分鏡：手繪畫格在移動的鏡頭下呈現，同樣的旁白和圖層，沒有生成的片段。每個帳戶都可以訂製動態分鏡；影片只為已購買點數包的帳戶製作。
  • 旁白一位旁白，英語或義大利語。沒有背景音樂、沒有字幕、沒有畫面文字。
  • 點數影片：1 點數 = 2 秒，無條件進位，最少 10 點數：15 秒 = 10，30 秒 = 15，60 秒 = 30，5 分鐘 = 150。動態分鏡：固定 5 點數。起步有 7 點數；點數包為 €5 = 10、€15 = 35、€40 = 100，一次付清，不必訂閱。
  • 時間渲染在租用的 GPU 上通常需要 25–35 分鐘；Kleo 會在對話裡告訴你預估時間。

05疑難排解

如果有什麼不順利。

Claude 裡沒有出現 Kleo。

檢查你貼上的位址：必須完全是 https://mcp.kleooai.com/mcp，用 https，/mcp 之後沒有任何東西。以 Kleo 這個名稱重新新增連接器。新增之後，它在對話裡仍是關閉的，要你手動開啟：開一個新對話，從工具選單把 Kleo 打開。免費方案只允許一個自訂連接器，所以那一個必須是 Kleo。

Kleo 的頁面一直沒開啟，或視窗被封鎖。

當你確認連接器時，Claude 會開啟 Kleo 的登入頁面：一個「免費開始」按鈕，沒有任何要填的東西。如果你的瀏覽器把它當成彈出視窗封鎖了，請允許 Claude 的彈出視窗並再次確認連接器；頁面會開啟，你按下「免費開始」，就回到 Claude 了。

點數不足。

連接即得 7 點數：可買一支動態分鏡（5 點），永遠買不到影片。影片只為已購買點數包的帳戶製作，一部 30 秒的影片是 15 點數：加購 €5 點數包（10 點數）後你有 17 點，渲染就可以開始。向 Claude 索取你的 Kleo 帳戶頁面（kleo_account）：上面會顯示餘額和結帳連結（€5 = 10 點數、€15 = 35、€40 = 100；以歐元一次付清，不必訂閱）。被拒絕的呼叫沒有扣費。

影片還沒好，等待就逾時了。

較長的渲染可能超過單次工具呼叫的時限，但工作仍在它的 GPU 上繼續。請 Claude 查詢工作狀態（kleo_get_job）或再等一次（kleo_wait_for_video），然後索取連結（kleo_get_result）。不要為了確認第一部影片而再要求第二部。

你想停止渲染。

請 Claude 取消工作（kleo_cancel_job）。渲染會停止，未用掉的點數會退回你的餘額。
