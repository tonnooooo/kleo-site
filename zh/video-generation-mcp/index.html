一个视频制作
MCP 服务器。

Kleo 向任何 MCP 客户端开放同一套影片工作流：需求确认、剧本大纲、分镜、在为任务租用的 GPU 上渲染，以及一部 4K 60 fps 旁白成片的链接。一位旁白，两种风格，两种产品（影片，或同一套分镜的动态分镜），15 秒到 5 分钟。没有应用，没有控制台；助手通过下面的工具完成工作。

01端点

通过 HTTPS 连接。

Kleo 是一个远程 MCP 服务器：一个地址，Streamable HTTP 传输，OAuth 2.1。在你的 MCP 客户端里配置地址，在浏览器中完成授权；没有注册表单，没有密码。

  • 端点https://mcp.kleooai.com/mcp
  • 传输Streamable HTTP；每个客户端都用同一个地址。
  • 认证OAuth 2.1。授权过程中客户端会打开 Kleo 自己的页面；点击免费开始，你就回到了客户端，账户里有 7 积分。没有表单，没有银行卡。
  • 没有令牌时对端点的 GET 请求返回 401，并携带 OAuth 资源元数据。它是协议端点，不是网页：在浏览器里打开它并不是连接流程。
  • 客户端Claude、ChatGPT、Grok、Claude Code、Cursor、VS Code、OpenCode、Gemini CLI、Windsurf、Gemini 应用，以及任何使用 HTTP 传输的 MCP SDK。

从终端或编辑器。

02工作流程

制作顺序。

工具按固定顺序运行。助手读取你的请求，从 kleo_adapt_prompt 获得剧本大纲，按照 kleo_storyboard_guide 写出分镜，然后才请 Kleo 渲染。

kleo 工具，按助手运行它们的顺序

工具 作用
kleo_adapt_prompt 对照需求清单（主题、时长、格式、风格；可选的受众、语调、必须出现的内容）读取请求，问清缺少的信息，然后返回剧本大纲：故事梗概、切入角度、开场、幕次、结局、风格、节奏、旁白。
kleo_storyboard_guide 说明分镜怎么写：导演思路、场景、镜头和限制。
kleo_create_video 检查全部内容，说明准确的积分数，然后在为该任务租用的 GPU 上开始渲染。接受 product: "film" 或 "animatic"。
kleo_get_job 用一次调用汇报任务进度。
kleo_wait_for_video 等待渲染并汇报进度，直到影片就绪。
kleo_get_result 返回成片的链接。
kleo_cancel_job 停止渲染并退还尚未花掉的积分。
kleo_list_templates 列出唯一的工作流——影片——及其格式、时长和声音，以及账户剩余的积分。动态分镜是同一工作流的一种产品。
kleo_account 显示积分、账户是否已付费（has_paid，它决定能否订购影片）、账户页面的链接，以及私密的 Kleo 密钥。
kleo_generate_thumbnail 测试版尚未提供。

准确的参数以线上服务器的工具模式为准。如果你的客户端限制单次工具调用的运行时长，助手可以轮询 kleo_get_job，而不是一直挂着 kleo_wait_for_video。

03参数

一次渲染需要什么。

kleo_create_video 接收你用自己的话写的请求，加上需求确认时问到的选项。剧本大纲和分镜来自两个规划工具，不是你亲手输入的。

  • prompt用户用自己的话写的请求。
  • productfilm（默认：每个镜头都是生成的视频片段，按时长计价，面向购买过积分包的账户）或 animatic（运动镜头下的手绘画帧，没有生成的视频片段，固定 5 积分，15 到 60 秒，对每个账户开放）。
  • duration_s影片 15 到 300 秒，动态分镜 15 到 60 秒。
  • format16:9 用于 YouTube 和横版，9:16 用于 Short 和竖版。
  • stylerealistic（生成的真人实拍感画面，电影感）或 animation（一部 2D 动画影片）。影片中每个镜头都从各自的画帧生成为动态画面；动态分镜则把这种风格保留在手绘画帧里。
  • languageen 或 it 旁白。一位旁白；标准影片中没有音乐、没有字幕、没有屏幕文字。
  • voice可选：narrator-en-m、narrator-en-f、narrator-it-m 或 narrator-it-f。
  • treatment可选：kleo_adapt_prompt 返回的剧本大纲（故事梗概、切入角度、开场、幕次、结局、风格、节奏、旁白）。
  • storyboard可选：按照 kleo_storyboard_guide 写出的分镜（导演思路、场景、镜头、限制）。

价格

影片：一积分对应两秒，向上取整，最低十积分：15 秒 = 10 · 20 秒 = 10 · 30 秒 = 15 · 60 秒 = 30 · 90 秒 = 45 · 3 分钟 = 90 · 5 分钟 = 150。动态分镜：固定 5 积分，15 到 60 秒。连接即包含 7 积分，一部动态分镜；影片只为购买过积分包的账户制作（它的视频片段由 Kleo 出钱生成，所以免费积分永远买不到影片）：7 + €5 积分包 = 17，影片解锁，一个 30 秒的 Short。积分包一次付清，以欧元计价，无需订阅：€5 = 10 积分 · €15 = 35 · €40 = 100。

任务被接受之前不扣任何费用

kleo_create_video 会先回复准确的积分数；被拒绝的调用不收费，kleo_cancel_job 会退还被停止的渲染尚未花掉的积分。

渲染时间

在租用的 GPU 上，影片通常需要 25–35 分钟，动态分镜约 15–20 分钟；服务器会把该任务的预计时间告诉助手。这不是固定时间。

04输出

输出是一部完整的视频。

一个 MP4：4K（3840×2160 或 2160×3840）60 fps，16:9 或 9:16，一位英语或意大利语旁白，影片中每个镜头都生成为动态画面。kleo_get_result 把文件链接交给助手；链接 7 天内有效。

Kleo 从不向 YouTube、TikTok 或任何渠道发布，标准影片不带音乐、字幕和屏幕文字。服务器上有两种风格，写实和动画；网站的风格页面各展示一部示例。

05账户

账户与任务处理。

不要让 OAuth 令牌和 Kleo 密钥出现在日志和公开示例里：密钥是私密的，谁持有密钥，谁就拥有账户。没有控制台；账户页面（只读的余额和结账链接）通过向助手索要获得，由 kleo_account 返回。

渲染会花积分：在 kleo_create_video 运行前先请求确认，查看进度或取消时复用任务标识符。服务器代码是公开的。
