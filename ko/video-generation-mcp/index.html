영상 제작을 위한
MCP 서버.

Kleo는 모든 MCP 클라이언트에 하나의 필름 워크플로를 제공합니다. 인테이크, 트리트먼트, 스토리보드, 작업을 위해 대여한 GPU에서의 렌더링, 그리고 4K 60 fps로 완성된 내레이션 필름의 링크까지. 내레이터 한 명, 두 가지 룩, 두 가지 제품(필름, 또는 같은 스토리보드의 애니매틱), 15초에서 5분. 앱도 대시보드도 없습니다. 어시스턴트가 아래 도구로 작업을 수행합니다.

https://mcp.kleooai.com/mcp
Kleo 연결하기 → 공개 저장소
01엔드포인트

HTTPS로 연결하세요.

Kleo는 원격 MCP 서버입니다. 주소 하나, Streamable HTTP 전송 방식, OAuth 2.1. MCP 클라이언트에 주소를 설정하고 브라우저에서 인증을 마치세요. 가입 양식도 비밀번호도 없습니다.

  • 엔드포인트https://mcp.kleooai.com/mcp
  • 전송 방식Streamable HTTP. 모든 클라이언트에서 같은 주소.
  • 인증OAuth 2.1. 인증 중에 클라이언트가 Kleo 페이지를 열고, 무료로 시작을 누르면 계정에 7크레딧이 담긴 채로 클라이언트로 돌아옵니다. 양식도 카드도 없습니다.
  • 토큰 없이엔드포인트에 GET을 보내면 401과 함께 OAuth 리소스 메타데이터가 돌아옵니다. 웹 페이지가 아니라 프로토콜 엔드포인트입니다. 브라우저에서 여는 것은 연결 절차가 아닙니다.
  • 클라이언트Claude, ChatGPT, Grok, Claude Code, Cursor, VS Code, OpenCode, Gemini CLI, Windsurf, Gemini 앱, 그리고 HTTP 전송 방식을 갖춘 모든 MCP SDK.

모든 클라이언트의 연결 단계 →

터미널이나 편집기에서.

테스트한 클라이언트 중 두 가지를 예로 들었습니다. Claude와 ChatGPT부터 VS Code와 Gemini CLI까지 나머지 단계는 연결 페이지에 있습니다.

Claude Code cli

# Kleo를 한 번만 추가 claude mcp add --transport http kleo https://mcp.kleooai.com/mcp # 그다음 세션 안에서: /mcp → Kleo → Authenticate

브라우저에 Kleo 페이지가 열리면 무료로 시작을 누르세요. 그러면 다시 Claude Code로 돌아옵니다.

Cursor ~/.cursor/mcp.json

{ "mcpServers": { "kleo": { "url": "https://mcp.kleooai.com/mcp" } } }

파일을 저장하세요. Cursor가 연결할 때 Kleo 페이지가 열리면 무료로 시작을 누르세요. 그러면 다시 Cursor로 돌아옵니다.

02워크플로

제작 순서.

도구는 정해진 순서로 실행됩니다. 어시스턴트가 요청을 읽고, kleo_adapt_prompt에서 트리트먼트를 받고, kleo_storyboard_guide에 따라 스토리보드를 쓴 다음에야 Kleo에 렌더링을 요청합니다.

어시스턴트가 실행하는 순서대로 본 kleo 도구

도구 하는 일
kleo_adapt_prompt 요청을 인테이크(주제, 길이, 포맷, 룩. 선택 사항으로 대상 시청자, 톤, 꼭 들어가야 할 것)에 비추어 읽고, 빠진 것을 물은 뒤 트리트먼트를 돌려줍니다. 로그라인, 앵글, 오프닝, 막 구성, 결말, 룩, 페이싱, 내레이터.
kleo_storyboard_guide 스토리보드 쓰는 방법을 설명합니다. 연출 블록, 장면, 샷, 그리고 한도.
kleo_create_video 모든 것을 확인하고 정확한 크레딧을 알려준 뒤, 그 작업을 위해 대여한 GPU에서 렌더링을 시작합니다. product: "film" 또는 "animatic"을 받습니다.
kleo_get_job 작업의 진행 상황을 한 번의 호출로 알려줍니다.
kleo_wait_for_video 렌더링을 기다리며 필름이 준비될 때까지 진행 상황을 알려줍니다.
kleo_get_result 완성된 필름의 링크를 돌려줍니다.
kleo_cancel_job 렌더링을 멈추고 아직 쓰지 않은 크레딧을 환불합니다.
kleo_list_templates 유일한 워크플로인 필름을 포맷, 길이, 목소리와 함께 나열하고, 계정에 남은 크레딧을 알려줍니다. 애니매틱은 같은 워크플로의 제품입니다.
kleo_account 크레딧, 계정의 결제 여부(has_paid, 필름을 주문할 수 있는지 결정), 계정 페이지 링크, 비공개 Kleo 키를 보여줍니다.
kleo_generate_thumbnail 아직 베타에 포함되지 않았습니다.

정확한 인수는 라이브 서버의 도구 스키마를 사용하세요. 클라이언트가 도구 호출의 실행 시간을 제한한다면, 어시스턴트는 kleo_get_job을 폴링하면 되고 kleo_wait_for_video를 계속 열어 둘 필요가 없습니다.

03매개변수

렌더링에 필요한 것.

kleo_create_video는 당신의 말로 된 요청과 인테이크가 물은 선택 사항을 받습니다. 트리트먼트와 스토리보드는 두 계획 도구에서 나오며, 키보드로 직접 입력하는 것이 아닙니다.

  • prompt사용자 자신의 말로 된 요청.
  • productfilm(기본값. 모든 샷이 생성된 클립, 길이에 따라 가격 책정, 팩을 구매한 계정 전용) 또는 animatic(움직이는 카메라 아래 그려진 프레임, 생성된 클립 없음, 5크레딧 정액, 15초에서 60초, 모든 계정).
  • duration_s필름은 15초에서 300초, 애니매틱은 15초에서 60초.
  • formatYouTube와 가로형은 16:9, 쇼츠와 세로형은 9:16.
  • stylerealistic(생성된 실사 푸티지, 시네마틱) 또는 animation(2D 애니메이션 필름). 필름에서는 모든 샷이 각자의 프레임에서 움직이는 푸티지로 생성되고, 애니매틱은 그려진 프레임 안에 룩을 담습니다.
  • languageen 또는 it 내레이션. 내레이터 한 명. 표준 필름에는 음악도, 자막도, 화면 속 텍스트도 없습니다.
  • voice선택 사항: narrator-en-m, narrator-en-f, narrator-it-m 또는 narrator-it-f.
  • treatment선택 사항: kleo_adapt_prompt가 돌려준 트리트먼트(로그라인, 앵글, 오프닝, 막 구성, 결말, 룩, 페이싱, 내레이터).
  • storyboard선택 사항: kleo_storyboard_guide에 따라 쓴 스토리보드(연출 블록, 장면, 샷, 한도).

가격

필름: 1크레딧이 2초(올림), 최소 10크레딧. 15초 = 10 · 20초 = 10 · 30초 = 15 · 60초 = 30 · 90초 = 45 · 3분 = 90 · 5분 = 150. 애니매틱: 5크레딧 정액, 15초에서 60초. 연결하면 7크레딧, 애니매틱 한 편 분량이 포함됩니다. 필름은 팩을 구매한 계정에만 만들어 드립니다(클립이 Kleo의 비용으로 생성되므로 무료 크레딧으로는 살 수 없습니다). 7 + €5 팩 = 17, 필름이 열리고, 30초 쇼츠 한 편. 팩은 EUR 일회성 결제이며 정기 결제는 없습니다. €5 = 10크레딧 · €15 = 35 · €40 = 100.

작업이 수락되기 전까지는 아무것도 청구되지 않습니다

kleo_create_video가 먼저 정확한 크레딧을 알려줍니다. 거부된 호출에는 아무것도 청구되지 않으며, kleo_cancel_job은 멈춘 렌더링이 쓰지 않은 크레딧을 환불합니다.

렌더링 시간

필름은 대여한 GPU에서 보통 25–35분, 애니매틱은 15–20분 정도 걸립니다. 서버가 작업의 예상 시간을 어시스턴트에게 알려줍니다. 정해진 시간은 아닙니다.

04출력

출력은 완성된 영상입니다.

MP4 하나: 4K(3840×2160 또는 2160×3840), 60 fps, 16:9 또는 9:16, 영어 또는 이탈리아어 내레이터 한 명, 그리고 필름에서는 모든 샷이 움직이는 푸티지로 생성됩니다. kleo_get_result가 파일 링크를 어시스턴트에게 전달하며, 링크는 7일간 유효합니다.

Kleo는 YouTube, TikTok 등 어떤 채널에도 게시하지 않으며, 표준 필름에는 음악도, 자막도, 화면 속 텍스트도 없습니다. 서버에서 리얼리스틱과 애니메이션, 두 룩을 운영 중이고, 사이트의 룩 페이지에서 각각의 샘플을 보여드립니다.

05계정

계정과 작업 관리.

OAuth 토큰과 Kleo 키는 로그와 공개 예시에 남기지 마세요. 키는 비공개이며, 그 키를 가진 사람이 계정의 주인이 됩니다. 대시보드는 없습니다. 계정 페이지(읽기 전용 잔액과 결제 링크)는 어시스턴트에게 요청해서 열며, kleo_account가 돌려줍니다.

렌더링은 크레딧을 씁니다. kleo_create_video가 실행되기 전에 확인을 요청하고, 진행 상황을 확인하거나 취소할 때는 같은 작업 식별자를 다시 사용하세요. 서버 코드는 공개되어 있습니다.
